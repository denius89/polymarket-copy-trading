# Controlled Copy Trading

Рабочий Git-проект сервиса контролируемого копирования сделок на prediction markets.

Первый MVP ориентирован на Polymarket. Limitless исследуется как следующая площадка и не должен усложнять первый прототип.

## Идея

После автоматического входа пользователь сохраняет контроль над каждой позицией и портфелем. Система показывает источник сделки, фактическое исполнение, решение risk engine, виртуальный лот и итоговый P&L.

## Структура

```text
apps/
  web/                 интерфейс пользователя
  worker/              получение событий и фоновые задачи
packages/
  core/                доменная логика, risk engine и virtual lots
  platforms/           адаптеры Polymarket и позднее Limitless
  testing/             fixtures и средства симуляции
docs/                   продукт, архитектура, план и состояние
research/               исследования площадок и конкурентов
references/             исходные материалы проекта, только для чтения
artifacts/              презентации и другие готовые материалы
infra/                  окружения и развёртывание
```

## Базовые ограничения

- реальные ордера по умолчанию выключены;
- приватные ключи, seed phrase и рабочие токены не сохраняются в Git;
- до live-теста используются mock data, записанные события и paper trading;
- каждое действие с позицией должно объясняться журналом;
- денежные значения не рассчитываются через binary floating point;
- публичный запуск требует отдельных security- и legal-gates.

## Начало работы

Пока репозиторий содержит проектную основу без установленных зависимостей. Переход к инженерному циклу возможен после согласования идеи, экономики и архитектуры и отдельного решения основателя.
