# Shared UI kit

`@cct/ui` owns the client color foundation and reusable Button, Card, Field, Notice, and Segmented controls. Token values were transcribed from the live Final Figma client screens; they are shared with `apps/web` and can be imported by `apps/admin`. The library uses semantic native controls and 44–48 px targets. It does not contain product data, permissions, or financial state.

Exports: `Button`, `Card`, `Field`, `Notice`, `Segmented`, `Locale`, and `Activity`, `ArrowLeft`, `ArrowRight`, `Bell`, `CircleHelp`, `House`, `Layers3`, `UserRound`, `UsersRound` icons. Styles are also exported at `@cct/ui/styles.css`.
