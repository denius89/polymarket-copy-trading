# Platform adapters

Изолированные адаптеры двух обязательных площадок: Polymarket и Limitless. Общий core остаётся venue-neutral, а readiness и live-доступ включаются для каждой площадки отдельно. Limitless идёт первым партнёрским spike, Polymarket Builder/Session Keys исследуются параллельно после возобновления технического этапа. См. ADR-0007 и ADR-0008.
