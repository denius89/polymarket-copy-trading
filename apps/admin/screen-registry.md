# Реестр реализации админки v1

Базовый коммит `6ebee6a7`. [Карта Figma от 03.11.2026](../../docs/design/admin/rebuild/figma/manifest.json) содержит 134 пары настольных и мобильных корней, общих для RU/EN. [Правила переходов](../../docs/design/admin/rebuild/navigation.md) и [сверка X07–X09](../../docs/design/admin/rebuild/contract-review/README.md) дополняют карту.

Клиентские справочные кадры сопоставлены по ключу сценария. Они помогают сверять правила между приложениями и не образуют маршруты админки. Остальные пары дополнительно сверены по ссылке мобильного кадра на настольный.

Стартовый экран `/admin/` показывает недоступность входа сотрудников. Это состояние приложения, отдельно от учебного выбора ролей в Figma. Разработка ведётся в рамках [плана интерфейсов](../../docs/technical/frontend/README.md).
