# Shadow · админка

Первый пакет включает состояние недоступности входа сотрудников, RU/EN и отдельную сборку по пути `/admin/`. Выбор языка сохраняет текущий URL и его параметры. [Реестр экранов v1](screen-registry.md) фиксирует очередь реализации.

Из корня общего проекта после установки зависимостей из lockfile:

```sh
npm run dev --workspace @cct/admin
npm run build --workspace @cct/admin
```

Для прямых ссылок внутри `/admin/` сервер отдаёт `apps/admin/dist/index.html`. Пока серверный вход сотрудников недоступен, приложение показывает это состояние и при прямом открытии защищённого адреса. Клиентская сессия Shadow не даёт доступа к рабочей области. API-запросы и данные сотрудников в этот пакет не входят.

## Локальная проверка вёрстки

После запуска сервера разработки откройте `/admin/review/`. Витрина содержит
синтетические данные и отдельно отмечает учебное назначение. Из обзора можно
перейти в отфильтрованный список пользователей, карточку, сессию и заявку.
Фильтры и выбор языка хранятся в адресе витрины. В поддержке доступны учебные списки обращений и отзывов, связанные инциденты и возвраты из торгового контекста. Изменения записей ожидают служебный API. В разделе «Финансы → Сверка операций» можно проверить три учебных снимка и вернуться из связанных записей. Результаты сравнения хранятся в памяти вкладки до перезагрузки. Права в этом маршруте относятся
к учебному набору. Для рабочего приложения отдельный вход сотрудников и
серверная проверка полномочий обязательны.

Vite собирает основной `index.html`. Страница и данные `review/` остаются
в локальной разработке и не публикуются с `dist/`.
