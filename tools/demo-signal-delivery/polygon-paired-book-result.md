# Время покупки по общей книге Polymarket

28 ноября 2026 года на изолированном сервере один новый подтверждённый сигнал Polygon обработали два виртуальных счёта. Тест использовал реальную публичную книгу Polymarket и виртуальные средства. Окно обработки составляло 30 секунд.

| Этап | Демо A | Демо B |
|---|---:|---:|
| Публикация в очереди с момента события | 3,352 с | 3,352 с |
| Допуск к книге с момента события | 9,330 с | 9,345 с |
| Получение снимка | 9,549 с | 9,549 с |
| Ответ об успешном коммите | 10,887 с | 10,095 с |

Полные сохранённые снимки книги совпали. Сверка по каждому счёту подтвердила одну запись исполнения, одну квитанцию, одно списание и соответствующее увеличение позиции. Источник времени для последней строки — обработчик после возврата PostgreSQL из коммита.

Полную проверку истории перенесли до запроса цены. В момент исполнения обработчик сверяет актуальность версии, срок сигнала и свежесть зафиксированного снимка. Книга проверяется по времени площадки и времени приёма. Прежние сигналы и отдельные успешные покупки разных счетов исключены из этого результата.

Это наблюдение по одному свежему сигналу. Для оценки доли пропусков и p95 нужна серия при разной плотности входящих событий. Подробные квитанции и настройки окружения хранятся на закрытом стенде.
