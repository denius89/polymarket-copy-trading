# Замер очереди Polymarket

Для двухчасового среза одного демо передайте ID сессии в переменной psql `pm_session`. Выполните [читающий SQL](polygon-observation-timings.sql) с `psql -XqAt` и сохраните результат как JSON Lines в закрытом временном файле. Передайте сообщения журнала одного обработчика покупок за тот же период через стандартный ввод в `python3 polygon-queue-timings.py --observations <jsonl>`. Удалите временный файл после замера. Отчёт содержит только счётчики и длительности.

Замер 26 ноября 2026 года по рабочему демо. Из 520 просроченных сигналов у 264 запись наблюдения уже имела отметку времени после дедлайна. Для 339 к дедлайну оставалось более раннее незавершённое задание. Группы пересекаются. Это сравнение ограничено заданиями из двухчасового окна, а отметки записи предшествуют COMMIT.

В журнале p95 от вставки до первого чтения обработчиком составил 23,148 с по 417 сигналам с обеими отметками. На 18 случаях с принятым в аренду заданием p95 аренды составил 67 мс, а p95 проверки истории — 3,856 с. Новых покупок в этом срезе нет, поэтому длительность от книги до покупки по нему не вычисляется. Для отдельной ранее подтверждённой покупки сохранён замер 26,783 с до COMMIT.
