# Сверка закрытой среды для staff Q06 · 20.11.2026

**Итог сверки Oracle V00.** Рабочая PostgreSQL содержит staff-профиль с двумя актуальными назначениями. У профиля истёк срок. Опубликованный адрес показывает действующий серверный сертификат. Для отдельного staff HTTPS-входа остаются нужны процессы и TLS-профиль.

Сверен пакет из `main@0e0b93e`, объединённый в [PR №279](https://github.com/denius89/polymarket-copy-trading/pull/279). За ориентир взята сохранённая конфигурация закрытого Oracle V00 и локальные архивные срезы 18–19 ноября. Действующий сервер опрошен позже в согласованном режиме только для чтения. ## Чтение Oracle V00 · 20.11.2026

- На сервере ARM64 найдены две разные базы с одинаковым именем. В старой базе V00 функций Q06 нет. Рабочий API использует другую PostgreSQL 17.11 в своей внутренней сети. В ней обнаружены `pilot_staff.session_read` и `polygon.pilot_staff_snapshot`. Состояние читалось в транзакции `REPEATABLE READ READ ONLY`.
- В рабочей БД есть существующий staff-профиль. Флаг включён, поле закрытия пустое, срок действия истёк. Оба назначения совпадают с текущими активными слотами и владельцами. Ранее выявленное несовпадение одного назначения на текущем срезе отсутствует. Для обновления срока нужен отдельный план с сохранением связей аудита. Штатное первичное создание не применяется поверх существующего профиля.
- Рабочие БД и пользовательский API подключены к закрытой сети Docker. Наружу их порты не опубликованы. В выделенной закрытой staff-сети обнаружен только шлюз. Отдельные процессы staff auth и reader в этом сегменте не наблюдались.
- Опубликованный шлюз предъявил сертификат с SAN для текущего IP. Срок действия до **23.11.2026, 14:01 по Варшаве**. В этом TLS-рукопожатии запрос клиентского сертификата не наблюдался. У локального служебного TLS на порту 18443 сертификат совпал с известным локальным отпечатком, SAN — `localhost`, срок действия до 04.12.2026. Цепочку доверия и разрешённые клиентские отпечатки нового выделенного адреса ещё предстоит подтвердить.

Служебный вход и чтение через Q06 в этом проходе не выполнялись: штатный Q06 записывает аудит. Настройки, состояние пилота и данные БД сохранены.

[План возобновления staff-доступа](renewal-plan.md).

## Готовность схемы к миграции · 20.11.2026

Рабочая PostgreSQL 17.11 проверена одним проходом `REPEATABLE READ READ ONLY`
после слияния [PR №281](https://github.com/denius89/polymarket-copy-trading/pull/281).
Владельцы задействованных таблиц, восемь вспомогательных функций и операторская
роль присутствуют. Действующий `audit_action_check` проверен. Набор его
двадцати двух действий совпадает с исходным набором миграции. Объекты нового
периода в рабочей схеме ещё отсутствуют.

Профиль периода 1 существует, флаг включён, срок истёк. Профиль не закрыт.
В БД есть прежний аудит чтения и два действующих назначения. Для обоих
подтверждены совпадение владельца и текущего слота и активный статус сессии.

Сверенные структурные предпосылки новой миграции совпадают. SQL миграции
не выполнялся. Для выпуска ещё нужны резервная копия, выделенный staff
HTTPS-вход и отдельное решение об установке. Перед активацией надо заново
сверить оба текущих слота.
