## Восстановление

Закрытый `oracle-demo-api-gateway-source-20261119.bundle` хранится на Google Диске с доступом владельца. Запись о проверке скачанного SHA‑256 находится в [каталоге хранения](../../docs/storage/catalog.json) и [манифесте архива](../../docs/storage/oracle-demo-runtime-recovery-2026-11-19.json). В манифесте зафиксированы имя архива, его SHA‑256, коммит, дерево и ветка. После сверки SHA‑256 восстановить ветку в новый каталог и проверить исходники:

```sh
shasum -a 256 oracle-demo-api-gateway-source-20261119.bundle
git clone -b oracle-demo-api-gateway-20261119 ./oracle-demo-api-gateway-source-20261119.bundle oracle-demo-source
cd oracle-demo-source
git rev-parse HEAD
git fsck --strict
shasum -a 256 -c SHA256SUMS
```

Коммит архива — самостоятельный снимок подключённых исходников. Поле `comparison_main` в манифесте указывает контрольную версию открытого репозитория. Для сборки полной среды отдельно понадобятся слои Docker-образов, зависимости среды, совместимая база и разрешённые настройки. Данные БД, секреты, настройки закрытых подключений, установленные зависимости и раздаваемые сборки клиентского приложения в архив исходников не входят.
