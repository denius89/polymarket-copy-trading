# Перезапуск закрытого демо Tokor

Временный сборщик закрывал наблюдение при обычной остановке. Поэтому непосредственный перезапуск возвращал `Personal stream is not observing`, а управляющий процесс удалял временную базу. Патч добавляет отдельную процедуру передачи процесса для закрытого режима с фиксированным сроком.

На закрытом Oracle контрольная служба запустила два экземпляра последовательно в одной демо-сессии `1c6d9f24-0f84-4a13-82f2-e712ff6919cf`. Первый при плановой остановке дождался завершения записи, перечитал сохранённую отметку и сообщил блок `97868672` с хешем. Новый экземпляр прочитал тот же блок и хеш из той же сессии. Начальная отметка отдельного испытания была `97868670`.

Для контрольной службы системный перезапуск отправляет `SIGUSR1`, а оба запуска получают одинаковый абсолютный срок через `--closed-handover-until` и одинаковый профиль из закрытой базы. Передача возможна только после завершения задач записи, повторной проверки профиля и чтения курсора. `SIGTERM`, `SIGINT`, подтверждённая покупка и истечение срока завершают наблюдение штатно. Неопределённый результат по-прежнему отправляет сессию на сверку. Плановый перезапуск не расширяет срок и не меняет правила покупки.

В ночном прогоне Tokor покупок не было. Пять сигналов дали два таймаута ожидания книги, два случая неподтверждённой комиссии по нескольким уровням и один случай устаревшей книги. Ошибка `P0001` в записи диапазона остаётся отдельным инцидентом. Приёмка покупки в новом окне остаётся открытой.
