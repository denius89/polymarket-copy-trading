# Контрольная точка Base для закрытого Limitless

Сборщик завершает обработку нормализованных событий диапазона до передачи отметки фоновому сохранению. При чтении он сверяет хеш конца диапазона до и после запроса журналов, хеши блоков найденных событий и связь с предыдущим концом. Если ветвь изменилась, состояние на диске не продвигается. Сохранение выполняет отдельный поток и использует только полностью обработанную отметку, чей хеш совпал у двух источников финализированных заголовков. Файл привязан к сессии, роли которой принадлежат записи, к трейдеру и релизу. Запись заменяется атомарно. Повторное открытие сверяет хеш, а незавершённая часть диапазона остаётся доступной для повторного чтения.

Контрольная точка отражает обработку диапазона по действующим правилам допуска. Она не увеличивает время жизни сигнала и не меняет поведение при занятом резерве. Источники подтверждения покупок не поменялись. Для чтения заголовков контрольной точки используются Base и PublicNode.

На догоне используется диапазон до 128 блоков. У вершины остаётся перекрытие в 16 блоков. Если поставщик отклоняет большой диапазон, сборщик уменьшает его ширину с тем же началом. Проверки ветви и завершения диапазона сохраняются при обоих размерах.

## Комиссия Tokor

Проверенный одиночный матч стандарта 0,01 округлил комиссию вниз до пяти знаков. Контракт V2 получает от оператора одно значение комиссии покупателя на вызов. Наблюдаемое поведение контракта не определяет способ расчёта этого значения для нескольких ценовых уровней. В выборке из двадцати подтверждённых квитанций с двух рынков не нашлось случая, который различает округление отдельных исполнений, округление суммы и расчёт по средней цене. Для живого прогона оставлен действующий критерий одного ценового уровня. Основной /app не использовался.

Для различающего примера при коэффициенте 0,01 и объёмах 4,0028 доли по 0,50 и 12,7971 по 0,51 три модели дают 0,04197, 0,04198 и 0,04199 USD соответственно. Этот расчёт показывает, какая квитанция нужна для проверки, и не задаёт правило площадки.
