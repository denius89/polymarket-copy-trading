# Запуск нового финансового процесса из заявки демо

База собирает профиль из подтверждения C06, текущей сессии, её настроек и авторитетного назначения площадки. Профиль возвращается только для действующей аренды. Истёкший или чужой токен не раскрывает профиль. Служба приложения не может вызывать функцию. Существующее назначение площадки должно быть подготовлено отдельно.

Непривилегированный координатор может отправить на закрытый Unix-сокет только UUID заявки и её токен. Локальный посредник сверяет UID вызывающего процесса, адрес и релиз закрытой базы, актуальную аренду, защищённый каталог и SHA256 разрешённой программы. Он записывает неизменяемый профиль, затем запускает отдельную службу от непривилегированного системного пользователя. Имя службы определяется UUID заявки. Значения заявки не используются как имя команды, аргументы оболочки или права подключения к PostgreSQL.

Служба сообщает готовность протоколом systemd notify после собственной проверки подключения. Посредник сверяет фактический процесс и действующую аренду перед подтверждением. При повторе он возвращает тот же работающий экземпляр. Если результат передачи команды systemd неизвестен, посредник перепроверяет точную службу. При утрате разрешения он останавливает только запущенную по этой заявке службу. Время работы ограничено окном сессии и лимитом пакета. Автоперезапуск у такой временной службы не включён.

## Сверка на Oracle

Во временных базах проверены две новые сессии Polymarket и две Limitless. Для каждого C06 подготовлен отдельный профиль. Контрольные процессы подключились под своими ролями, сообщили готовность и получили отдельные экземпляры systemd. После имитации сбоя между запуском и записью результата повторная аренда приняла прежний экземпляр той же заявки. Чужой токен не возвращал профиль. Штатные финансовые функции обработали архивные сигналы с одной записью, позицией и списанием на сессию. Повтор не изменил баланс. Отдельная проверка смоделировала таймаут команды systemd при уже созданной службе и потерю разрешения в этот момент.

На постоянной закрытой копии установлен API профиля. Две прежние активации сохранены. Новый посредник проверен с контрольными программами. Для работы с живыми сигналами требуется подключить к нему релизные точки входа Polymarket и Limitless, поддерживающие новый профиль и сигнал готовности. Основной /app не участвовал.
