# Подключение подтверждённого демо к очереди покупок

Наблюдатель закрытой базы читает штатное подтверждение демо C06. Событие и квитанция связывают подписку с текущей сессией, редакцией трейдера и кошельком. После появления подтверждённого назначения площадки наблюдатель сам регистрирует его в очереди. При отложенном назначении подписка ожидает следующего опроса. Если привязка устарела, наблюдатель восстанавливает её по авторитетному назначению площадки. Подтверждение задания сверяет активную сессию и роль площадки. У наблюдателя нет прав вызывать покупку, выдавать роли, менять баланс или переписывать историю.

При подготовке закрытой базы используются схема очереди и миграция квитанций из `tools/demo-signal-delivery`, затем `closed-demo-start-observer.sql` и `closed-demo-writer-binding.sql`. Оператор выдаёт отдельной роли наблюдателя только использование схемы и запуск `demo_delivery.consume_ready_demo_sessions()`. Наблюдатель запускается с `--with-financial-bindings`. Если пакет миграции ещё не установлен, прежний режим поддерживает только регистрацию подписки.

## Проверка 23 ноября 2026 года

Во временных базах Oracle на каждой площадке открыты две синтетические сессии через штатные операции приложения. Независимый процесс связал подписки со штатными назначениями площадки. Для Limitless назначение появилось после подписки. После перезапуска наблюдателя квитанции, привязки и дата активации остались прежними. PostgreSQL продолжал работать.

Один архивный сигнал на площадку создал по одной покупке и позиции в каждой из двух сессий. Финансовые обработчики выполнили штатные операции, а сверка использовала данные, доступные владельцу. На Polymarket с балансов 200 и 250 USD списано по 10 USD. На Limitless списано по 9,999997 USD. Повторная доставка осталась с теми же исполнениями и балансами.

На постоянной закрытой копии после включения настроены обе существующие подписки. Это подтверждает автоматическую регистрацию уже выданных назначений. Выдача роли и запуск финансового процесса для новой сессии пока требуют отдельной настройки площадки. Основной /app в этой проверке не участвовал.
