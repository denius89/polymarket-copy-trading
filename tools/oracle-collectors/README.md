## Как воспроизвести архивы исходников

Выполнить из корня чистой копии на зафиксированном коммите. Нужен Python 3.10+ и стандартная библиотека. Команда только читает исходники и упаковывает их, без запуска сборщиков.

```sh
python3 tools/oracle-collectors/package_sources.py tradecraft --output /tmp/tradecraft-sources.tar.gz
python3 tools/oracle-collectors/package_sources.py breakthebank --output /tmp/breakthebank-sources.tar.gz
python3 tools/oracle-collectors/package_sources.py polymarket-v2 \
  --oracle-origin-file "${CCT_ORACLE_ORIGIN_FILE}" \
  --output /tmp/polymarket-v2-sources.tar.gz
```

`CCT_ORACLE_ORIGIN_FILE` — путь к закрытому локальному текстовому файлу с исходным HTTPS-адресом из записи оператора. Без `--output` команда только сверяет файлы. Для Polymarket без адреса она сверяет 33 оригинала и два шаблона.

## Граница воспроизводимости

Результат — архивы сверенных исходников. Они не воспроизводят исторические архивы установки целиком. Для полного выпуска нужно отдельно связать настройки окружения, версии Python и драйвера PostgreSQL, схему БД, служебные файлы упаковки и остальные зависимости с записью выпуска. Рабочие настройки, учётные данные, данные БД и текущие образы Docker в этот снимок не входят. См. [порядок выпуска и восстановления](../../docs/technical/first-session/v00-oci/workflow.md).
