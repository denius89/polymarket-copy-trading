# Изолированный стенд staff Q06

Две синтетические демо-сессии для проверки карточек с позицией и без неё. Клиентский Q04 и staff Q06 читают один финансовый снимок. Временное служебное назначение разрешает чтение через существующие правила пилота. PostgreSQL хранит аудит просмотра. Компоненты собираются из Git без внешних архивов и устанавливаются только в одноразовую локальную среду.

Сборка использует [проверяемую основу Git-демо](../v00-polygon-gateway/README.md), UI из `3a4582f` и staff API из `69071e2`, а также SQL и API из локально проверенных компонентов `polygon-live-buy-compose-20261113` и `polygon-live-buy-runtime-20261113`. Изменённые части находятся в `kit/`. Используются образы Node и PostgreSQL по digest из основной сборки. Демо включает вымышленный источник, 20 долей по себестоимости 9,80 USD и временные ключи. Финансовый код фиксирует одно синтетическое исполнение. Соединений с площадками и Oracle в сценарии нет.

## Запуск на Apple Silicon

Нужны Git, Python 3.11+ и Lima 2.0+. На другом хосте можно использовать отдельную Linux ARM64 VM с Docker. У гостя должна быть собственная файловая система без подключений к проектным секретам. Команды из корня чистого Git checkout:

```bash
python3 tools/staff-q06-local/assemble.py HEAD /tmp/shadow-staff-q06
limactl start --tty=false --name=shadow-staff-q06 tools/staff-q06-local/lima.yaml
tar -C /tmp/shadow-staff-q06 -cf - . | limactl shell --tty=false shadow-staff-q06 \
  bash -ec 'mkdir -p /tmp/staff-kit && tar -xf - -C /tmp/staff-kit'
limactl shell --tty=false shadow-staff-q06 sudo bash /tmp/staff-kit/start.sh
```

Дождитесь `PILOT_PRIVATE_GATEWAY_READY`. Оставьте этот терминал открытым. Во втором терминале:

```bash
python3 tools/staff-q06-local/browser-relay.py -- limactl shell --tty=false \
  shadow-staff-q06 sudo -n python3 -B /tmp/staff-kit/relay-guest.py
```

Сначала откройте `http://127.0.0.1:52486/admin/__disabled` и убедитесь, что служебный вход недоступен. Затем откройте `http://127.0.0.1:52486/admin/` во встроенном браузере ChatGPT. Одноразовые вымышленные значения доступны на `/__local_permit` того же адреса. Откройте карточку «участник пилота 1». Ожидаются 290,10 USD доступно, 0,00 USD в резерве и одна позиция на 20 долей. Вернитесь к списку и откройте «участник пилота 2». Ожидаются 200,00 USD доступно и 0 позиций. После одного просмотра каждой карточки проверьте Q04, Q06, аудит и отказ обычному пользователю:

```bash
limactl shell --tty=false shadow-staff-q06 sudo python3 /tmp/staff-kit/probe.py
```

Проверка сравнивает точные финансовые поля, ID сессии и снимка с ответом Q06, прочитанным браузером. Она требует по одной записи просмотра с соответствующим снимком и HTTP 401 при запросе Q06 под обычным пользователем. После проверки остановите relay и удалите только созданную одноразовую VM:

```bash
limactl stop shadow-staff-q06
limactl delete shadow-staff-q06
```

Порты базы и API остаются в закрытой сети гостя. Браузерный relay слушает только локальный адрес. Для запуска повторного сценария соберите новую копию и используйте новую VM.

## Результат 20.11.2026

Из чистого Git-дерева `69bd017fccdb311aec202f1119705db09536d6d7` собраны React-приложение, PostgreSQL 17.11 и раздельные API. Во встроенном браузере открыта сессия `ef56ac5f-c750-4c69-999d-36df96520c81`. Админка показала 290,10 USD доступно, 0,00 USD в резерве и 20 долей с себестоимостью 9,80 USD. Q04 и Q06 дали одинаковый снимок `faedf6c4-5946-46da-80ab-9c0b917b56a3` версии 3. Сверены точные дроби, позиция и комиссия 0,10 USD.

Аудит `session_read` записан один раз под служебным входом с привязкой к тому же снимку. Его ID — `923356f2-6576-43d7-8bcc-25968a75f856`. Обычный пользователь получил 200 на своё чтение и 401 `AUTH_REQUIRED` на админское чтение без данных сессии. Проверка ограничена изолированным синтетическим стендом.
