# Облако при бюджете $0 · 18.10.2026

Владелец уточнил: сервера/аккаунта нет, бюджета нет. Рабочий бюджет считаем **$0**: платные ресурсы и переход на pay-as-you-go не разрешены. Подготовленный cloud package остаётся переносимым; облачный deployment не выполнен. Локальный пилот сохраняет прежние ограничения.

Проверены текущие первичные страницы18.10.2026:

| Вариант | Подтверждено документацией | Что не подтверждено для нашего запуска |
|---|---|---|
| [Northflank Sandbox](https://northflank.com/pricing) | Два бесплатных сервиса, одна БД, два cron jobs; заявлен always-on compute без сна | Доступность free-tier конкретному новому аккаунту, необходимость проверки карты, достаточность CPU/RAM/traffic, бесплатное сохраняемое хранилище raw archives и восстановление. Привилегии платного sandbox продукта нельзя приписать бесплатному тарифу |
| [Render Free](https://render.com/docs/free) | Web service засыпает после15мин без входящего трафика; локальные файлы теряются при restart/redeploy/sleep; free disk недоступен | Не подходит для нынешнего фонового сборщика с локальным сохраняемым архивом без дополнительной архитектуры/хранилища. Искусственные keepalive ради обхода сна не предлагаются |
| [Oracle Always Free](https://docs.oracle.com/en-us/iaas/Content/FreeTier/freetier_topic-Always_Free_Resources.htm) | Есть compute/storage в free quotas; простаивающие compute могут изыматься по правилам провайдера | Доступность ресурсов/регистрация/условия проверки карты и пригодность региона для API. Нельзя обещать постоянный сервер по названию Always Free |

Первым кандидатом для проверки является Northflank Sandbox, а не уже выбранный/готовый deployment. Бесплатный compute не доказывает бесплатное надёжное хранение: raw archive должен пережить замену процесса и быть восстановимым. Текущему пакету может потребоваться отдельный storage adapter; выдавать файл в ephemeral container за сохранённые данные нельзя.

Для продолжения нужен бесплатный аккаунт владельца и доступ к его фактическим квотам. До запуска проверить тариф/платёжные условия, постоянное хранение, ограничение расходов и API smoke. Если бесплатная конфигурация не проходит, не создавать платную замену автоматически и не обещать непрерывную30дневную панель. Локальный collector останавливается только после проверенного переключения либо по своим сроку/байтовому пределу.
