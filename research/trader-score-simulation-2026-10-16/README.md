# Синтетическая проверка модели скора — 16.10.2026

**Новый эксперимент:** [сравнение CE и LCB с упрощённым исполнением и отдельным будущим](CE_REVIEW.md). 768 адресов, 6 миров, 4608 будущих испытаний; преимущество CE не подтверждено, gates сузили выбор до одного типа. Ниже — исторический v1, который моделирует только формулы.

Статус: выполнен исследовательский эксперимент над формулами. **Это не исторический бэктест реальных кошельков, не симулятор исполнения и не калибровка production-рейтинга.** В просмотренных файлах репозитория не найден пригодный полный набор истории исполнения и стаканов; найденные fixtures относятся к дизайну.

## Воспроизведение

Из корня репозитория: `python3 research/trader-score-simulation-2026-10-16/run.py`. Только стандартная библиотека Python, фиксированный seed 20261016.

Артефакты: [код эксперимента](run.py), [700 прогонов CSV](runs.csv), [параметры и агрегаты JSON](summary.json). Методика: [черновик модели](../../docs/TRADER_SCORE_MODEL_DRAFT.md).

7 синтетических профилей × 100 прогонов, 90 дневных наблюдений. Для каждого пригодного прогона — 160 круговых блочных bootstrap-выборок длиной блока 7; односторонний нижний квантиль 10%. Это условный исследовательский уровень, не подтверждённая вероятность успеха.

Формулы компонентов и веса — из черновика. Исключительно тестовые параметры: T_ref=90 дней, N_ref=60 групп, d_ref=10%, r_ref=0.1% в день; coverage=1. Они не оценены по реальной выборке, не утверждены, не являются порогами безопасности.

Дневная доходность после условных расходов и доля исполнения генерируются как отдельные входы. Нет заявок, книги, реальных комиссий, бюджетов, резервов и исполнения пропорциональной продажи. Поэтому даже результат неликвидного профиля здесь не означает достижимый результат копирования. Эксперимент проверяет арифметику и поведение функции при заданных метриках.

## Результат

Медианы 100 прогонов; доходность — синтетическое изменение капитала за 90 дней, а не прогноз.

| Устойчивый положительный | 84.5 | +9.07% | 1.26% | 48.0 |
| Устойчивый убыточный | 67.5 | −5.40% | 5.55% | 0 |

*Доходность здесь отдельно сгенерирована как вход; она не рассчитана из низкой исполнимости и не отражает доход копировщика в неликвидном рынке.

Для последнего профиля исследовательский harness требует минимум 20 независимых групп для bootstrap и отказывается от расчёта при одной группе. **Это дополнительная экспериментальная предпосылка, а не принятое продуктовое правило:** действующий допуск говорит о 20 подходящих действиях, а не о 20 независимых группах. Число групп и его последствия ещё нужно согласовать. Этот сценарий проверяет отказ при зависимости, не строит модель коррелированных fills.

## Что обнаружено

1. Сумма с весами 30/25/25/20 может дать высокий балл без подтверждённого положительного результата: технические компоненты занимают 80 баллов. Один случайный выигрыш получает около 74 при P=0.
2. В 4 из 100 убыточных прогонов балл превышает 70. Число 70 выбрано только для диагностики; это не действующий и не предлагаемый автоматически порог допуска.
3. Профиль без преимущества бывает положительным в 52 из 100 прогонов. Положительный итог сам по себе не подтверждает преимущество.
4. Низкая исполнимость уменьшает технический компонент. Большой хвостовой убыток уменьшает оценку просадки. Это проверка чувствительности, не доказательство качества отбора.
5. Небольшое число независимых событий не позволяет трактовать частые fills как надёжную статистику.
6. Ниже нуля за период не означает автоматически отсутствие долгосрочного преимущества; выше нуля — его наличие. Для оценки нужны независимый будущий период и подходящая методика неопределённости.

## Рекомендация для обсуждения

Сохранить действующие веса до решения владельца. Разделить:
- рассчитанное качество данных/копирования;
- достаточность экономического основания для рекомендательной подборки;
- персональную симуляцию бюджета и лимитов пользователя.

Не размещать оценку «74 — хороший трейдер» без объяснения, что устойчивость не подтверждена. При P=0 рекомендательный статус не должен автоматически становиться положительным по одному суммарному числу. Конкретное правило — предложение, не принятое ограничение.

Следующий содержательный эксперимент — на реальных сигналах/позициях с подтверждёнными временем наблюдения и глубиной книги, либо forward paper-сбор. Сначала проверить доступность этих данных и согласовать паспорт сравнения. Подбор коэффициентов по этим же синтетическим примерам не будет доказательством пригодности модели.
