# Local references

Эта папка предназначена для локальных исходных материалов, которые помогают восстановить контекст, но не должны автоматически публиковаться.

Файлы здесь, кроме этого README, игнорируются Git. Решения, необходимые команде, нужно переносить в `docs/PROJECT_STATE.md`, тематический документ или ADR без персональных данных и закрытой переписки.
