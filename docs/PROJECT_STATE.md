## Решения и гипотезы

- Подтверждено основателем: сначала идея и архитектура, затем решение о разработке.
- География исследования: Сомали, Бангладеш, Марокко, Египет и Таиланд. По сообщению основателя, в первых четырёх есть большой опыт прошлого проекта и контакты; в Таиланде есть контакты. Страна запуска ещё не выбрана.
- Контакты — агенты MobCash; в нашем продукте их роль реферальная. По прямому уточнению основателя приём платежей не рассматривается; собственная касса и интеграция MobCash не планируются.
- Ориентир входа: просто и прозрачно, как у Polyfox. Пользователь самостоятельно управляет пополнением своего кошелька. Рекомендована встроенная пользовательская модель с отдельным торговым signer; внешний кошелёк — альтернатива. Privy выбран первым кандидатом будущего spike, Dynamic — контрольным; интеграционная совместимость ещё не подтверждена.
- Основатель требует заложить реферальную программу и максимально простой вход клиентов; требования и открытые вопросы — в docs/08_agent_distribution_and_onboarding.md.
- Сомали и Таиланд имеют ограничения Polymarket, не допускающие новый вход в позиции; остальные страны и Limitless ещё не прошли проверку допустимости.
- По оценке основателя клиенты в основном пользуются агентами; предполагаемый первый торговый бюджет $10–200. Самостоятельный криптоопыт и готовность платить за копирование не подтверждены.
- По сообщению основателя агенты смогут организовать продажу USDT в популярных сетях и обратный обмен на локальные деньги. Для проверки выбран Tron USDT через Polymarket Bridge; на 24.09.2026 текущий минимум API — $2. Комиссия агента и отправки не получена; это внешняя услуга, наш приём платежей исключён.
- Уточнено основателем: партнёрам 25–35% от полученной сервисной комиссии по их клиентам, без вычета операционных расходов. Предусмотреть индивидуальные VIP-условия. Формула и пример сохранены в документе 08.
- Основатель может организовать интервью с 2–3 агентами; сценарий подготовлен в документе 08, беседы ещё не проведены.
- Исследуются две аудитории: действующие копировщики и клиенты агентского канала. Прежняя рекомендация ограничиться опытными копировщиками пересматривается; клиентам агентского канала требуется помощь с самостоятельным входом.
- Рекомендация интерфейса: независимый mobile web, опционально PWA; обычный бот позднее для уведомлений.
- Telegram Mini App исключён из рекомендуемой торговой архитектуры из-за платформенных ограничений; это не решение о готовности самого web-продукта.
- Polymarket — первый кандидат; Limitless — альтернативная площадка для сравнения; Polyfox — продуктовый конкурент.
- Модель торговых разрешений и точные правила исполнения требуют завершения спецификации.
- Реальные сделки не разрешены; автоматизация выключена по умолчанию.

## Новые продуктовые решения

- Собственный понятный рейтинг трейдеров плюс ручное добавление адреса.
- Первая версия: копирование и управление скопированными позициями, без самостоятельного открытия произвольных сделок.
- Базовая сервисная комиссия 1%, настраиваемая; ограничения механизма площадки учитываются отдельно.
- Партнёрская лестница 25–35% от комиссии и VIP-условия. Лестница накопительная за всё время с сохранением достигнутого уровня, без ежемесячного сброса. По требованию основателя параметры лестницы и VIP-условия должны настраиваться; целевой интерфейс — админ-панель с версиями и сохранением достигнутых прав. Численные пороги пока предварительные; правила — в docs/09_product_decisions_and_partner_tiers.md.

## Результат текущего блока

- Сравнены публичная стоимость и восстановление Privy, Dynamic и Turnkey. Для будущего spike первым выбран Privy, контрольным — Dynamic; выбор не окончательный.
- Проверен текущий публичный маршрут Tron USDT через Polymarket Bridge. Минимум API — $2; read-only котировки для 10/50/200 USDT дали разницу примерно $0,05/$0,11/$0,32 до комиссии агента и отправки.
- API отдельно показал около $1,68 `gasUsd`; его фактическое списание и продолжение USDC.e → pUSD требуют тестовой транзакции. Базовой суммой будущей проверки предложено $50, а $10 не считается подтверждённым коммерческим минимумом.
- Экономическая модель дополнена стоимостью wallet-провайдеров и ограничением: основной кошелёк не должен тарифицируемо подписывать каждую копию, для этого нужен отдельный Polymarket session key.
- Код приложения не создавался и реальные сделки не выполнялись.

## Следующие результаты

1. Согласованная формулировка сегмента, проблемы и ценности; критерии выбора стран.
2. Новая экономическая модель с расходами, удержанием и проверкой цены.
3. Архитектура с границами доверия, моделью доступа и таблицей торговых состояний.
4. Согласованные документы 01–03 и обновлённая презентация.

## Что нельзя считать готовым

Спрос, рынок запуска, реализуемость всех разрешений, прибыльность копирования и бизнес-модели. Отдельные возможности подтверждены документацией, но интеграционный тест не выполнялся.
