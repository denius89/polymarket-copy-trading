# Текущее состояние проекта

Обновлено: 23 сентября 2026 года.

## Текущий этап

Этап 1 — UX и пользовательские сценарии.

## Что уже готово

- отдельный локальный Git-репозиторий и безопасный каркас проекта;
- UX-аудит Polyfox и платформенное сравнение Polymarket с Limitless;
- основной user flow, аварийные состояния и требования к пяти экранам;
- продуктовая идея и экономическая модель;
- техническая концепция;
- дорожная карта;
- исследовательский контур Limitless;
- анализ перспектив;
- презентация идеи;
- регламент разработки через vibe coding.

## Рабочие решения

- первая площадка: Polymarket;
- Limitless: альтернативная площадка уровня Polymarket; исследование сейчас, полноценная интеграция после подтверждения MVP;
- Polyfox: прямой продуктовый аналог copy-trading сервиса;
- интерфейс первого прототипа: web app;
- язык основного приложения: TypeScript;
- режим до реальных сделок: mock data, записанные события и paper trading;
- реальное исполнение по умолчанию выключено;
- Polyfox рассматривается как конкурент с комиссией 1% за каждую покупку и продажу.

## Следующий результат

Wireframes и интерактивный прототип пяти экранов MVP на mock data.

## Следующие три задачи

1. Зафиксировать информационную архитектуру и общую навигацию.
2. Подготовить wireframes: портфель, позиции, трейдеры, журнал и риск.
3. Собрать интерактивный прототип с основным сценарием и двумя аварийными состояниями.

## Открытые решения основателя

- какие 3–5 адресов Polymarket использовать в техническом эксперименте;
- какой максимальный капитал допустим для будущего личного live-теста;
- кого пригласить на проверку понятности прототипа.

Эти решения не блокируют создание прототипа. Адреса лидеров потребуются перед техническим экспериментом, а лимит капитала — только перед live-тестом.

## Блокеры

Блокеров для wireframes нет. Дополнительные скриншоты авторизованного Polyfox улучшат вторую итерацию аудита, но не блокируют прототип.
