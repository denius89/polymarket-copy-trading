# Бизнес-логика первого демо-копирования — действующая сводка

Исходный документ: 05.10.2026. Обновлено: 27.10.2026, по принятым ADR-0010–0061. Это точка входа в согласованные правила; нормативные детали и область принятия находятся в связанных ADR. Сводка не разрешает реальные сделки и не объявляет прототип работающим сервером.

## 1. Что делает продукт в первом выпуске

Одна виртуальная paper-сессия пользователя с выбранным трейдером и площадкой. Копируются новые подтверждённые действия, прошедшие все условия; Polymarket и Limitless не подменяют друг друга. Каталог и профиль доступны гостю; запуск и сохранение требуют входа по email. Telegram необязателен. Первый вход, черновик и продолжение существующей сессии — [ADR-0048](decisions/0048_unified_registration_and_first_entry.md).

Сервисная комиссия Paper Alpha — 0%. Это не доказательство нулевых расходов площадки. Реальные счета, партнёрские выплаты и собственные средства Shadow отделены от демо и имеют собственные разрешения/условия допуска.

## 2. Понятия, которые нельзя смешивать

| Понятие | Принятый смысл |
| --- | --- |
| Бюджет B | Настроенная сумма виртуального финансирования сессии; не её текущая рыночная стоимость |
| Размер копии | Фиксированная сумма F либо доля q конкретного подтверждённого BUY трейдера |
| Позиционный лимит P | B × p/100; учитывает части и ещё возможное исполнение, не заменяет размер копии |
| Дневной лимит D | B × d/100; новые увеличивающие риск покупки и незавершённые резервы |
| Свободные деньги | Подтверждённые доступные средства после всех денежных резервов, включая возможные расходы |
| Резерв | Ещё возможное обязательство, а не уже понесённый расход; одна покупка видна нескольким квотам без повторного списания |
| Части позиции | Копируемые и ручные/отсоединённые количества и стоимость учитываются раздельно |
| Результат | Эффект торговли после доказанных расходов; ввод/изъятие B не прибыль и не убыток |
| Неизвестный итог | Нет подтверждённого окончательного результата; не отказ, не ноль и не разрешение повторить |

## 3. Путь пользователя

Ознакомление → выбор трейдера → fixed или % → проверка → email при необходимости → запуск либо продолжение имеющейся сессии. Подготовленный пример с историей не запускает новую сессию. Вход, язык, просмотр профиля и помощь не снимают паузу и ограничения.

Пользователь видит состояния, причины пропусков, резерв, открытые части и историю. Отчёт за период может существовать раньше окончательного завершения всей сессии.

## 4. Как система принимает решение

Уникальное подтверждённое действие → размер по сохранённой версии настроек → действующие запреты, возраст сигнала и пригодные рыночные данные → полная проверка всех текущих квот и денежного резерва → неделимое решение с резервом → исполнение/частичное исполнение → сверка.

- Повторная новая покупка того же исхода разрешена при достаточных лимитах; повтор доставки одного события не создаёт новую покупку. [0015](decisions/0015_repeat_buy_signals_in_paper_copy.md).
- Если полная желаемая покупка не помещается, пропуск целиком. Нет уменьшения до остатка или повышения до минимума. Частичное исполнение возможно после полного допуска. [0018](decisions/0018_skip_buy_when_full_copy_exceeds_limits.md), [0025](decisions/0025_skip_buy_when_verified_liquidity_cannot_cover_full_copy.md).
- Конкурирующие события идут по порядку поступления. [0023](decisions/0023_process_competing_paper_buy_signals_in_arrival_order.md).
- Не хватает свежих рыночных данных — показываем известное действие и пробел без выдуманного исполнения. [0024](decisions/0024_show_missing_market_data_without_simulated_fill.md).
- Подтверждённая часть сохраняется; резерв остатка удерживается до окончательной отмены/исполнения. Поздние подтверждения не удваивают покупку. [0026](decisions/0026_keep_confirmed_partial_fill_and_cancel_remainder.md), [0027](decisions/0027_reconcile_fills_while_remainder_cancellation_is_pending.md).

## 5. Уже согласованные правила управления

| Ситуация | Последствие |
| --- | --- |
| Пауза | Новые BUY/увеличения запрещены; сокращения и выходы продолжаются по принятым правилам |
| Отключить и оставить | Копирование прекращается; остатки BUY запрашиваются к отмене, позиции остаются ручными; новая сессия ещё недоступна |
| Закрыть и отключить | Запрос закрытия, не готовое закрытие. Частичный/неизвестный результат не разрешает финал |
| Ручная продажа | Пропорциональная атрибуция выбранной группы частей; автоматический повторный вход по закрытому рынку требует явного разрешения |
| Новые настройки | Старый размер сигнала не переписывается; до допуска проверяются текущие лимиты и все прежние резервы. Уже допущенные намерения не пересчитываются |
| Изменение B | Виртуальное движение на разницу B_new − B_old. Изъятие только из свободных денег, иначе отклоняется вся правка; нет принудительной продажи/освобождения резерва |
| Снижение B/p/d | Может сохранить старый F с предупреждением, хотя новые BUY по нему не проходят. Новый ввод F проверяется заново; молчаливого уменьшения нет |
| Отчёт после изменения B | Неисчезающая отметка «Баланс изменён», движение финансирования отделено от торгового результата |
| Граница 14 дней | Период оценки закрыт; новые BUY запрещены, остатки BUY запрошены к отмене. Сокращения копируемой части продолжаются до явного отключения |
| Недостаточно действий к границе | «Недостаточно данных» без оценки качества; последующие закрытия не продлевают оценочный период |
| Новая сессия/reset | Только после отключения, закрытия всех частей и окончательной сверки всех операций; история сохраняется, новая paper-среда стартует с $200 |
| Малый остаток | Не списывается и не превращается в ноль. Блокирует финал/reset до подтверждённого закрытия/погашения |

Детали: [0049](decisions/0049_position_parts_cost_and_manual_sales.md), [0050](decisions/0050_shadow_assessment_boundary_and_exit_only_tail.md), [0051](decisions/0051_strict_session_completion_and_paper_reset.md), [0052](decisions/0052_late_fills_follow_ownership_and_exit_target.md), [0053](decisions/0053_serialize_sells_and_preserve_exit_targets.md), [0054](decisions/0054_round_down_without_limit_bypass_and_keep_dust.md), [0055](decisions/0055_exact_rational_position_attribution.md), [0056](decisions/0056_active_session_budget_flows_and_settings_revisions.md).

## 7. Проверка и оставшиеся решения

Принятые правила не требуют повторного выбора. Новые продуктовые варианты отделяются от технической реализации. До включения зависимой функции закрываются её гейты и проверяются UI, модель, сервер и данные площадки каждый в своём объёме.

Примеры сохранения обязательств:
- $20 неизвестного BUY занимает один денежный резерв и соответствующие квоты позиции/дня; полночь не освобождает его.
- После $8 подтверждённого исполнения и $12 возможного остатка заняты $8+$12; отмена освобождает только окончательно подтверждённые $12.
- Поздние ещё $4 дают $12 исполнено/$8 остаток; свободные деньги не растут от факта исполнения.
- Подтверждённая оценка расходов $0,20 дополнительно занимает денежный бюджет, не номинал P/D. Это иллюстрация, не тариф площадки.
- Уменьшение B200→150 из свободных $60 изымает $50, оставляет $10; позиции и резерв сохраняются. B200→100 требует $100 и при свободных $60 отклоняется целиком.
