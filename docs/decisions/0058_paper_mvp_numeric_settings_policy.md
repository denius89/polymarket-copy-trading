# ADR-0058: Числовые параметры настроек paper MVP

Дата: 19.10.2026. Статус: **принято владельцем для paper MVP**.

## Контекст и решение

Владелец явно подтвердил предложенные диапазоны/шаги документа 130 и отдельно выбрал минимум $5 только для фиксированной копии. Нормативная детализация — [130](../130_paper_copy_settings_numeric_policy_proposal_2026-10-18.md), идентификатор версии — `paper-mvp-settings-v1`, [JSON](../policies/paper-mvp-settings-v1.json).

- B=$100–$1 000, шаг $10, старт $200.
- Новый F=$5–floorUSD(min(P,D)), шаг $1, старт $20. P=B×p/100, D=B×d/100 точные; абсолютный максимум F=$200. Старт должен быть валиден для выбранных B/p/d, не автоматически исправляться.
- q=1–20% отдельного подтверждённого BUY трейдера, шаг 0,5 п.п., старт 3%. Минимум $5 к результату процентного расчёта не применяется; проверяется реальный минимум инструмента без повышения суммы.
- p=5–20% бюджета, шаг 1 п.п., старт 10%; d=10–30%, шаг 1 п.п., старт 15%. p>d допустимо.
- Возраст сигнала 30 секунд, без пользовательского редактирования. Свежесть книги не определяется этим числом.
- Снижение B/p/d в активной сессии сохраняет неизменённый активный F с предупреждением, даже если он больше новой границы. Новый выбор/смена на fixed проверяются заново. Это сохраняет ADR-0056; ввод не округляется молча.

## Последствия и проверка

Это продуктовые границы формы, не достаточные условия допуска. ADR-0054/0055 задают внешнее округление/точную внутреннюю арифметику, ADR-0056 — версии и движения B, ADR-0057 — все применимые квоты и причины. Старые обязательства не переписываются, вывод денег проверяется по свободным деньгам, BUY не уменьшается до остатка.

[QA](../qa/numeric-policy-2026-10-19/README.md) проверяет reference-модель и сочетания B/p/d; не runtime/UI/API. Числовые параметры формы закрыты как решение владельца. Профили рынка/расходов, достоверное время, partial SELL, отчёт и реализация сохраняют отдельные gates. Прочие предложения 129, системные/global потолки, Figma и live не принимаются этим ADR.
