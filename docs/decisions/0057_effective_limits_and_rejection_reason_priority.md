# ADR-0057: Совмещение лимитов и главная причина отказа · BL-08

Дата: 19.10.2026. Статус: **принято владельцем для paper MVP**.

## Контекст

Предложения 129/130 и [ADR-0056](0056_active_session_budget_flows_and_settings_revisions.md) оставляли BL-08 открытым. Владелец явно выбрал «все ограничения одновременно» и порядок причин от блокировки/сверки до денег/экспозиции/дня. Нормативная детализация — [контракт 135](../135_effective_limits_and_rejection_reasons_2026-10-19.md).

## Решение

- Все применимые обязательные правила действуют одновременно. Индивидуальный/сессионный выбор может быть строже системного, но не отменить его. Проверенно отсутствующий optional override наследует правила; недоступная обязательная policy/counter блокирует новый допуск.
- Для одной области квоты с одинаковыми единицами/периодом эффективный максимум — минимум применимых максимумов, использование/резерв считаются один раз. У разных областей отдельные cap/used/reserve/headroom и проверки contribution; min сырых потолков с разной агрегацией запрещён. Базы процентов/валюты/счета не смешиваются. Расходы уменьшают свободные деньги, не номинал P/D.
- Сохраняются выбранные и эффективные значения, все источники, в том числе равные binding sources, snapshots/версии правил и счётчиков. Проверка полного BUY и резерв неделимы по ADR-0023/0056. История/дубликаты не пересчитываются по новым потолкам, skip не догоняется.
- Главная причина выбирается устойчиво: режим/блокировка/сверка → контекст/обязательная policy → давность сигнала → данные рынка/минимум/ликвидность/расходы → свободные деньги → позиция/общая экспозиция → дневной лимит → иной уже принятый тип. Точный каталог/разрешение равенства — раздел 5 контракта 135. Это порядок объяснения, не отмена остальных ограничений.
- В деталях остаются все фактически доказанные препятствия; неизвестные, непроверенные и неприменимые условия имеют отдельные статусы. Не выдумывать лимит/нулевой остаток по отсутствующим данным. Unknown созданной операции не становится новым skip/failed или разрешением resend. Несколько причин — один вердикт одного действия.
- BUY-лимиты не блокируют SELL сами по себе; отдельные обязательные системные запреты сохраняются. Полный технический режим ADR-0045 не допускает новых отправок и из сверки. 135/0057 не вводят автоматическую ликвидацию или новый override UI.

## Причины, проверка и границы

Модель исключает обход общего остатка через менее занятую локальную квоту, двойное вычитание резерва за каждый источник и случайный выбор первой причины из массива правил. [QA-пакет](../qa/effective-limits-reasons-2026-10-19/README.md) подтверждает ограниченные свойства reference-модели, не production-полноту policy/API/конкуренцию.

BL-08 закрыт как выбор способа совмещения/объяснения для этого среза. Не приняты целиком числовая политика 130, новые размеры системных/global/individual лимитов, рекомендации по скору или новые права. Время/рынки/полная методика отчёта и физическая реализация сохраняют gates. Figma, приложение, live не изменялись.
