## Как добавить решение

1. Использовать следующий номер и короткое имя файла.
2. Указать дату и один из статусов: `предложено`, `принято`, `заменено`, `отклонено`.
3. Описать контекст, решение, причины, последствия и способ проверки.
4. Добавить строку в эту таблицу и ссылку из тематического документа.
5. Если новый ADR заменяет старый, обновить статус обоих документов без удаления истории.
