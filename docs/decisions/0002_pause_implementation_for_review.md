# ADR-0002: пересмотр перед разработкой

Дата: 24 сентября 2026. Статус: принято в части паузы, по прямому указанию основателя.

Разработка приложения, wireframes и интерактивного прототипа приостановлена. Сначала пересматриваются идея, экономика и архитектура. Tier‑3 — направление исследования, конкретные страны и сегмент пока не выбраны.

docs/07_strategy_architecture_review.md содержит текущие предложения и пробелы. Его рекомендации по интерфейсу и аудитории не считать утверждёнными основателем. ADR-0001 сохраняет разделение ролей Polyfox, Polymarket и Limitless; порядок интеграций остаётся предметом проверки осуществимости.

Возобновление разработки требует согласованных документов 01–03 и решения основателя. Существующая презентация не является актуальной утверждённой стратегией.
