# ADR-0008: Polymarket и Limitless входят в обязательный scope продукта

Дата: 25.09.2026. Статус: принято основателем.

## Контекст

Limitless выбран первым партнёрским integration spike благодаря прямой поддержке и Programmatic API. При этом Polymarket заметно известнее, имеет сильный пользовательский бренд и остаётся важным источником аудитории, ликвидности и лидеров. Рассматривать его как необязательный будущий адаптер не соответствует продуктовой стратегии.

## Решение

- Polymarket и Limitless являются обязательными execution-площадками целевого продукта.
- Общий copy engine, risk engine, virtual lot ledger, журнал и интерфейс с самого начала проектируются venue-neutral.
- Для каждой площадки создаётся отдельный adapter данных, авторизации, ордеров, комиссий, settlement и reconciliation.
- Paper-trading версия должна уметь моделировать обе площадки до разрешения публичного live-запуска.
- Live-доступ включается для каждой площадки отдельно после её GEO, trust, security, fee и execution gates.
- Limitless остаётся первым партнёрским spike; Polymarket Builder и Session Keys исследуются параллельно, а не откладываются до неопределённого будущего.
- Пользователь явно выбирает площадку. Автоматическое сопоставление и перенос сделки между похожими рынками разных площадок не входят в первую версию.

## Почему

- Polymarket снижает маркетинговый барьер благодаря известности.
- Limitless снижает интеграционный риск благодаря прямой поддержке и партнёрскому API.
- Две площадки уменьшают стратегическую зависимость проекта от одного API и одной GEO-политики.
- Поэтапное включение live execution сохраняет управляемость разработки и безопасности.

## Последствия

- «Второй необязательный адаптер» больше не является корректной формулировкой.
- Архитектура и данные обязаны сохранять `venue` во всех идентификаторах, событиях, ордерах, fills, лотах и комиссиях.
- Backtest, shadow copy и рейтинг показывают площадку и не объединяют статистику без явной нормализации.
- План содержит два параллельных трека доступа: Limitless Programmatic API и Polymarket Builder/Session Keys.
- ADR-0007 продолжает определять первый партнёрский spike Limitless, но его формулировка об опциональном втором адаптере заменена этим ADR.
