# ADR-0003: пользовательский кошелёк и отдельный торговый signer

Дата: 24.09.2026. Статус: предложено; связка не проверена интеграционно.

Для аудитории с первым бюджетом $10–200 рекомендуем встроенный пользовательский кошелёк; внешний кошелёк — альтернативный вход. Пользователь контролирует основной signer. Сервис получает отдельный торговый session signer для Polymarket Deposit Wallet с scope CLOB, без права вывода. Для первого будущего spike выбран Privy, Dynamic остаётся контрольным кандидатом; окончательный провайдер пока не утверждён.

Рабочий маршрут пополнения для проверки — внешний USDT в Tron через уникальный deposit address Polymarket. Текущий минимум Bridge API — $2; базовая сумма проверки — $50, а $10/$200 используются как точки чувствительности. Маршрут не утверждён для пользователей до сквозной проверки USDT → USDC.e → pUSD и учёта комиссии агента/отправки.

Зависимости: одобрение Builder-доступа к session-key management; проверка EIP-712 совместимости, владельца, восстановления и независимого доступа к средствам; стоимость обслуживания; сквозной путь пополнения. Beta и срок 180 дней требуют отдельной модели отзыва и статусов. Ограничения бюджета в нашем backend не выдаются за ограничения контракта.

Сравнение, пользовательский путь и критерии подтверждения — docs/02_technical_concept.md, раздел 9. Экономическая чувствительность — docs/01_product_and_economics.md. Решение не разрешает разработку MVP, покупку услуг или реальные сделки.
