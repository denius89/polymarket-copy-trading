# Выравнивание кнопок в мобильной поддержке

Дата: 04.10.2026. Область: связанные мобильные экраны поддержки RU/EN в Figma.

На экранах ошибки кода подписи «Попробовать снова» и «Изменить email» были прижаты к левому краю широких кнопок. Проверка соседних сценариев показала такое же выравнивание у других пар действий в поддержке и переходах из помощи.

Подписи 136 кнопок выровнены по центру: по 68 в каждой локали. Изменено только горизонтальное выравнивание текста; ширина, высота, цвета, тексты и переходы сохранены. Визуально проверены [ошибка кода RU](https://www.figma.com/design/lxPP2um7FvIbt02K8eeH4T?node-id=697-640), [ошибка кода EN](https://www.figma.com/design/lxPP2um7FvIbt02K8eeH4T?node-id=697-93) и [сценарий из помощи RU](https://www.figma.com/design/lxPP2um7FvIbt02K8eeH4T?node-id=714-398).
