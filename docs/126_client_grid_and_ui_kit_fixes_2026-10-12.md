## Передача в разработку

[Контракт сетки и ширины кнопок](../design/client-ui-kit/grid-and-button-width.json) теперь содержит ID page grid и фактические счётчики. Новый Client UI kit содержит самостоятельные native masters и переиспользует существующие Shared/Recovery masters. На текущих продуктовых экранах экземпляры новых native masters ещё не используются; это не повод массово заменять 4 522 экземпляра. При реализации связывать элементы с kit по смыслу и состоянию, а мигрировать Figma instances только после проверки визуального совпадения и prototype reactions в RU/EN. Текущую границу фиксирует [инструкция по kit](../design/client-ui-kit/USAGE.md).

## Открытые проверки

- Четыре desktop кнопки кошелька на [EN](https://www.figma.com/design/lxPP2um7FvIbt02K8eeH4T?node-id=951-17926) и [RU](https://www.figma.com/design/lxPP2um7FvIbt02K8eeH4T?node-id=905-9404) остаются 40×44 px. Локальная правка внутри экземпляра общего header не меняет ширину; изменение master затронуло бы остальные его использования. Требуется отдельная проверка влияния и увеличение кликабельной области до 44×44 без потери реакций.
- Полных экранных вариантов 320/360 и 1024/1280 нет; адаптивность, длинные строки и zoom 200% проверить в работающем интерфейсе до дизайн-приёмки.
- Ручной Present этой итерации не пройден: Computer Use для приложения Figma вернул `permissions are not granted`. Снимки Figma и структурная проверка реакций не заменяют ручной маршрутный тест.
- Клавиатура, фокус, screen reader и контраст на финальном рендере остаются проверками реализации.

Локально пройдены `npm run check` и `git diff --check`. Этот пакет закрывает перечисленные геометрические и текстовые дефекты, но не является полной приёмкой всех 613 фреймов или работающего приложения.
