# Порядок в клиентском UI kit — 12.10.2026

По скриншотам владельца приведена в порядок секция Controls на единой [странице Client UI kit](https://www.figma.com/design/lxPP2um7FvIbt02K8eeH4T?node-id=1976-2). Работа касается только клиентского набора: админка, продуктовые экраны, поведение и бизнес-правила не менялись.

| Проблема | Исправление в Figma |
| --- | --- |
| Два визуально одинаковых обзора переключателя | Дублирующий обзор `Shared/Switch` (`1978:667`) удалён только из review board. Мастер `Shared/Switch` (`987:93`) сохранён. [Клиентский обзор](https://www.figma.com/design/lxPP2um7FvIbt02K8eeH4T?node-id=1982-38469) перенесён на место старого: один видимый блок с шестью состояниями и подписью роли. |
| Непонятный порядок исходных вариантов | Нативный [`Client/Touch switch`](https://www.figma.com/design/lxPP2um7FvIbt02K8eeH4T?node-id=1982-38468) разложен в сетку 3×2: верхний ряд On (Default, Focus, Disabled), нижний Off (Default, Focus, Disabled). Component set и все шесть variant IDs сохранены. |
| «Голые» мастера без пояснений | Исходный [переключатель](https://www.figma.com/design/lxPP2um7FvIbt02K8eeH4T?node-id=2105-5928) и [кнопка-иконка](https://www.figma.com/design/lxPP2um7FvIbt02K8eeH4T?node-id=2105-5923) помещены в подписанные панели с порядком состояний и размерами. Их component set IDs остались `1982:38468` и `1978:794`; варианты и preview instances не отсоединялись. |

Визуально проверены обе панели исходников и оба обзорных блока. Структурно подтверждены четыре секции на одной странице, один видимый switch review, по шесть вариантов в обоих component sets и сохранённые связи примеров `1978:800 → 1978:770`, `1982:38474 → 1982:38444`. Размер Controls review board уменьшился с 5298 до 5066 px без пустого места после удаления дубля. Ручной Present не выполнялся: здесь менялась библиотечная выкладка, а не маршрут прототипа.

Для разработки: `Shared/Switch` — базовый переиспользуемый мастер; `Client/Touch switch` — клиентский вариант с областью 96×60 px. В интерфейсах использовать экземпляры с нужным состоянием, а не копировать геометрию из обзорных карточек. Кнопка-иконка имеет размер 44×44 px. Новые панели — документация источников, не отдельные компоненты и не продуктовые экраны.
