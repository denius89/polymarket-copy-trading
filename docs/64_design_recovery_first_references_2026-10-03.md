# Восстановление дизайна: первый результат

Дата: 03.10.2026. Статус: первые RU-эталоны для визуального согласования, не завершённая пересборка проекта.

## Что сохранилось

Удачные исходные экраны действительно остались в файле. Проверены, например, [главная ПК 205:386](https://www.figma.com/design/lxPP2um7FvIbt02K8eeH4T?node-id=205-386), [каталог ПК 205:4](https://www.figma.com/design/lxPP2um7FvIbt02K8eeH4T?node-id=205-4), [мобильная сессия 191:163](https://www.figma.com/design/lxPP2um7FvIbt02K8eeH4T?node-id=191-163). Их не следовало подменять универсальным техническим каркасом. Однако суммы и часть деталей в них устарели: вернуть стартовую ссылку недостаточно.

После уточнения пользователя дальнейшее создание самостоятельных копий остановлено. Следующий перенос должен обновлять выбранные исходные продуктовые экраны на месте, с сохранением IDs. Уже построенные контрольные композиции остаются одним ограниченным набором для сравнения, а не новой полной версией приложения.

## Что сделано

- На ПК восстановлены боковая навигация с активным пунктом, рабочие колонки главной и каталог из трёх колонок. На мобильном сохранены четыре нижних раздела.
- Переиспользованы шапки, основные кнопки, токены и Inter. Новые компоненты метрик, поиска, карточки трейдера и навигации ограничены этим контрольным набором; прежние общие masters глобально не менялись.
- Денежная сводка согласована с fixtures: доступно 180,38 $, резерв 5,79 $, в позициях 23,60 $, стоимость счёта 209,77 $, результат +9,77 $.
- Пять текущих позиций отображаются с разными состояниями, а не как пять открытых.
- По замечаниям агентов мобильную разбивку результата разделили на две пары значений, убрали повторную крупную сумму, исправили пробелы в названиях рынков. Предупреждение об неизвестном исходе заявки подняли выше карточки копирования, чтобы действие было видно в первом экране.
- Карточки трейдеров получили стрелку перехода. Недостаточная история обозначена явно; неизвестное значение не заменено нулём.
- Настроены панели фильтра и сортировки, положительный PnL, бюджет до 50 $, сброс, выдача по PnL с фактическим изменением порядка, поиск по предусмотренному примеру и вариант без совпадений. Исходный порядок подписан как исходный.
- Сохранены инициализация выбранного трейдера и переход в его деталь. Настройки ведут в существующий индивидуальный риск; неизвестная заявка сохраняет инициализацию конкретного объекта. Переходы в средства и уведомления исправлены на точные существующие назначения.

Поиск здесь ограничен демонстрационными вариантами. Произвольный ввод и запрос к API не реализованы. Фильтры пока демонстрируют отдельные подборки, а не полноценное пересечение всех условий. Эти ограничения нельзя выдавать за готовое поведение приложения.

## Порядок в файле

На четырёх пользовательских страницах переименованы 113 секций, чтобы различались:

1. **Сохранённые макеты** — ранее созданные продуктовые композиции и состояния.
2. **QA · Технический прототип данных** — универсальный каркас для проверки логики и fixtures.
3. **На согласование** — только первые контрольные композиции RU.

Это маркировка, не завершённая чистка всего файла. Исходные IDs, страницы, маршруты, Future/Proposed и архивы не удалены. Перенос технических экранов между страницами пока не выполнялся: сначала нужно проверить зависимости переходов. После выбора основы должен остаться один актуальный пользовательский путь; тестовые входы будут отделены от него.

## Проверка и ограничения

Три агента участвовали в подготовке; два независимо просмотрели четыре целых экрана. Их существенные замечания устранены. После исправлений повторно просмотрены композиции и сортированные состояния. Все проверенные тексты используют Inter; raster-слоёв внутри этих экранов нет. Каталоги содержат 24 карточки; на ПК сетка занимает 1152 px и восемь рядов, на мобильном — одну колонку. Вертикальная прокрутка и отдельная нижняя навигация настроены.

Проверен фактический порядок сортировки: первые результаты +13,70 / +12,33 / +10,96 / +9,59 / +6,85 $. Переходы и переменные проверены по структуре Figma. Полный живой clickthrough через Figma Present ещё предстоит; нельзя считать его выполненным только по записанным reactions.

Проверка арифметики fixtures прошла; `git diff --check` прошёл. Общий `npm run check` не прошёл из-за относительных ссылок внутри ранее скачанных внешних API-документов в `design/qa-2026-10-02/api-comparison/`. Эти материалы не изменялись в текущем дизайн-цикле. Общую проверку репозитория зелёной не объявляем.

Обновление проверки 2026-10-03: сырые внешние статьи и OpenAPI-схемы вынесены из области публикации репозитория в локальный исследовательский кэш. Содержание сохранено без изменений с проверкой SHA-256; исходный индекс скачивания не изменён. В репозитории оставлены [метаданные и ссылки на первоисточники](../design/qa-2026-10-02/api-comparison/README.md) и [манифест перемещения](../design/qa-2026-10-02/api-comparison/cache-relocation-manifest.json). После перемещения `npm run check` и `git diff --check` прошли. Это проверка структуры и ссылок репозитория; она не подтверждает сквозную проверку прототипа и не завершает отдельный анализ совместимости с API.

Свидетельства: [реестр объектов](../design/qa-2026-10-03/recovery-ledger.json), [структурный аудит](../design/qa-2026-10-03/recovery-audit.json). Аудит содержит исходный снимок и отдельную финальную проверку исправленного порядка сортировки. Скрипты — материалы итерации, не универсальная команда повторной сборки всего файла.

## Что дальше

Согласовать визуальное направление этих четырёх экранов с сохранёнными исходными композициями. Затем обновлять выбранную основу на месте: сначала главная/каталог и EN, потом средства/профиль, после этого остальные сценарии из [отчёта 63](63_design_regression_and_recovery_report_2026-10-02.md). Не создавать ещё один параллельный полный набор экранов.

Средства, профиль, вход, поддержка и остальные детали ещё не восстановлены. Переход из эталона в эти разделы открывает прежний дизайн. Frontend, API и реальные операции в этом цикле не выполнялись.
