Статус — собственный пилот / открытая регрессия с явным чтением навыка. Автор и grader совпадают, oracle видим: это не независимый holdout. Автоматический discovery не проверен; выигрыш качества без baseline не установлен. Далее нужны независимый исполнитель без ключа, новые контрольные задачи и отдельное наблюдение runtime выбора навыка в целевой рабочей папке. Пока вывод относится только к этому self-pilot.
