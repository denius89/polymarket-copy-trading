# Глубокая независимая проверка · 17.10.2026

Область: подготовительные процедуры S01–S23. Продуктовые изменения, контракты функций, сделки, API/Figma/server actions и публикации не входят в тест.

## Независимость и заморозка

Отдельный автор получил текущие процедуры/общие опоры, но не прошлые проверки и историю их автора. Созданы 46 новых задач (две на каждый навык) и 184 семантических критерия. Входы и ключи заморожены до выполнения; SHA256 — [manifest](manifest.json). Задания распределены между тремя новыми контекстами, два случая одного навыка — разным исполнителям. Исполнители получили только свои synthetic fixtures, навыки/опоры, без ключей и прежних ответов. Три других контекста оценивают ответы по отдельным ключам. Родитель исправляет процедуры после получения замечаний; исходные ответы не заменяются.

[Уточнения автора тестов](errata.json) сохраняются отдельно от замороженных ключей: пропорциональная аллокация комиссии, условие release резерва и произвольный порог stale не должны становиться выдуманными обязательными правилами. В критериях оценивается смысл, а не совпадение слов. Эти открытые случаи после прогона — регрессия, не будущий скрытый holdout.

## Автоматическое подключение

Отдельный автор запросов видел лишь metadata каталога. Подготовлены 23 положительных запроса без названий/ID/путей навыков и пять отрицательных простых задач. Каждый выполнен в новой ephemeral Codex CLI с read-only sandbox и без пользовательской конфигурации; ключи не передаются модели. Успех положительного случая требует успешного чтения ожидаемого SKILL.md в native command trace, а не обещания в ответе или наличия metadata. Отрицательный случай требует отсутствия чтения проектных процедур. Незавершённый процесс — not_verified.

Версия CLI: 0.162.0-alpha.17.2. Полный набор выполняется в изолированной копии процедур и опор, без рабочих API/сети/продукта. Дополнительно проверяются metadata реальной родительской папки/репозитория и одно фактическое implicit выполнение из родительской папки. CLI требует обычного доступа к своим служебным данным; запуск согласован автоматической проверкой разрешений, дочерняя сессия read-only. Это не проверка обновления списка навыков в текущем Desktop-чате.

Исходный прогон выполнен [одноразовым runner](round1/cct_run_implicit.py), сохранённым с исходным prompt suffix. Поддерживаемый runner создан после прогона, его анализатор повторно применён ко всем raw traces; это не исходный генератор traces. [Воспроизводимый runner](../run_implicit.py) принимает cases/oracles/cwd/out, сохраняет prompts, native traces, ответы и результаты. Ключи применяет процесс оценки, а не модель. [Тесты анализатора](../test_implicit.py) проверяют отказ считать самоотчёт и неуспешное чтение доказательством. Материалы для повторения — [queries](discovery-queries.json) и [ожидания](discovery-query-oracles.json).

Официальные основания: [описание обнаружения и symlinks](https://learn.chatgpt.com/docs/build-skills), [проверка implicit invocation через CLI JSON](https://developers.openai.com/blog/eval-skills). Проверено только указанное поведение установленной версии.

## Ограничения

Контекстная независимость внутри одного семейства моделей не равна независимости разных организаций/семейств. Нет baseline без навыков, доказанной экономии или статистической гарантии качества. Synthetic задачи проверяют рассуждение и подготовленный review; они не доказывают runtime финансового продукта, доступность API, применимость серверного runbook или реальные controls. Latency/token counters сохраняются где доступны; стоимость и эффект относительно baseline не установлены.
