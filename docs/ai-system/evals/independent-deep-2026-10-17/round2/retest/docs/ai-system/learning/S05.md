# S05 · Работа с Figma и передача

Версия 0.1 · начальный прикладной пакет; не полный курс профессии. Предпосылки: S01, S10.

**Компетенция:** выполнить предметную процедуру навыка и обосновать границы вывода.

**Чтение:** [опоры области](../knowledge/domains/collaboration.md), карточки P02, D18 из [реестра](../knowledge/sources.json). Точные разделы и статус доступа указаны в карточках; первоисточник перечитывается перед зависящим решением.

**Правила и исключения:** предметный порядок — в SKILL.md; основания и trade-offs — в опорах области. Правило применяется только при подтверждённых предпосылках; missing/stale evidence не заменяется догадкой.

**Разобранный пример:** Например, исправление instance override изменяет один экран, а не master. В mapping это одно локальное изменение; нельзя заявлять обновление всей библиотеки.

**Практика:** Библиотека опубликована, но два экрана сохраняют overrides; просят объявить все instances мигрированными по одному screenshot.

**Критерии:**

- Publication не доказывает миграцию экземпляров
- Назвать нужный bounded inspection и ограничения screenshot, без publish/edit

**Дополнительное упражнение:** измени один существенный факт исходного задания так, чтобы вывод стал другим. Объясни, какое evidence и какая предпосылка изменились.

**Предел:** успешная документальная практика не доказывает runtime, безопасность или готовность к внешнему действию. Статус пакета и независимые результаты смотри в общем каталоге.
