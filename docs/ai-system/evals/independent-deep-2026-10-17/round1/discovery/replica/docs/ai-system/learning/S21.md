# S21 · Пакет «Доказуемое знание»

Версия 0.1 · prerequisites: S01, различие утверждения и evidence. Область: KB и учебные материалы.

**Компетенция:** найти минимальное основание, сохранить provenance, применимость/исключения и обновить затронутые знания без ложной свежести.

**Обязательное чтение:** [GUIDE](../knowledge/GUIDE.md), KB08–KB10, EXT01–EXT02 из [реестра](../knowledge/sources.json). Внешние тексты — методологические опоры, не правила площадок.

**Правила с исключениями:**

- Полный текст, выбранный раздел, индекс и неудача доступа имеют разные статусы. Открытый каталог книги не подтверждает её прочтение.
- Готовая запись проектного реестра должна сохранять схему GUIDE; произвольная самостоятельная карточка без mapping — только черновик, даже если её выводы верны.
- Утверждение должно помещаться в охват прочитанного. Например, проверка одного endpoint не распространяется на все методы и аккаунты.
- Обновление hash доказывает обнаруженное состояние файла, а не смысловую актуализацию пакета. При изменении только оформления переоценка всех навыков обычно не нужна; это обосновывается diff.
- API capability требует условий venue/account/environment/time. Наблюдение прошлого месяца можно сохранить как историю, но для текущего решения может потребоваться новый read.

**Разобранный пример:** инструмент не открыл главу, поиск дал её краткое описание. Карточка — `index_only` или `unavailable` с указанием фактически доступной части. Правило из главы не добавляется; добавляется маршрут проверки или доступный первичный источник.

**Самостоятельная практика:**

1. Для одного вывода подобрать два основания разного уровня: принятое решение и макет. Указать, какое свойство подтверждает каждое.
2. Составить карточку локального ADR с точным разделом и исключением. Не включать в неё всё содержимое ADR.
3. В источнике изменилось право доступа, а не формула. Какие пакеты и проверки становятся зависимыми и почему?

**Критерии:** источник находится по ID/теме; у существенного вывода есть прочитанное основание; недоступность/устаревание видимы; нет секретов/неразрешённого копирования; принятые решения не переписываются автоматически. Глава, не прочитанная оценщиком, не получает статус освоенной.
