# S06 · Качество frontend и performance

Версия 0.1 · начальный прикладной пакет; не полный курс профессии. Предпосылки: S04, S05.

**Компетенция:** выполнить предметную процедуру навыка и обосновать границы вывода.

**Чтение:** [опоры области](../knowledge/domains/engineering.md), карточки P03, D03, D04, D11 из [реестра](../knowledge/sources.json). Точные разделы и статус доступа указаны в карточках; первоисточник перечитывается перед зависящим решением.

**Правила и исключения:** предметный порядок — в SKILL.md; основания и trade-offs — в опорах области. Правило применяется только при подтверждённых предпосылках; missing/stale evidence не заменяется догадкой.

**Разобранный пример:** Например, lab metric измерена на warm cache desktop. Её можно сообщить с условиями; она не подтверждает распределение mobile field пользователей.

**Практика:** Есть только Figma и локальная картинка с быстрым открытием. Нужно заявить хороший INP и WCAG для всех экранов.

**Критерии:**

- Не подтверждать INP/WCAG runtime по картинке
- Подготовить соразмерный план измерений без начала frontend

**Дополнительное упражнение:** измени один существенный факт исходного задания так, чтобы вывод стал другим. Объясни, какое evidence и какая предпосылка изменились.

**Предел:** успешная документальная практика не доказывает runtime, безопасность или готовность к внешнему действию. Статус пакета и независимые результаты смотри в общем каталоге.
