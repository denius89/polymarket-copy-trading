# S22 · Возможности API Polymarket и Limitless

Версия 0.1 · начальный прикладной пакет; не полный курс профессии. Предпосылки: S03, S10.

**Компетенция:** выполнить предметную процедуру навыка и обосновать границы вывода.

**Чтение:** [опоры области](../knowledge/domains/engineering.md), карточки D01, D02, P06, P09, P10 из [реестра](../knowledge/sources.json). Точные разделы и статус доступа указаны в карточках; первоисточник перечитывается перед зависящим решением.

**Правила и исключения:** предметный порядок — в SKILL.md; основания и trade-offs — в опорах области. Правило применяется только при подтверждённых предпосылках; missing/stale evidence не заменяется догадкой.

**Разобранный пример:** Например, публичный market list не подтверждает webhook для чужого кошелька. Для каждого требуется собственная documented/observed/account evidence.

**Практика:** Публичный market GET дал 200, а partner endpoint 403; предлагают объявить историю всех лидеров доступной и live gate пройденным.

**Критерии:**

- Разделить public success, partner unknown и account permissions
- Не объявлять полную историю/live готовность; выдать scoped matrix

**Дополнительное упражнение:** измени один существенный факт исходного задания так, чтобы вывод стал другим. Объясни, какое evidence и какая предпосылка изменились.

**Предел:** успешная документальная практика не доказывает runtime, безопасность или готовность к внешнему действию. Статус пакета и независимые результаты смотри в общем каталоге.
