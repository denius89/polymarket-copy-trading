# Исходная рамка проектных навыков

Версия 0.1 · прочитано 17.10.2026 · локальный ориентир, не новый ADR.

## Найти проект

В текущем зеркале репозиторий находится в `polymarket-copy-trading/`. Родительские `docs/PROJECT_STATE.md` описывают срез 23.09 и не заменяют документацию этого checkout; `polymarket-github-sync/` — другой срез. При переносе репозитория определяй корень по фактическим AGENTS/документам, не по имени пользовательской папки. Корневые `sources/` зеркала и `references/` репозитория read-only.

## Минимальные основания

| Вопрос | Где читать от корня репозитория | Ограничение |
| --- | --- | --- |
| Поручение и область работы | Текущий запрос пользователя, применимые AGENTS | План не разрешает смежные задачи |
| Текущая очередь/журнал | `docs/ROADMAP.md`, `docs/PROJECT_STATE.md`, `docs/README.md` | Датированные записи не доказывают текущее runtime-состояние |
| Пауза разработки | `docs/decisions/0002_pause_implementation_for_review.md` | Уточнения по дизайну не возобновляют приложение |
| Площадки | ADR-0007 и ADR-0008 | Limitless первый partner spike; обе площадки обязательны; live-gates отдельные |
| Техническая основа | ADR-0042 | Предложение, не подтверждённая реализация/развёртывание |
| Данные и рейтинг | ADR-0044; для чисел — относящиеся части ADR-0011 | Принята область дизайна; новые права/API-specific параметры предлагаются отдельно |
| Пользователь/языки | ADR-0009, ADR-0006 | При затрагивании прочитать первичные решения |
| Дизайн → дальнейшая работа | `design/client-ui-kit/HANDOFF.md`, документ 118 | Макет, сохранённый prototype и runtime имеют разное evidence |
| План AI-подготовки | `../planning/2026-10-17/AI_SYSTEM_PREPARATION_MASTER_PLAN.md` | Файл в родительском пространстве может не входить в отдельный checkout |

Первоначально была разрешена подготовка S01/S21/S10; последующим поручением 17.10 владелец расширил подготовку на весь каталог S01–S23. Продуктовые функции, контракты функций, новые формулы рейтинга и внешние действия не входят в эту работу. Это описание текущей подготовки, а не вечный запрет на последующие явно разрешённые задачи.

Перед задачей, зависящей от свежего GitHub/Figma/API, зафиксировать новое наблюдение или явно ограничить вывод старым evidence. Для подготовки этих трёх навыков повторная полная внешняя приёмка не требуется и не проводилась.

## Выбор процедуры

- S01 / `$cct-project-context`: существенная новая задача, продолжение прежнего обсуждения, конфликт очереди/решений/реализации.
- S21 / `$cct-knowledge-curation`: поиск/проверка оснований, пополнение KB, подготовка учебного пакета, обновление источников.
- S10 / `$cct-ai-quality`: проверка содержательного результата AI, утверждения о готовности, оценка навыка.

Для короткого перевода фразы, арифметики или нейтрального вопроса загрузка всех трёх не нужна. Предметные процедуры S02–S09/S11–S20/S22/S23 теперь подготовлены: выбирай по [каталогу](CATALOG.md), без автоматического запуска всего набора. Доступность файла, структурная проверка и независимая задача имеют отдельные статусы.
