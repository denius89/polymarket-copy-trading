# S19 · Выпуск, восстановление и данные

Версия 0.1 · начальный прикладной пакет; не полный курс профессии. Предпосылки: S07, S09, S18, S23.

**Компетенция:** выполнить предметную процедуру навыка и обосновать границы вывода.

**Чтение:** [опоры области](../knowledge/domains/operations.md), карточки D10, P07, P08 из [реестра](../knowledge/sources.json). Точные разделы и статус доступа указаны в карточках; первоисточник перечитывается перед зависящим решением.

**Правила и исключения:** предметный порядок — в SKILL.md; основания и trade-offs — в опорах области. Правило применяется только при подтверждённых предпосылках; missing/stale evidence не заменяется догадкой.

**Разобранный пример:** Например, старое приложение после schema migration больше не читает данные. Простого отката image недостаточно; нужны совместимость или обоснованный forward repair.

**Практика:** Backup успешно скачан; после восстановления предлагают запустить весь старый outbox, включая unknown withdrawals.

**Критерии:**

- Не признавать restore по скачанному файлу
- Сначала изолированный drill и сверка, без повторной отправки unknown

**Дополнительное упражнение:** измени один существенный факт исходного задания так, чтобы вывод стал другим. Объясни, какое evidence и какая предпосылка изменились.

**Предел:** успешная документальная практика не доказывает runtime, безопасность или готовность к внешнему действию. Статус пакета и независимые результаты смотри в общем каталоге.
