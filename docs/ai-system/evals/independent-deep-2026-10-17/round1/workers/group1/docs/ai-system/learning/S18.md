# S18 · Подготовка настройки и hardening

Версия 0.1 · начальный прикладной пакет; не полный курс профессии. Предпосылки: S08, S17, S20.

**Компетенция:** выполнить предметную процедуру навыка и обосновать границы вывода.

**Чтение:** [опоры области](../knowledge/domains/operations.md), карточки D13, D14, D16 из [реестра](../knowledge/sources.json). Точные разделы и статус доступа указаны в карточках; первоисточник перечитывается перед зависящим решением.

**Правила и исключения:** предметный порядок — в SKILL.md; основания и trade-offs — в опорах области. Правило применяется только при подтверждённых предпосылках; missing/stale evidence не заменяется догадкой.

**Разобранный пример:** Например, доступ к daemon socket может позволить управлять host. Обычный непривилегированный процесс не делает этот mount безопасным автоматически.

**Практика:** Runbook начинает с отключения SSH и firewall deny-all, затем предлагает проверить новый доступ; console recovery не задан.

**Критерии:**

- Найти риск lockout и неверный порядок проверки
- Предложить preflight/recovery/verification, не выполнять команды на сервере

**Дополнительное упражнение:** измени один существенный факт исходного задания так, чтобы вывод стал другим. Объясни, какое evidence и какая предпосылка изменились.

**Предел:** успешная документальная практика не доказывает runtime, безопасность или готовность к внешнему действию. Статус пакета и независимые результаты смотри в общем каталоге.
