# S23 · Сквозная стратегия качества

Версия 0.1 · начальный прикладной пакет; не полный курс профессии. Предпосылки: S06, S07, S08.

**Компетенция:** выполнить предметную процедуру навыка и обосновать границы вывода.

**Чтение:** [опоры области](../knowledge/domains/engineering.md), карточки D11, P06, P07 из [реестра](../knowledge/sources.json). Точные разделы и статус доступа указаны в карточках; первоисточник перечитывается перед зависящим решением.

**Правила и исключения:** предметный порядок — в SKILL.md; основания и trade-offs — в опорах области. Правило применяется только при подтверждённых предпосылках; missing/stale evidence не заменяется догадкой.

**Разобранный пример:** Например, E2E подтверждает правильную надпись, но два конкурирующих handler нарушают резерв. Добавить invariant/concurrency проверку важнее дублирования visual теста.

**Практика:** Тест сравнивает PnL с той же функцией, что считает PnL; 100% coverage предлагают считать доказательством денежной корректности.

**Критерии:**

- Обнаружить круговой oracle и ограниченность coverage
- Предложить независимые денежные инварианты и сбойные сценарии без кода продукта

**Дополнительное упражнение:** измени один существенный факт исходного задания так, чтобы вывод стал другим. Объясни, какое evidence и какая предпосылка изменились.

**Предел:** успешная документальная практика не доказывает runtime, безопасность или готовность к внешнему действию. Статус пакета и независимые результаты смотри в общем каталоге.
