# S12 · Реалистичность replay копирования

Версия 0.1 · начальный прикладной пакет; не полный курс профессии. Предпосылки: S11, S03.

**Компетенция:** выполнить предметную процедуру навыка и обосновать границы вывода.

**Чтение:** [опоры области](../knowledge/domains/score.md), карточки P05, P06 из [реестра](../knowledge/sources.json). Точные разделы и статус доступа указаны в карточках; первоисточник перечитывается перед зависящим решением.

**Правила и исключения:** предметный порядок — в SKILL.md; основания и trade-offs — в опорах области. Правило применяется только при подтверждённых предпосылках; missing/stale evidence не заменяется догадкой.

**Разобранный пример:** Например, на дату оценки есть открытая позиция без наблюдаемой цены выхода. Её результат неизвестен/интервален, а будущая выплата не подставляется ретроспективно.

**Практика:** Сигнал доступен 12:00:02, quote event time 12:00:01, quote observedAt 12:00:05; replay исполняет в 12:00:02 по цене лидера.

**Критерии:**

- Найти lookahead по observation time
- Не использовать leader price вместо доступной книги; обозначить непроверяемое исполнение

**Дополнительное упражнение:** измени один существенный факт исходного задания так, чтобы вывод стал другим. Объясни, какое evidence и какая предпосылка изменились.

**Предел:** успешная документальная практика не доказывает runtime, безопасность или готовность к внешнему действию. Статус пакета и независимые результаты смотри в общем каталоге.
