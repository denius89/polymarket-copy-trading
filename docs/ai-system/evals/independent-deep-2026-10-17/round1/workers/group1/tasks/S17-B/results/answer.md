# Decision matrix размещения

Сравнение — только offers.md, без покупки и сетевой проверки тарифов. Paper research требует изолированной среды без live credentials. Будущий live требует отдельного решения по signer, доступам, восстановлению и зависимостям.

| Критерий | A | B |
|---|---|---|
| Runtime | Docker | Docker |
| EU personal-data storage | Не доказано: EU edge не определяет DB region | DB EU заявлена; backup region неизвестен |
| Базовый тариф | «Free forever», условия неизвестны | Quote 50 USD/month, не полный TCO |
| Egress | 1 GB/month quota | Квота и цена неизвестны |
| Restore | Время не подтверждено | Время не подтверждено |

При экспорте 2 GB/day × 30 ожидается **60 GB** данных за период до неизвестного сжатия. Если этот экспорт проходит через учитываемый egress, превышение квоты A — **59 GB**, объём в 60 раз больше квоты. Это условный расчёт: маршрут и billing rules надо подтвердить. Объём хранения зависит от retention и одновременно сохраняемых копий.

TCO = compute + DB/storage + backups + egress + monitoring/secrets + restore drills + эксплуатация/support. Неизвестные статьи не равны нулю. Docker не гарантирует переносимость данных или recovery.

Блокирующие вопросы: где хранятся DB/backup/export с персональными данными; разрешены ли соответствующие регионы; как тарифицируются 60 GB и нужный retention; какая нагрузка/бюджет допустимы; какие RPO/RTO нужны для paper и live. Другие residency решения не приняты. До ответов A не проходит подтверждение EU storage, B остаётся условным вариантом; ни один не имеет доказанного live recovery. Exit-проверка — экспорт, восстановление и контроль полноты в изоляции.
