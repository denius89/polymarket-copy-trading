# Переносимость результата

Сохраняется узкий полезный вывод: frozen candidate один раз оценён против baseline на synthetic replay шести событий venue P, с полной depth и latency ≤1 s, 1–7 октября. Audit подтверждает корректный grouped temporal split. Средняя парная net разница составляет **+0,20 USD/event**, event-level 90% interval **[−0,10; +0,50]**. Ноль внутри интервала означает неопределённость знака эффекта, а не бесполезность всего анализа или доказательство равенства методов.

Coverage — 6/30 = **20%** целевых событий. Нет evidence для venue L, sparse books, latency >1 s и других периодов. Маркетинговая фраза о доказанном преимуществе на обеих площадках при любом latency не поддержана. При этом оснований выдумывать leakage нет: корректность split явно дана.

| Stress-проверка frozen метода | Минимальный охват и результат |
|---|---|
| Latency | Новые окна выше 1 s, отдельные net difference и coverage |
| Depth | Sparse books, partial/skip и исполнимый объём |
| Fees/расходы | Документированные диапазоны и чувствительность net outcomes |
| Venue L | Отдельный audit identity, cashflows и replay, затем парная оценка |
| Regime/time | Следующий временной блок и иные классы событий без tuning |
| Missingness | Все 30 целевых событий: причины исключения, сравнение покрытых/непокрытых |

Протокол stress-оценки фиксировать до новых результатов, сохраняя параметры candidate. По каждой ячейке публиковать размер, uncertainty и ограничения; не усреднять площадки так, чтобы скрыть провал покрытия. Synthetic результаты не превращаются в гарантии реальной прибыли. Чисел для stress-режимов пока нет; fitting и новые испытания не выполнялись.
