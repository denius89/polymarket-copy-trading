# Смысловой review exports

Охват — RU mobile node 41 и EN desktop node 52, только текст. Скриншотов и runtime нет: контраст, сетка, переносы, клавиатура и фактический retry не проверены. Текущий kit требует текстовый status label; цвет лишь дополняет его. Impeccable прочитан как контекст review; визуальная проверка невозможна на этих входах.

По state.json операция на 120 USD имеет `unknown`, резерв 120 сохраняется. Доступно: 300 − 120 = **180 USD**. Последнее подтверждение денежных данных — 10:01Z, просмотр — 10:06Z; это возраст пять минут, а порог stale не задан.

| Приоритет | Наблюдение | Минимальная правка |
|---|---|---|
| P1 | «Выведено» и зелёный check сообщают неподтверждённый успех | Явный unknown, без символа завершения |
| P1 | «Повторить» / «Try again» при unknown создаёт риск повторной операции | Следующий шаг — проверка статуса и reconciliation |
| P1 | EN Available $300 игнорирует резерв | Показать доступные 180 и резерв 120 отдельно |
| P2 | RU «Баланс» смешивает виды денег | Подписать подтверждённый остаток и время |

RU: «Статус вывода неизвестен. Запрошено 120 USD. В резерве 120 USD. Доступно 180 USD. Подтверждённый остаток 300 USD, данные на 10:01 UTC. Проверить статус».

EN: «Withdrawal status unknown. Requested: USD 120. Reserved: USD 120. Available: USD 180. Confirmed cash: USD 300, as of 10:01 UTC. Check status».

Тексты требуют последующей проверки в обоих размерах и локалях. Изменения Figma не выполнялись.
