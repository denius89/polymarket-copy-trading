Frontend r31 нельзя считать готовым по приведённым данным. Функциональный дефект подтверждён client-state.txt: после reload localStorage withdrawalDraft со status success перекрывает server pending. Минимальная правка поведения — хранить черновик суммы отдельно, а денежный статус получать из подтверждённого server state; pending остаётся pending. При недоступном сервере показывать неизвестность/устаревание, не успех.

Доступность имеет наблюдаемые дефекты: фокус остаётся на disabled button, серверная ошибка доступна лишь визуально. Нужны управляемое перемещение фокуса после submit и доступное объявление ошибки с привязкой к полю/форме. Соответствие kit не подтверждает WCAG; EN и desktop не исследованы. Визуальную готовность также нельзя подтвердить по одному заявлению автора.

Performance: RU /wallet, Android emulation среднего класса, 4G, cold cache, lab три запуска. LCP 4.1/4.3/4.2 s, медиана 4.2; CLS 0.03/0.04/0.03, медиана 0.03. Это lab evidence, INP field отсутствует.
