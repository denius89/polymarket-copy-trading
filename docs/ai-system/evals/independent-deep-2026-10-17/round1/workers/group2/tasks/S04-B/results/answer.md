Диалог противоречит принятому decision.md в двух существенных местах. RU обещает мгновенное закрытие и получение денег при остановке, хотя остановка блокирует лишь новые входы. EN support получает Close all, хотя роль может только видеть статусы. Это риск неправильного распоряжения позициями и превышения полномочий; просьба «не усложнять» не меняет принятую семантику.

Минимальная RU редакция: заголовок «Остановить новые копирования?», описание «Новые входы прекратятся. Открытые позиции сохранятся», кнопка «Остановить копирование». Получение денег не обещать: закрытие и вывод требуют собственных подтверждений. Для user отдельное действие «Закрыть копируемые позиции» с подтверждением последствий и текстом «Исполнение может занять время; результат уточняется». Для EN support: “Copying status”, без исполняющей кнопки Close all.

| Недостающее состояние | Требуемое поведение |
|---|---|
| Loading/pending | Сообщить об обработке, предотвратить случайный повтор |
| Unknown | Результат уточняется; не показывать закрытие |
| Error | Понятная причина и допустимый следующий шаг |
| Permission denied | Объяснить ограничение роли; серверная проверка отдельно |
| Partial close | Показать закрытый объём и оставшиеся позиции |

Основания — только dialog.txt и decision.md. Скриншотов нет: визуальная иерархия, mobile reflow, контраст, focus и runtime-доступность не проверены. Следующая проверка — соответствие role/action/state в текстовом сценарии; макеты не изменялись.
