Подтверждены только ограниченные свойства: artifact имеет digest h5; migration dry-run прошёл на empty DB; backup зашифрован, checksum скачанного файла проверен. Это полезные основания для продолжения review. Они не доказывают восстановление, производительность миграции на 300M rows или готовность live.

Оставшиеся gates: изолированный restore drill после вчерашней ротации decrypt key; проверка полноты и согласованности восстановленных данных; репрезентативная миграция/backfill с измерением locks, времени и нагрузки. Production dataset радикально отличается от пустого staging. RPO/RTO отсутствуют: владельцам нужно определить цели, а drill должен предоставить наблюдаемые значения, не обещания.

Proposed rollout: зафиксировать h5 вместе с schema/config versions и ответственным; провести перечисленные проверки на репрезентативной изолированной копии; проверить r5 с old+new columns в течение backfill. Затем подготовить ограниченный rollout с контролем ошибок, прогресса backfill и денежных инвариантов. Старые columns сохранять до подтверждения завершения и совместимости.

Abort при нарушении целостности, несовместимости или неприемлемой блокировке по согласованным критериям. Откат приложения допустим лишь при совместимой схеме; разрушительный schema rollback не предполагать. После restore сначала read-only reconciliation submitted/unknown и актуальных controls, без слепого replay outbox.

Deploy, migration, feature enable и partner live gate — отдельные решения. Flag остаётся off в предложении; incomplete partner gate не позволяет enable live. Это readiness note и план для согласования, релиз не выполнялся.
