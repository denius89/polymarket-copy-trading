# Исправленное объяснение

> Индекс 72/100 — оценка по шкале используемой методики. Он не означает 72% вероятности вашей прибыли: метод не калиброван в вероятность. Три дня истории сами по себе не подтверждают надёжность оценки. Данных может быть недостаточно для уверенного вывода; результат будущего копирования остаётся неопределённым.

В исходной фразе две неподтверждённые связи: значение индекса приравнено к вероятности и длительность в три дня объявлена достаточной без проверки качества и полноты данных. Удаление этих утверждений не требует новой формулы или изменения весов.

Перед использованием объяснения нужно привязать его к действующей версии метода, периоду и venue, а также уточнить, что именно оценено: история лидера или воспроизводимый результат копировщика. Эти сведения в fixture отсутствуют; их нельзя додумать. Не установлены ни достаточность истории, ни влияние расходов, исполнения и открытых позиций. Поэтому не следует обещать будущую прибыль или придумывать доверительный интервал.

Если действующее правило считает наблюдение недостаточным, корректный статус — «недостаточно данных для оценки», с пояснением причины. Это не 0 баллов, не штраф и не автоматически остановленная сессия. Без указанного правила нельзя самостоятельно заменить 72 другим числом или объявить пользователя eligible/ineligible. Здесь подготовлена только точечная вычитка текста; UI, методика и публикация не изменялись.
