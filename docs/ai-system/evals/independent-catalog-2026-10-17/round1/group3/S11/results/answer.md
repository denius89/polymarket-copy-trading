# Пригодность данных на конец day1

Для score с cutoff на конец day1 данная сделка недоступна: она произошла day1, но поступила только day2. Отбор по одному eventTime создаст lookahead. Resolution, ставший известным day8, нельзя использовать ни как признак day1, ни как текущую цену/оценку позиции. Его можно хранить отдельно как позднее полученный исход для последующей оценки с корректным горизонтом; это не делает его доступным в прошлом.

100 fills одного event — 100 записей исполнения, а не 100 независимых исходов. Их нельзя автоматически удалить как дубли: нужны IDs и экономическая семантика. Для неопределённости и разбиений нужно учитывать общий event; эффективный объём независимой информации из fixture определить нельзя.

Без cashflows и opening cash/positions невозможно подтвердить полный ledger, доходность капитала или результат копировщика. Комиссии, переводы, резервы и оценка открытых позиций также не подтверждены. Допустим описательный отчёт о числе предоставленных fills и задержке получения данной сделки в единицах дней; точная latency неизвестна. Метрики прибыли и числовой score — not_verified/insufficient data, а не 0 или 50.

Следующий шаг: зафиксировать snapshot, timezone и cutoff, восстановить observedAt/corrections, идентичность и денежные слои; затем отдельно проверять replay копии. Никакие данные или баллы не дополнялись предположениями.
