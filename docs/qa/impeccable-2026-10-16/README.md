Навык доступен для сессий, которые обнаруживают `.agents/skills` из рабочей папки репозитория. В чатах, работающих из родительской папки проекта, его нужно загрузить по явному пути; указание добавлено в репозиторный AGENTS.md. После установки каталог навыков обновляется на следующем ходе; это не означает автоматическую установку в Claude/Gemini или все облачные чаты.

## Границы проверки

Цель — визуальная критика текущих клиентских Final-страниц и админки в режиме Operate: понятность, иерархия, последовательность, читаемость и состояния. Архивные варианты не считаются текущими. Утверждённый UI kit и бизнес-правила не меняются по эстетическим предпочтениям внешнего навыка.

Figma — макет, а не HTML приложения. DOM-детектор, клавиатура, экранный диктор, runtime-контраст, скорость и фактическое серверное поведение не объявляются проверенными по изображениям.

Две оценки выполняются независимо: A — дизайн по изображениям/узлам; B — установка и применимость инструментов. Результаты B не передаются A до завершения визуальной оценки. Это адаптация метода к Figma; она не является полным браузерным проходом `impeccable critique`.
