## Проверка и пределы

`npm run check` проверяет обязательные пути, локальные Markdown/HTML-ссылки, каталог архивов и политику tracked-файлов. `npm run test:repository` проверяет ошибки manifests: повторные/опасные пути, неверные hashes и случайное попадание внешнего raw-файла в Git; изолированные сценарии уборки проверяют запрет удаления main/base, fork, незавершённого PR, продвинувшейся и не относящейся к задаче ветки без выполнения сетевых записей. `git diff --check` проверяет пробелы. Обложка и README проверяются в визуальном предпросмотре; окончательный GitHub-рендер — после публикации. Workflow уборки проверяется отдельно по реальному событию merge и составу веток.

Статическая проверка manifests не подтверждает нынешние права/доступность Диска или удалённые байтовые hashes. Figma/API повторно не запрашивались; ссылки и статусы взяты из сохранённых пакетов. Полный семантический аудит всех продуктовых/финансовых правил, расчётов и требований не выполнялся и не объявляется завершённым.
