# Общий пример пустой сессии Q04 ↔ Q06

03.11.2026. Документальная привязка исправленных клиентских кадров и админки. Это макет, не созданные записи БД и не наблюдение API.

## Один определённый набор

Основа — **S01 / AP09**, Polymarket, fixed 20 USD, бюджет 200 USD, лимит позиции 10%, дневной лимит покупок 15%, зона Etc/UTC. AP09 параметризован: выбор S01 здесь явный. AP11 с S14/B110 не переносится в этот пример.

| Объект | Обозначение макета и источник |
| --- | --- |
| Площадка / источник / трейдер / revision | V-PM / SRC-PM / T-PM / TR-PM-1 из синтетических примеров |
| Имя | Momentum Fox — сохранённый визуальный псевдоним макета. Не значение displayed_name эталона TR-PM-1 и не данные реального трейдера. В каталоге выводить displayName из Q02. В Q04/Q06 — summary.traderDisplayName сохранённой при запуске ревизии сессии, даже если текущая карточка Q02 изменилась. |
| Сессия | SS → S-DEMO-EMPTY-01 |
| Настройки | ST, неизменяемые настройки S01; fixed 20, budget 200, p10%, d15% |
| Снимок | SN1; snapshotVersion, sessionVersion, ledgerSequence = строки «1» |
| Время | asOf = 2026-11-02T12:02:00.000Z; createdAt = 2026-11-02T12:02:00.001Z |
| Деньги | initialFunding = free = equity = 200; reserved = positionCost = positionValue = tradingResult = 0 виртуальных USD |
| Счётчики | Все торговые счётчики = «0»; заявок, позиций, исполнений и резервов не создаём |
| Состояния | active / copying_not_connected / EMPTY / synthetic / no_trade_data |

Все обозначения SS/ST/SN1/S-DEMO-EMPTY-01 — **алиасы документа**, не строки, допустимые вместо UUID в runtime API. Для Limitless используется собственная цепочка venue/source/trader/revision и другой SS. Процентный S02 с 3% может переиспользовать визуальный макет, но имеет собственные SS/ST/SN1 и не объявляется тем же S01.

Аннотации внутри клиентских кадров не видны пользователю. Сведения о версии не добавлены в основной интерфейс ради технической проверки. Разрешённый Q06 и Q04 сравниваются по одному SN1; при скрытой финансовой группе суммы отсутствуют, а не превращаются в нули. session:null, скрытый/отсутствующий ресурс и ошибка чтения — отдельные состояния, а не разные изображения пустого SN1.
