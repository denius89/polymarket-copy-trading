# Tokor в демо для разработки

Для новых проверок Polymarket по умолчанию используем Tokor и отдельную тестовую демо-сессию. Публичный адрес, подтверждённая покупка и вход для воспроизводимого прогона записаны в [настройке разработки](../../tools/oracle-collectors/recovery/tokor-dev.json). У действующих сессий сохраняются их назначения.

[Патч профиля 0,01](../../tools/oracle-collectors/recovery/tokor-standard-fee.patch) предназначен для отдельной сборки на основе сохранённого сборщика. Проверенный пример Polygon подтверждает округление вниз до пяти знаков для одного исполнения на стандартном CTF Exchange. Для нового прогона остаются обычные проверки идентичности, свежести и комиссии.

В изолированной базе проведена одна покупка на тестовой книге. В «Активности» появилось исполнение, позиция составила 31,25 доли, комиссия 0,068 USD, доступный баланс 189,932 USD. Во время ограниченного наблюдения свежая подходящая котировка не была поймана.
