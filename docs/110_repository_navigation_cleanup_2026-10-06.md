# Навигация репозитория — 6 октября 2026

## Результат уборки

Главные страницы RU/EN теперь дают одну точку входа в Figma, четыре прототипа, текущий статус и свежие изображения. Убраны конкурирующие вступления, называвшие разные старые отчёты «текущими».

[Навигатор документации](README.md) отвечает на вопрос, что открыть по задаче. [Полный каталог](DOCUMENT_INDEX.md) сохраняет доступ к историческим материалам. Старые документы и изображения не удалены; их даты определяют контекст.

Текущая очередь находится в [ROADMAP](ROADMAP.md), состояние — в [PROJECT_STATE](PROJECT_STATE.md), последний срез дизайна — в [109](109_latest_design_review_2026-10-06.md). История ROADMAP и PROJECT_STATE отделена от текущих вводных. Инструкции агентам направляют к этой очереди.

## Ветки и открытые PR

Проверенный срез: main и три документационные ветки, три открытых PR.

| Ветка / PR | Роль | Статус |
| --- | --- | --- |
| main | Каноническая документация и текущая навигация | Основная ветка |
| docs/consolidated-plan-2026-10-02 / [13](https://github.com/denius89/polymarket-copy-trading/pull/13) | Исторический пакет дизайна и плана | Открыт; содержит отличия от main, автоматически не закрыт и не объединён |
| docs/polymarket-api-reference / [14](https://github.com/denius89/polymarket-copy-trading/pull/14) | Справочник Polymarket API | Черновик, не объединён с main |
| docs/limitless-api-reference / [15](https://github.com/denius89/polymarket-copy-trading/pull/15) | Справочник Limitless API | Черновик, не объединён с main |

API-справочники описывают интерфейсы площадок и проверенные публичные запросы. Проверка структуры репозитория в обоих PR прошла. Это не проверка реального исполнения, авторизации или готовности адаптеров. В main каталога docs/api ещё нет; пользовательские и торговые приложения не реализованы.

Ветки и PR сохранены: удаление могло бы потерять отдельную работу. Старый PR 13 не используется как текущая точка входа; его содержимое требует отдельного сравнения перед объединением или закрытием.
