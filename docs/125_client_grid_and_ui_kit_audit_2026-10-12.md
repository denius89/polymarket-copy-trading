# Аудит клиентской сетки и UI kit — 12.10.2026

**Вердикт:** клиентский интерфейс пока не готов к полной дизайн-приёмке по сетке и UI kit. В этом проходе Figma не изменялась. Админка и архив не проверялись и не менялись.

Проверены четыре рабочие страницы [Mobile EN](https://www.figma.com/design/lxPP2um7FvIbt02K8eeH4T?node-id=29-2), [Mobile RU](https://www.figma.com/design/lxPP2um7FvIbt02K8eeH4T?node-id=33-2), [Desktop EN](https://www.figma.com/design/lxPP2um7FvIbt02K8eeH4T?node-id=186-2), [Desktop RU](https://www.figma.com/design/lxPP2um7FvIbt02K8eeH4T?node-id=205-2), а также стартовая страница, страницы правил/общих компонентов/QA и [Client UI kit](https://www.figma.com/design/lxPP2um7FvIbt02K8eeH4T?node-id=1976-2). Структурный проход охватил 613 верхнеуровневых экранных фреймов шириной 390/1440 px и высотой от 700 px: 153/154 mobile EN/RU и 151/155 desktop EN/RU. В подсчёт входят дополнительные состояния, reference и FUTURE; это не число утверждённых маршрутов. Скриншоты просмотрены выборочно для каждого найденного типа дефекта, но каждый экран вручную в Present не пройден.

## Что уже соответствует правилу

- [Образец сетки](https://www.figma.com/design/lxPP2um7FvIbt02K8eeH4T?node-id=2075-541) показывает 4 mobile и 12 desktop колонок; три grid styles существуют в файле.
- [Образец ширины кнопок](https://www.figma.com/design/lxPP2um7FvIbt02K8eeH4T?node-id=2078-538) различает Fill для главного mobile CTA и Content для короткого действия. Новый `Client/Button/Content` имеет 18 variants.
- Все 307 фреймов 390 px имеют mobile grid style. На desktop все найденные внутренние grid styles совпадают с x=256 и шириной 1152 px. [Главная EN](https://www.figma.com/design/lxPP2um7FvIbt02K8eeH4T?node-id=905-9713) и [главная RU](https://www.figma.com/design/lxPP2um7FvIbt02K8eeH4T?node-id=905-9074) визуально сохраняют расклад 8/4.
- В Client UI kit обнаружены 136 native component variants и 234 instances; потерянных master-ссылок внутри kit нет. Обзорные boards Foundations/Controls/Data/Patterns отрисовываются.

## Порядок исправления

1. Исправить читаемость EN денежных значений и наложенные desktop headers; проверить парные RU/EN экраны, действия и реакции после каждой правки.
2. Согласовать фактические мобильные поля с 4-колоночной сеткой: полноширинные блоки 350 px на 390, 20 px с обеих сторон; отдельно проверить вложенные отступы и fixed CTA. Исправить текст страницы правил Figma.
3. Выравнять шесть desktop sidebars и системно проставить сетку на текущие композиции, сохранив 232 + 24 + 1152 при 1440. Обновить устаревшую страницу QA на основании нового прохода.
4. Сделать mapping Shared/Recovery → Client UI kit и мигрировать повторяющиеся компоненты небольшими партиями, проверяя RU/EN, состояния и prototype reactions. До этого не считать наличие kit доказательством использования его masters на экранах.
5. Проверить реальные композиции на 320/360 и 1024/1280, длинные строки, 200% text zoom; выполнить ручной Present основных и ошибочных маршрутов. Проверка браузерной адаптивности и доступности остаётся задачей реализации.

Аудит был read-only. Геометрические счётчики показывают кандидатов и точные Figma ID; визуальные выводы выше подтверждены указанными скриншотами. Он не является приёмкой каждого из 613 экранов, всех prototype reactions или работающего приложения. Принятые бизнес-правила и [спецификация 117](117_user_interface_technical_specification_2026-10-09.md) не менялись.
