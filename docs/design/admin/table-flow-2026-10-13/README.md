# Исправление наложений таблиц админки · 13.10.2026

Только дизайн существующих RU/EN страниц Figma. Новых страниц, экранов, функций и переходов нет. 292 RU + 292 EN, UI kit 0.4.12; количество компонентов/вариантов сохранено.

## Причина и исправление
После вставки Table column headings в RU родительский auto-layout сохранял старые позиции строк: header y=0 и Record 1 y=0. Высота родителя также не учитывала шапку. Прежняя проверка наличия шапок и колонок недостаточна; эта правка уточняет приёмку пакета table-headers-2026-10-13.

Исправлено 107 RU таблиц: 104 Data / metadata table и 3 Ticket queue. Восстановлен пересчёт вертикального потока и размеров родительских контейнеров. Теперь metadata header h=48, первая строка y=48; очередь поддержки учитывает h=48 + gap=8, первая строка y=56. Данные, колонки, компоненты и реакции сохранены.

В общем компоненте группы Management RU увеличена высота пункта «Аварийное управление» до 64 px: двухстрочная подпись помещается полностью. Изменение распространяется на экземпляры. EN такого дефекта не имел.

## Правило приёмки для следующих макетов
После вставки/изменения шапки пересчитать auto-layout. Проверять фактические границы: следующая строка начинается не раньше нижней границы предыдущей; высота родителя включает шапку. Для wrap-контейнеров сравнивать пересечение по обеим осям, чтобы перенос кнопок не считался наложением. Не скрывать проблему обрезкой текста или фиксированием координат строк вручную.

## Проверка
На обеих страницах проверены видимые FRAME auto-layout контейнеры и границы TEXT относительно непосредственных родителей. После исправлений: RU 0 наложений / 0 выходов текста за блок, EN 0 / 0. Это структурная проверка данного класса дефектов, а не полная ручная приёмка каждого экрана.

Визуально проверены таблица изменения прав 2138:58040 и очередь 2185:21230. [Пример в Figma](https://www.figma.com/design/lxPP2um7FvIbt02K8eeH4T?node-id=2138-57954).
