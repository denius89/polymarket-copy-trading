# Общий проход оставшихся цепочек · 21.10.2026

Последующее исправление: [состояние RU/EN](../locale-state-2026-10-21/README.md). Прежние снимки и журналы ниже остаются историческими; языковые URL-переходы из этого пакета заменены внутренними переходами на общей странице. Дефект сохранения при смене языка проверяется новым пакетом.
Исходный main: `42fe50ebec8e171d067c71d463e5780d6d0c2b2a`. Продолжение отчёта L01–L17 и пакетов 20 октября. Только дизайн и его передача.

Проверены выбранные ветви десяти дополнительных цепочек RU/EN: приглашение сотрудника, пароль, email, замена ключей, восстановление ключей, отзывы, уведомления, журнал, восстановление текстов и пауза объявления. Журнал различает нажатия, прямые входы и ранние неуспешные попытки. Подпись шага без соответствующего фактического экрана не считается успехом.

Исправлено:

- В личном профиле подтверждённый email сохраняется между безопасностью, обзором и устройствами; завершённые остальные сеансы не появляются активными после перехода через внутреннее меню. 349 ссылок на каждом языке заменены переходами к кадрам в той же странице Figma; активные ссылки на самих себя сняты. Межъязыковые переходы рассматриваются отдельно.
- После обработки отзыва список показывает текущий статус; повторное открытие ведёт в соответствующую карточку. Сохранённая связь с TKT-1042 остаётся видимой после завершения. Без создания связи экран прямо говорит об её отсутствии. Обработанный FB-DEMO-01 исключается из подготовленной выборки новых.
- Карточка AUD-041 и связанные экраны экспорта возвращают в исходную выборку либо общую историю. Отдельные права аудитора и экспорта не менялись.
- В 27 личных RU-снимках «Owner» заменён на «владелец».
