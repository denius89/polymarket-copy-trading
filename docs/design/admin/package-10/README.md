# Админка · пакет 10 · Инциденты и сверка

18 RU + 18 EN состояний. Только дизайн, Paper fixtures; backend/live не начинаются.

[RU прототип](https://www.figma.com/proto/lxPP2um7FvIbt02K8eeH4T?node-id=2414-117179&starting-point-node-id=2414-117179&scaling=scale-down) · [EN прототип](https://www.figma.com/proto/lxPP2um7FvIbt02K8eeH4T?node-id=2414-120601&starting-point-node-id=2414-120601&scaling=scale-down)

Очередь/фильтр/empty/load error → карточка → назначение Operations → внутренняя заметка → контекст S-DEMO-002 → сверка → running/unknown/discrepancy/confirmed → причина закрытия → закрытый инцидент. Read-only — ограниченный пример без команд.

Неизвестный результат не считается ошибкой исполнения. Проверка читает прежний object identity, не повторяет отправку заявки/платежа. Параллельный запуск заблокирован. Подтверждённые факты вызывают domain transition; резерв вручную не снимается. Закрытие инцидента не возобновляет торговлю и не делает выплату оплаченной. История и внутренние заметки не видны клиенту.

## Тестовые данные

INC-DEMO-03 / CASE-DEMO-03 / ORD-DEMO-03 / S-DEMO-002 / U-DEMO-002 / Polymarket / Paper. Бюджет $200: доступно $160, резерв $20, исполненный расход $20. Проверяется отмена заявки с ожидаемым исполнением $0; unknown сохраняет резерв. Успешная ветка EVID-DEMO-03 подтверждает cancelled/$0; доменный процесс снимает резерв, сессия остаётся paused. Альтернативная EVID-DEMO-04 — исполнено $12 (расхождение с ожидаемой отменой); случай остаётся открыт. Частичное исполнение заявки допустимо; частичных партнёрских выплат не добавлено.

INC-DEMO-04 — отдельная учебная проблема потока Limitless; ведёт в существующий экран подключения, не меняет его фактический статус. Числовые severity/SLA, инфраструктура и новые привилегии не утверждаются.
