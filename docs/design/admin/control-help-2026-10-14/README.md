# Контекстные подсказки аварийных ограничений · 14.10.2026

В существующие RU/EN экраны добавлены короткие пояснения и знак вопроса: 41 экран и 45 триггеров на язык. Новые страницы и ветки не создавались. GLOBAL_STOP и технический режим имеют расширенное объяснение в правой панели; остальные ограничения — краткую подсказку.

## Поведение

Пояснение видно постоянно. Наведение раскрывает краткую подсказку; нажатие закрепляет её. Подробнее открывает панель с блоками: что отключается, что продолжает работать, уже начатые операции и восстановление. Подсказка не меняет состояние ограничения и не заменяет подтверждение действия.

В реализации: доступ по клавиатуре, закрепление Enter/Space, закрытие крестиком/Escape/нажатием вне подсказки, перенос текста, выбор стороны по доступному месту. В Figma подсказка закрывается повторным нажатием на знак вопроса или Escape. Неработающий крестик внутри подсказки убран; в правой панели крестик работает. Это отличие прототипа от будущей реализации.

## Передача

UI kit 0.4.20: 28 наборов, 168 вариантов. Карта 0.12: 427 root frames на язык; 422 основных состояния и пять технических оболочек (три меню аккаунта, две панели помощи). ID и изменённые узлы — manifest.json. Тексты и переводы — config внутри manifest.json. Правила безопасности и права на действия не менялись.

## Проверка

Привязки Подробнее сохраняются при переходе к Pinned в обоих языках. Привязки переводов во всех восьми вариантах исправлены, RU/EN визуально проверены. В RU Present проверены закрепление, Подробнее и закрытие панели. Полная приёмка всех 82 состояний и клавиатуры остаётся частью сквозной вычитки. Справочник в Google Docs обновлён; все 422 карточки сохранены.


## Уточнение технического режима

По [ADR-0045](../../../decisions/0045_technical_mode_full_user_shutdown.md) полностью закрывается пользовательская часть Shadow в выбранной среде. Уточнены восемь состояний технического режима и его подсказки RU/EN. Сверка только проверяет результат; ничего не отправляет. Пользовательский экран сообщает «Сервис временно недоступен». Подробности и тексты в manifest.json.
