# Полное отключение техническим режимом

Принято владельцем 14.10.2026. [ADR-0045](../../../decisions/0045_technical_mode_full_user_shutdown.md).

Обновлены восемь состояний технического режима на каждом языке, девять подсказок на язык (включая общий обзор) и две панели подробностей. Технический режим закрывает всё приложение и публичный API для пользователей, новые торговые и денежные действия через Shadow и все продуктовые фоновые задачи в выбранной среде. Выбор отдельной площадки не предусмотрен для этого режима.

Сохраняются только аварийная админка, мониторинг, журнал аудита, инциденты, безопасная сверка и восстановление. Сверка ничего не отправляет. Отправленные ранее операции могут завершиться; прямые действия вне Shadow не блокируются. Требование пользовательского экрана «Сервис временно недоступен» и серверной блокировки отражено в макетах и документации; работающий экран и сервер ещё не реализованы.

Справочник 17.09–17.16 обновлён адресно, 17 абзацев; все 422 карточки сохранены. Прямые ссылки не менялись. Поведение восстановлений и независимые подтверждения сохранены.

Идентификаторы, тексты и данные проверки — manifest.json. Новые страницы и ветки Figma не создавались. Проверка оформления проводится на RU/EN макетах; реальные подключения и команды не запускались.
