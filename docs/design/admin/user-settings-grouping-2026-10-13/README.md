# Группировка настроек пользователей · 13.10.2026

Только дизайн: исправлены user-settings, user-noor-settings и user-ops-settings на RU/EN страницах. Новых страниц, веток и экранов нет; 292 RU + 292 EN. Существующие карточки профилей, чья полная пересборка ожидает отдельного согласия, не изменялись.

## Новая группировка
- Сверху: идентификатор пользователя и текущий контекст.
- Основная колонка: «Профиль и доступ клиента». Предпочтения, сведения о самостоятельных настройках клиента и пояснение административных прав в одном блоке.
- Ниже: «Связанная сессия · снимок настроек». Площадка, версия, бюджет и данные сессии относятся к сессии. Кнопка перехода находится в отдельном footer внутри этой карточки.
- Контекстная колонка: «Тариф и VIP», затем «Обращения и события».
- Отдельная карточка «Настройки и доступ» объединена с данными клиента. Удалены только её дублирующий заголовок и пустой контейнер после переноса текста.
- Убрана фраза о непоказанном в прототипе VIP второго демо-профиля: это техническая заметка, а не пользовательское состояние. Новый VIP-сценарий для Noor не добавлялся.

Права Owner/Operations, существующие VIP-кнопки и реакции сохранены. Неизвестные язык/часовой пояс и незагруженная история остаются неизвестными; данные не выдумывались. Учебная alpha-комиссия 0% и стартовая комиссия продукта 1% не менялись.
