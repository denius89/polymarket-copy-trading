## Правила сценариев

Один набор ID поддерживает разные независимые снимки: normal, empty, stale, denied, compromise, isolation, emergency, owner loss, source outage/disagreement и audit mismatch. Переход к другому примеру сбрасывает мысленный сценарий; он не сообщает о выполненной операции. Нормальный список STAFF-204 без роли не противоречит снимку её назначения.

AUD-046…041 — первая страница, AUD-040…035 — вторая; всего 12 событий по 6 на странице. Образец CSV содержит четыре отфильтрованных события AUD-044…041 в порядке отображения. Изменение, назначение и отзыв помечены отдельными branch. Эти записи не доказывают подлинность или защищённое хранение аудита.

Все числа USDT-DEMO — пример профиля. Для расхождения: 100 × |P1 − P2| / $1, единица — процентный пункт; это отдельно от процентного отклонения каждой цены от $1. Настройки боевого профиля определяют Owner до live.

Финансы прошлых макетов — отдельный будущий платный этап: PART-024 (Agent A) PM $120 + LL $40 доступно, $18 pending; PART-031 (Agent B) $25 в резерве. Доступное $160 + pending $18 + резерв $25 = $203. Pending и резерв не доступны для новой выплаты; выплачивается весь доступный баланс выбранной площадки. Учёт 1 USDT = $1. Сетевые маршруты и источники комиссий проверяются при интеграции.
