# Два ключа безопасности и актуальная передача админки

18.10.2026. Только дизайн и документация, без регистрации настоящих ключей или запуска приложения.

Проверка ключей владельца разделена на последовательные этапы. Основной и другой запасной ключ имеют отдельные результаты. Ошибка/отмена второго шага сохраняет действующий результат первого; повтор основного вместо запасного отклоняется. При устаревании или изменении набора ключей проверка начинается заново. Завершение настройки входа не подтверждает денежную операцию.

- 8 новых состояний RU +8 EN; 2 прежних экрана на язык обновлены на месте.
- 10 пар /24 перехода на язык. Служебные исходы запроса отделены подписью «Сценарии прототипа» и не входят в продуктовые команды.
- Карта 0.19: 566 корней /561 основное состояние на язык. UI kit 0.4.21 — прежние 28 наборов /168 вариантов; новые компоненты и токены не создавались.
- В покрытии B06 закрыт на уровне дизайна: 81 покрыто, 21 частично, 2 отсутствует, 6 отложено.
- Читаемая карта пересобрана по всем разделам JSON; текущие указатели согласованы. Основной раздел восстановления отличает общее снятие ограничения от денежного маршрута с двумя владельцами.

Существующие страницы, корневые ID двух прежних экранов, палитра, сетка и компоненты сохранены. Конструкционные сценарии описывают эту итерацию и не являются резервной копией Figma. Запросы браузера, проверка происхождения/идентичности, срок результата, соответствие зарегистрированным средствам входа, отзыв и сохранение незавершённой настройки проверяются при реализации. Разные регистрационные идентификаторы сами по себе не доказывают, что физические устройства разные; конкретный способ подтверждения и ограничения поставщика входа требуется проверить при реализации. Подсказка использовать два физических ключа не является доказательством аппаратной независимости.
