## Что проверять коллеге

1. Уведомления: список → фильтры → запись → попытки. Доступность, доставка и прочтение имеют отдельные основания.
2. Ознакомление владельца A не отмечает B; просмотр чужой записи не даёт отметить её прочитанной. Уведомление не подтверждает денежное действие и не снимает ограничения.
3. Неизвестный результат → проверка той же попытки → неизвестность сохранена, новой отправки нет. Неподключённый канал не выглядит доставленным.
4. Отзыв: оригинал → классификация и назначение → внутренняя заметка → сохранение. Ошибка поля и конфликт версии не перезаписывают чужую правку.
5. Связь с TKT-1042 проверяет USR-1007 / S-CP-041; исходный отзыв, переписка и статусы разделены. Разобрано не означает исправлено или закрытую поддержку.
6. Без контекста личность не подставляется; похожие отзывы не объединяют пользователей и исходные тексты. Английский оригинал не заменяется переводом в RU.

## Передача

screen-content.json, screen-pairs.json, guide-cards.json, entry-points.json и записи проверок связывают требования с узлами. Скрипты сборки и журнал изменений не являются точной резервной копией Figma. Перед программированием читать свежий Git main и затронутые узлы. sources/ и references/ не изменялись.

Во время работы несколько ответов Figma завершились тайм-аутом. Результаты проверены на холсте, существующие экраны не пересоздавались; переходы восстановлены адресно. Ошибочные ответы не считались доказательством сохранения.
