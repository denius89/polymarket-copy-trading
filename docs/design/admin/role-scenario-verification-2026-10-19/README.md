# Повторная проверка клиентских состояний · 19.10.2026

Продолжение [проверки ролей и сквозных сценариев](../role-scenario-pass-2026-10-19/README.md) после восстановления доступа к Figma.

Проверены оставшиеся 16 состояний: mobile RU — 3, mobile EN — 7, desktop RU — 3, desktop EN — 3. Вместе с 28 ранее прочитанными состояниями получено 44 из 44 записей (11 сценариев × RU/EN × mobile/desktop). Это чтение текстов и прототипных действий, а не 44 ручных прохождения интерфейса.

Обнаружена и исправлена одна неточность: заголовок «Исполнение пришло после отмены» мог означать завершённую отмену. В двух русских макетах теперь «Исполнение после запроса отмены». Пояснение сохраняет правило: запрос отмены не равен подтверждённой отмене. Позднее исполнение учитывается один раз: $8 + $4 = $12; оставшиеся $8 в резерве до сверки. Английский заголовок уже явно указывал на запрос отмены.

Сверены комиссия Paper Alpha 0%, неактивные будущие условия VIP, сохранение резерва при неизвестном результате, новое подтверждение вывода после снятия ограничения, публичный ответ TKT-1042/MSG-1042-C и объявление ANN-DEMO-01/A-2. Кнопки обновления меняют только состояние компонента на загрузку; повторная отправка сделки или перевода не предусмотрена этим прототипом.
