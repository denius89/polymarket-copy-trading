# Проверка финансового обзора

Проверка ограничена шестью корнями, новым семейством графиков и выбранными внутренними переходами. Полная приёмка админки, всех ролей, устройств, реальных источников и серверных прав не заявлена.

- Арифметика: `check-fixtures.py` проверяет шесть разных записей, суммы поступлений/расходов, оба периода, остатки двух источников, исключение несопоставленного и нулевые комиссии/долг/выплаты Alpha. Пройдено.
- Структура: прежние root IDs, Main, заголовки сотрудника и сетка сохранены. Табличные строки 1144 px; их пять колонок помещаются в строку. Высота под две строки текста рассчитывается автоматически.
- При первом структурном чтении скрытые экземпляры показателей другого периода имели сохранённые координаты за границей ряда. Это не видимые переполнения: в Present оба периода показывают четыре показателя. Проверка границ учитывает видимость и не выдаёт скрытые координаты за дефект.
- Ручной проход: столбец поступления 10 октября → ALPHA-IN-002 / $500 → возврат к той же выборке; нулевой день 8 октября → пустая выборка; период 3 дня → $520 поступлений / $10 расходов при неизменном текущем остатке.
- Отбор расходов за 3 дня показывает ALPHA-EX-003 / $10. Задача внимания открывает ALPHA-IN-003 / $20; состав средств отделяет наблюдаемый остаток, сопоставленное и несопоставленное.
- Найдено: задача внимания и последние записи могли наследовать несвязанный старый отбор при возврате. Исправление подготавливает контекст записи; вход из полноценной выборки сохраняет её отбор.
- RU → EN через собственный профиль открыл тот же внутренний раздел и ALPHA-IN-003 / $20 с тем же сотрудником STAFF-201. Период хранится отдельно и не сбрасывается сменой языка.
- Особенность Figma: после изменения переменных часть содержимого исчезает из дерева доступности, оставаясь на изображении. Для повторного чтения выполнялся обычный переход через общий обзор и обратно без сброса переменных. Это не проверка доступности работающего приложения. Настройки пользователя не менялись.

Загрузка и ошибка доступны в UI kit; не утверждается ручная приёмка отдельных маршрутов загрузки/ошибки основной сводки. Реальная сохранность после перезагрузки, реальная сверка и финансовые отправки отсутствуют в этом дизайне.

После точечного исправления возврат из ALPHA-IN-003 проверен повторно: выборка «12.10.2026 · receipts», только ALPHA-IN-003 / $20; прежний отбор расходов не наследуется. Отсутствие источника и устаревшие данные в EN открыты через ссылки состояния; возвраты к сводке сохраняют STAFF-201 и период 3 дня. Нулевые доход и обязательство раскрывают причины и отделяют будущий платный пример.

Итоговые снимки RU/EN и состояния устаревших данных просмотрены: сетка, подписи шкал, суммы и таблица внимания читаются. Снимок UI kit просмотрен отдельно. Нативная сводка выше окна 1000 px, нижние разделы доступны прокруткой; это не обрезка содержимого.

Результаты проверок репозитория записаны в checks.json после выполнения.
