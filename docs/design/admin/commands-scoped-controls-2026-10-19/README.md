# Команды сборщиков и области ограничений

19.10.2026. Дизайн для вычитки; приложение и реальные операции не создавались.

Добавлены 87 состояний и обновлены 8 существующих на каждом языке. Карта 0.24: 776 RU +776 EN, по 771 основному состоянию. Используется прежний набор компонентов 0.4.21.

- Девять команд: настройки, пауза и возобновление сбора; правила и запуск проверки; сравнение, публикация, расчёт и восстановление методики рейтинга.
- Восемь областей: сотрудник, клиент, источник данных, собственный денежный источник, подписант, сеть, актив и маршрут.
- Применение отделено от принятия команды; неполнота и неизвестность не считаются успехом.
- После первого согласия показано ожидание. Второй участник подтверждает независимо; только служебная панель прототипа открывает подготовленный пример его экрана.
- Полное техническое отключение и глобальный денежный запрет сохраняют приоритет. Нет автоматического повтора пропущенных действий.
