# Ручная проверка пакета 03

Статус: на совместную вычитку, не финальная приёмка.

1. Подключения → Polymarket → Изолировать → причина/область → Изолировать. Проверить явное отличие остановки в Shadow и неподтверждённого отзыва ключа у площадки. Повторить Limitless.
2. USDT/USD → Настройки → Проверить. Пустые обязательные параметры должны вести к ошибке. Предупреждение не пересчитывает старые обязательства.
3. Сотрудники → Создать роль → Предпросмотр → Сохранить / конфликт. Owner-only полномочия недоступны; сохранение шаблона не назначает роль сотруднику.
4. Сотрудник → Admin-сессии → Отзыв; отдельно компрометация. Пользовательские trading-сессии не считаются отключёнными после обычного отзыва admin-сессии.
5. Журнал → AUD-041; экспорт без права → отказ. Не должно быть ложного подтверждения защищённой копии.
6. GLOBAL_STOP → причина → активация → неполное применение → проверка → полный stop. Нельзя выдавать pending/unknown за подтверждённый stop.
7. Восстановление → Owner A → независимый Owner B → staged / blocked. Без автоотправки старой очереди.
8. На каждом шаге проверить RU/EN, полный адрес при наличии, соответствующую иконку, выбранный пункт меню, читаемость.
9. Статические demo-поля не вводятся; переключение языков и списков не моделирует сохранение состояния приложения.

Выполнено вручную: выбранные RU пути изоляции PM и GLOBAL_STOP. EN и остальные маршруты требуют полного ручного прогона. Точные результаты и ограничения: qa.json.
