# Заголовки таблиц админки · 13.10.2026

Исправление на существующих RU/EN страницах Figma, только дизайн. На каждом языке добавлено 107 шапок (104 таблицы данных/метаданных и 3 очереди поддержки), уточнены заголовки 14 финансовых таблиц. Новых экранов и переходов нет; 287 RU + 287 EN остаются текущим количеством.

UI kit: `Admin/Table header` (2202:642), варианты Metadata (2202:634) и Support (2202:638). Три текстовых свойства Column 1–3; ширина 1144, высота 48. Цвета/отступы связаны с общими токенами, текст Body/Small medium. Витрина экземпляров 2202:643 на текущей странице Admin UI kit.

Заголовки указывают смысл данных, не обещают сортировку. Поддержка: «Обращение / клиент и контекст», «Статус / ответственный», «Обновлено (UTC)». Сотрудники: «Сотрудник», «Роль», «Статус». Аудит: «Событие и время (UTC)», «Автор», «Действие». Карточки с параметрами используют «Параметр», «Значение / состояние», «Примечание / контекст». Финансовые таблицы получили подписи для конкретного раздела: партнёр, источник, выплата, тариф, актив/сеть.

Проверки: все 107 новых шапок на каждом языке присутствуют, непустые, совпадают с позициями колонок данных; переполнения главных контейнеров нет. Визуально проверены очередь RU, подключения RU, сотрудники EN, выплаты EN и витрина UI kit. Старые карточки пользователей/сессий являются списками карточек, не таблицами; эта правка их не пересобирает. Пустые/недоступные очереди сохраняют сообщения состояния, а не строки данных.

[Узлы и QA](qa.json). Скрипты — журнал операций, не полный backup Figma. Полная приёмка админки остаётся отдельным этапом. GitHub-публикация пакета поддержки ожидает ранее запрошенного разрешения; эта правка пока сохранена локально.
