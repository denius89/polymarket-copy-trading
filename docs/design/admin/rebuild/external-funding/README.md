# Пополнение собственного кошелька извне

27.10.2026 · [Правила ADR-0061](../../../../decisions/0061_owner_external_wallet_funding.md).

Вход: **владелец A или B → Финансы → Пополнить кошелёк Shadow**. Кнопка также находится в собственных средствах. На сайте безопасная проверка доступна из сверки даже при техническом режиме.

1. Выберите USDT / TRON, USDT / Ethereum или USDC / Ethereum. Адрес показывается полностью. На сайте можно скопировать учебный адрес; не отправляйте на него реальные деньги.
2. Нажмите «Проверить поступление · демо»: 250 выбранного актива найдены, но ещё не доступны.
3. В «Учебных результатах проверки» выберите «Зачислено» и снова проверьте поступление. Подтверждённый баланс увеличится один раз; доступная сумма сохраняет вычет обязательств и резервов.
4. Повторите проверку: второго начисления нет. Проверьте неизвестный результат или неверные реквизиты на другом кошельке — они не пополняют баланс.
5. Через личный профиль смените язык и вернитесь: кошелёк, состояние и сотрудник сохраняются. На сайте откройте средства выбранного кошелька; вывод сохраняет два подтверждения.

## Реализация и пределы

HTML: общий журнал входящих наблюдений, отдельные кошельки и активы, защищённые обработчики, данные для движения средств, баланс вывода из той же модели. Прототип хранит данные в текущем сеансе браузера; обновление страницы начинает новый пример.

Figma: шесть редактируемых корней, три настольных и три мобильных, общие RU/EN. Выбор кошелька и ответа проверки — кликабельные подготовленные состояния. Учебный входящий перевод один на каждый маршрут; свободное число переводов и настоящая сеть не моделируются. Изменённые узлы и construction scripts — описание построения, не точная резервная копия Figma.
