# Рабочий пример первого маршрута

Локальный прототип взаимодействий, не приложение и не замена редактируемой Figma. Данные вымышлены, внешних API и авторизации нет. Запуск из этого каталога: `python3 -m http.server 8765 --bind 127.0.0.1`, затем `http://127.0.0.1:8765/`. Можно также открыть `index.html` локально.

## Что проверить

1. Выберите учебный вход (например, Олег — руководитель операций). Обзор → Polymarket → календарь 18 октября → 2 пользователя / 2 сессии / 1 проблема.
2. Проблемные сессии → Demo Noor → сессия → ORD-002. Итог неизвестен, резерв 20 $, повторной отправки нет.
3. Личный профиль → Язык интерфейса → English → вернуться к работе. Сохраняются заявка, сотрудник, площадка и фильтры.
4. Назад до списка. Сбросить фильтры → следующая страница → выбрать строку → карточка → назад: страница и выбор сохраняются.
5. Найти Atlas → Торговля → S-DEMO-001B: это Limitless, отдельная заявка ORD-001B.
6. Найти Cedar: сессий нет. Найти Orion: данные устарели. Robin: исполнено 8 $, остаток 12 $, резерв 12 $.
7. «Столбцы», галочки, свободный поиск, сортировка, календарь, подсказка и Escape работают на учебном наборе.

24 пользователя и 24 сессии: у Atlas две площадки, у Cedar нет сессий. Обычный снимок: бюджет 200 = доступно 160 + резерв 20 + учётная стоимость позиций 20. Частичное исполнение: 200 = 160 + 12 + 28. Это выбранный учебный пример без прибыли/расходов, не универсальная формула кошелька. У Orion доступная сумма неизвестна, не равна нулю.

Состояние живёт в текущей вкладке и сбрасывается при перезагрузке. Имя и черновик сохраняются только в памяти; сохранение на сервер не имитируется. Семь учебных входов совпадают с Figma: два владельца, руководитель операций, операции/поддержка, ограниченное назначение DEMO-R1, маркетинг, аудитор. Профиль содержит личные данные, защиту, свои сеансы, язык и просмотр прав. Учебная роль выбирается только на экране входов; обычные переходы её не меняют. Это не серверная авторизация. Остальные разделы обозначены как будущие, кнопки не обещают выполненное действие.

Проверка данных: `node check-fixtures.cjs`; переходов профиля: `node check-account.cjs`; поддержки: `node check-support.cjs`.

[Контракт профиля](../figma/interactive/profile-contract.md) · [Проверка и изображения](../figma/interactive/profile-verification.md). Для ошибок и неизвестного результата используйте «Учебные состояния для проверки» перед входом. Свободный ввод имени/почты работает; письма, физические ключи, отзыв токенов и денежные операции не выполняются. `responsive-review.html` — узкое окно 390×640 для проверки того же приложения без изменения его стилей.
 Источник визуальной основы и отличия Figma — в [foundation](../foundation.md), результаты — в [QA](../qa.md).

## Поддержка

Войдите как руководитель операций → Поддержка → Demo Noor. Отдельно попробуйте ответ и внутреннюю заметку, смену статуса и ответственного, ссылку на сессию и возврат. В «Учебных состояниях» выберите неизвестный исход отправки: повтор заблокирован; повторные проверки оставляют неопределённость. Для подтверждения исходного ответа явно выберите «Успех» в учебном ответе сервиса, затем проверьте исходное сообщение. Через профиль смените язык — сотрудник, фильтры, выбранное обращение и черновики остаются. [Контракт и ограничения](../support/README.md) · [Проверка](../support/verification.md).

## Обратная связь

Поддержка → Обратная связь: три учебных отзыва, фильтры и календарный период, карточка, обработка и отдельные внутренние заметки. Связь с обращением проверяет контекст и не отправляет сообщение. RU/EN в профиле сохраняет рабочее состояние. [Правила и границы](../feedback/README.md). Проверка модели: `node docs/design/admin/rebuild/prototype/check-feedback.cjs`.

## Инциденты и публичный просмотр

[Открыть публичный прототип](https://shadow-admin-demo.denisfedko.chatgpt.site). Учебный вход → Управление → Инциденты → INC-102 → обращение T-103 → назад. Закрытие требует подтверждения устранения причины, причины и отметки последствий. В учебных состояниях доступен пример EVID-DEMO-102. Подробности: [контракт](../incidents/README.md), [проверка](../incidents/verification.md).

Публичная версия содержит только восемь исполняемых файлов прототипа. Данные вымышленные; введённые тексты остаются в памяти вкладки и сбрасываются при перезагрузке. Это не общая база обращений для коллег.
