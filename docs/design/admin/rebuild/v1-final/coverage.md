# Покрытие требований дизайном v1

27.10.2026. Сверка с локально принятой [матрицей R01–R18](../requirements.md) и [картой ADM-01–18](../navigation.md), действующими уточнениями и пакетами реализации. Новая удалённая редакция исходного Google Doc в этом проходе не читалась; утверждения о полном совпадении с возможными новыми правками коллеги не делаются.

«В v1» ниже означает передаваемый учебный сценарий, а не реальный сервер/API. Детальные границы источников сохраняются. Полное покрытие продуктового требования не выводится из наличия экрана.

| ID | В v1 / свидетельство | Что остаётся за границей |
| --- | --- | --- |
| R01 · обзор | Графики, период, показатели и переходы; [первый маршрут](../first-route.md), [интерактивные проверки](../figma/interactive/verification.md) | Настоящие источники и расчёт всех показателей |
| R02 · список пользователей | Таблица, отборы, сортировка и возвраты; [первый маршрут](../first-route.md), `check-role-context.cjs` | HTML содержит 24 учебных пользователя; Figma — подготовленные проблемные записи, не полный произвольный ввод |
| R03 · пользователь | Карточка → сессия/связанные операции с тем же пользователем; [торговля](../trading/README.md), [поддержка](../support/README.md) | Все реальные пользовательские данные и интеграционные вкладки |
| R04 · торговые состояния | Частичное/позднее исполнение, отмена остатка, неизвестный результат; [проверка](../trading/verification.md) | Реальные команды, очередь и конкурентные ответы площадок |
| R05 · помощь | Обращения, заметки, статусы, обратная связь и связи с инцидентом; [поддержка](../support/README.md), [обратная связь](../feedback/verification.md) | Настоящая доставка, многопользовательская работа и все жизненные состояния обращений |
| R06 · деньги сервиса | Сводка, движение, обязательства и собственные источники раздельно; [финансы](../finance/verification.md) | Реальный учёт, бухгалтерская полнота и подтверждение балансов |
| R07 · выплаты | Полная партнёрская выплата, адрес/сеть/комиссия, ограничения; [финансы](../finance/verification.md). Дополнительно [вывод собственных средств](../own-withdrawals/verification.md) | Подписанты, сети, резервы и повторные запросы на сервере |
| R08 · условия | Тарифы/VIP и партнёрские денежные правила; [финансы](../finance/README.md) | Полный перерасчёт/применение версий к реальным данным |
| R09 · площадки | Polymarket/Limitless, рынки, подключения и сборщики; [проверка](../platforms/verification.md) | Подтверждение возможностей API, реальные команды и наблюдение |
| R10 · данные и рейтинг | Валидатор, сравнение и публикация методики, восстановление новой версией; [пакет](../platforms/README.md) | Методология и качество реальных исходных данных не сертифицированы дизайном |
| R11 · тексты | Поиск, редактор, предпросмотр, версия/публикация/история; [проверка](../content/verification.md) | Все строки продукта, реальные файлы и доставка опубликованной версии |
| R12 · лендинг | Правка разрешённого содержимого, предпросмотр и версии; [передача](../content/design-handoff.md) | Свободный визуальный конструктор и произвольный HTML/JS не входят |
| R13 · уведомления/маркетинг | Отдельные уведомления, кампании/аудитории и подготовленные результаты; [контент](../content/README.md) | Внешние массовые каналы, настоящие согласия/расписания и доставка |
| R14 · сотрудники | Шаблон → сравнение → назначение → отзыв → журнал; [управление](../management/README.md), [RU/EN](../management/locale-verification.md) | Частичное покрытие: приглашения, произвольный полный каталог прав/областей и производственный жизненный цикл требуют G03 |
| R15 · свой аккаунт | Данные/язык/защита/свои сеансы; [восстановление](../access-recovery/verification.md) | Независимая идентификация без действующего способа и возврат заблокированных прав — G01/G02 |
| R16 · инциденты/ограничения | [Инциденты](../incidents/verification.md), [сверка](../reconciliation/verification.md), полный технический режим и [связанное восстановление](../technical-mode/clarity-verification.md) | Частичное покрытие: не все области ограничений, восстановительное пополнение, все исторические переходы Figma — G03/G04 и отдельные проверки реализации |
| R17 · работа с данными | Календари, подписи/единицы, таблицы, графики и детализация; [первый маршрут](../first-route.md), тематические проверки | Произвольные интервалы Figma ограничены; реальные данные, устройства и доступность проверяются при реализации |
| R18 · контекст | Семь назначений × RU/EN в модельных проверках; профиль и возвраты, связанные объекты/черновики | Память вкладки не серверное хранение; полный ручной перебор всех сочетаний и всех физических устройств не выполнен |

Учебная комиссия Paper Alpha — 0%; неактивный пример будущего тарифа не становится действующей комиссией. Новые адреса партнёров и вывод собственных средств имеют разные правила по ADR-0047/0060.
