# Пожелания к следующим версиям админки

27.10.2026 · Базовая версия: [«Админка v1 — согласовано»](README.md).

Новые пожелания собираем здесь, отдельно от согласованного состава v1. Запись в список не означает решение реализовать её и не открывает новый цикл переработки. Перед началом работы владелец согласует задачу, результат и версию.

## Новые пожелания

На момент фиксации v1 новых конкретных пожеланий не поступило.

Для каждого пожелания записываем: ID, дату и источник, задачу сотрудника или наблюдаемую проблему, ожидаемое улучшение, затронутые роли/экраны, приоритет и статус. Статусы: «собираем», «на согласовании», «согласовано для версии», «отложено», «выполнено». Конкретную версию назначаем после согласования.

## Ранее обозначенные направления — без обещания реализации

- Дополнительные фильтры, сохранённые представления и настройка колонок по реальным задачам сотрудников.
- Дополнительные графики и показатели с подтверждёнными источниками и единицами.
- Редкие сценарии, массовые операции и улучшение текстов по обратной связи.
- Полноценный визуальный конструктор лендинга и внешние массовые каналы как отдельные расширения.
- Дополнительные демонстрационные сочетания в Figma для конкретных задач разработки.

Это перенесённые из прежнего списка направления, а не вновь согласованные задачи. Приоритеты и сроки им не назначены.

## Ошибки и условия запуска

Ошибка уже принятого поведения оформляется как исправление с шагами воспроизведения и проверкой результата. Критические ошибки исправляются до включения затронутой функции. Условия G01–G07 остаются в [списке допуска к реализации и запуску](backlog.md); их нельзя переносить в необязательные пожелания ради завершения версии.
