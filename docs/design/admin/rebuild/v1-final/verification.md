## Ручной проход публичного сайта

Во встроенном браузере проверен настоящий интерфейс публичной v18 с учебными данными:

1. Владелец A, Елена Морозова, STAFF-201: ограничения и восстановление, причина включения, отдельная проверка личности, команда включения технического режима.
2. Обычные разделы заблокированы уже при начале отключения. Переход через хлебные крошки не обходит ограничение.
3. Проверка отключения подтверждает три компонента и включённый режим.
4. Денежная сверка остаётся доступной для безопасной проверки результата.
5. Через профиль переключён язык на EN; возврат сохраняет STAFF-201, сверку и активный технический режим.
6. Подготовлено выключение с причиной; проверка готовности, запрос TECH-DEMO-1 версии 3, отдельная проверка личности и первое подтверждение владельца A. Одного подтверждения недостаточно.
7. Через явную передачу сценария выполнен вход владельца B, Максима, STAFF-202. Сохранены язык, причина, версия запроса и первое подтверждение. После отдельной проверки личности получено второе подтверждение.
8. Отдельная команда выключения снимает технический режим и открывает обычное меню. Остальные ограничения сохраняются; старые операции не отправляются повторно.
