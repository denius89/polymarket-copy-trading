# Как открыть и проверить админку v1

[Актуальные сценарии X07–X09](../contract-review/README.md) · [Figma desktop](https://www.figma.com/proto/lxPP2um7FvIbt02K8eeH4T?node-id=3990-108&starting-point-node-id=3990-108&scaling=scale-down) · [Figma mobile](https://www.figma.com/proto/lxPP2um7FvIbt02K8eeH4T?node-id=4160-650&starting-point-node-id=4160-650&scaling=scale-down).

Для X07–X09 откройте действующие экраны Figma из основного меню. Технические примеры доступны в учебном приложении QA. Следующий абзац описывает исторический HTML v21.

На [историческом сайте](https://shadow-admin-demo.denisfedko.chatgpt.site) выберите учебного сотрудника. Елена и Максим — два отдельных владельца; другие входы показывают свои разрешённые разделы. Язык меняется в личном профиле в шапке. Для обычного нового просмотра перезагрузите страницу: данные учебного сеанса сбросятся. Для проверки двух подтверждающих используйте предусмотренный выход и вход другого владельца **в той же вкладке без перезагрузки** — запрос сохранится. Реальных переводов и ключей нет.

| Задача | Куда идти | Что должно быть понятно |
| --- | --- | --- |
| Чтение paper-сессии | Владелец → Пользователи → карточка → сессия | Пустая сохранённая сессия, ограниченная выдача, подтверждённое отсутствие, 404 и 503 |
| Пользователи и торговая история | Обзор → Пользователи → карточка → исторический учебный пример | Демо-средства, площадка, неизвестный и частичный исход |
| Поддержка | Поддержка → обращение / обратная связь → инцидент | Ответ отличается от заметки, статуса и назначения |
| Финансы | Обзор финансов → движение / партнёры / выплаты / собственные средства | Доход, средства и обязательства различаются; полный адрес и комиссия видны |
| Вывод собственных средств | Владелец A → собственные средства → вывод → проверка → первое подтверждение → предусмотренный переход к владельцу B | Два разных владельца, та же версия запроса; неизвестный результат сверяется без повтора. USDT TRON/Ethereum и USDC Ethereum |
| Ограничения | Управление → Ограничения и восстановление | Включение требует причины и проверки личности; принятие команды не равно остановке. Выключение проходит готовность и два независимых подтверждения |
| Восстановление владельцев | Экран входа → Восстановление владельцев | Single и pair, подтверждение той же версии, закрытый аварийный случай и отдельный новый вход |
| Входы сотрудника | Профиль → Мои сеансы | Один текущий вход и история завершённых или отозванных входов |
| Данные и контент | Площадки и данные; Контент и маркетинг | Подготовка, проверка, предпросмотр, применение/публикация и история различаются |

Figma использует готовые варианты полей и отдельные окна выбора. Свободный ввод и прежние учебные состояния доступны на историческом сайте. Подписи «демо» и «учебный ответ» — средства проверки сценариев, не поведение настоящей авторизации или отправки.

Для замечания достаточно: сотрудник/роль, язык, раздел, что нажали, что ожидали и что получилось. Снимок полезен, но необязателен. После фиксации v1 приоритет у ошибок прав, денег, неизвестных исходов и восстановления; остальные улучшения собираем отдельно.
