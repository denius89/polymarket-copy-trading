# Проверка финансов

25.10.2026. Синтетический браузерный прототип; серверные гарантии, физические ключи, сеть/блокчейн и реальные деньги не проверялись.

## Локальная модель

Все десять проверочных сценариев прототипа проходят: 2073 утверждения, включая 137 финансовых. Результаты — [check-results.json](check-results.json). Проверены оба владельца, отказ остальным пяти назначениям, RU/EN, резервы, срок согласия, точная версия, источник, получатель, 24 часа, жёсткий запрет, пороги и независимость инцидента.

Отдельно исправлены: первый новый адрес обходил специальный порог; неизвестная выплата не учитывалась в суточной сумме; неподдерживаемая сеть/актив получателя пропускались; сравнение реквизитов после согласования теряло предыдущую версию. При повторной проверке текущая выплата исключается из суммы, другие неподтверждённые обязательства сохраняются. Неподдерживаемый маршрут блокируется.

## Ручной проход

HTML: график → записи дня → EN; полная выплата → подтверждение → неизвестный исход → точный связанный инцидент; реквизиты → два владельца → ожидание RU/EN → активация; VIP → действующая версия + новый черновик; собственное пополнение → второй владелец → неизвестно → подтверждение исходного перевода. Снимки в evidence показывают конкретные состояния; это не заявление о проверке каждого сочетания входных данных.

Узкие размеры документа 320/390 px: график, вкладки, карточка выплаты, полный адрес, форма и сравнение реквизитов. Таблица имеет собственную горизонтальную прокрутку. Harness сохраняет тот же сеанс при изменении ширины; физические устройства не использовались.

Figma mobile: вход A → финансы → платный пример → порог → подготовка → A → передача B → второе подтверждение → неизвестный результат → инцидент → профиль EN → возврат на тот же инцидент → сверка → закрытие. Отдельно после исправления сверка неизвестного ответа оставляет резерв; финальный отказ отображается отдельно. [Журнал действий](evidence/native-mobile-trace.json) содержит наблюдения, включая промежуточные ошибки, а не только удачные клики. Нижние кнопки длинного меню требуют прокрутки: запрос клика по внеэкранной записи AX сам по себе не считается выполненным действием.
