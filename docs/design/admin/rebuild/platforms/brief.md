# Площадки и данные

Operate, расширение существующего Shadow: тёмные поверхности, Inter, фиолетовые действия, таблицы и постоянное меню. Не заменяет согласованную визуальную систему. Основания: R09–R10, ADR-0011/0044/0046, package-09/data-rating-contract.md.

Основной маршрут: состояние площадки → конкретный источник/рынок → сборщик → проверка данных → сравнение методики на неизменном снимке → подтверждённый новый каталог. Подключение, пригодность данных и рейтинг показываются независимо. Неполученные данные не превращаются в нулевой рейтинг.

Учебные разрешения явно разделены: владельцы — просмотр/черновик/диагностика/применение; руководитель — просмотр/черновик/диагностика; операции — просмотр/диагностика; аудитор — просмотр. Ограниченное назначение и маркетинг не получают доступ. Это сценарии вычитки, не автоматическое расширение производственных полномочий.

Числа P-1/P-2/V-1/V-2 — прежние учебные примеры, не подтверждённые параметры API. Реальный режим и произвольные источники не включаются. Технический режим запрещает запуск продуктовых сборщиков и публикацию; чтение и сверка команды сохраняются. Ручного присвоения баллов нет.

FINISH: независимая проверка, документация принятого расширения и происхождение снимков обязательны. Мобильная проверка — размеры браузера, не физические устройства.
