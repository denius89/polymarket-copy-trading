25.10.2026. Только синтетический дизайн-прототип. Базовый main: `8567e91e0a5fadb9caedd47d1a7f109654fe302a`.

## Проверенное поведение

Все 11 локальных наборов проходят: 2228 утверждений, включая 155 по площадкам. [Результаты](check-results.json). Новые проверки охватывают семь назначений RU/EN, отдельные права чтения/черновика/диагностики/применения, пересечение фильтров, отсутствие данных без нулевого рейтинга, исходную площадку команды, запрет повтора неизвестного результата, конфликт версии, технический режим, сохранение нового черновика при позднем подтверждении, отдельную публикацию методики/каталога и восстановление новой версией.

Ручной HTML-проход: черновик сборщика → профиль → EN → возврат с тем же вводом; сравнение R-1/R-2 → публикация методики → подтверждение полного каталога → восстановление прежних значений новым черновиком. На 390/320 px проверены подключения, длинная форма, неизвестная команда и RU/EN. Полные адреса и широкие таблицы остаются внутри своих областей прокрутки. Физические телефоны не проверялись.

Ручной Figma mobile: вход владельца A → меню → Polymarket → параметры 10/90 → неизвестный исход → профиль EN → тот же результат команды → подтверждённая сверка → исходный сборщик P-2. Затем новый вход аудитора: прежние параметры сброшены, имя и права аудитора сохраняются, команды применения/паузы/возобновления скрыты. Журнал включает промежуточные наблюдения, в том числе клики, после которых переход не был немедленно виден. Успех подтверждается последующим состоянием, а не фактом нажатия.

Во время прохода исправлены перенос подписи «Площадки и данные» в мобильных меню, подпись применённого черновика и полный сброс учебного состояния при новом входе. [Журнал HTML](evidence/manual-local-trace.json), [журнал Figma](evidence/manual-native-trace.json), [снимки и хеши](evidence/manifest.json).

## Структура и границы

Добавлены 11 настольных +11 мобильных корней: по восемь экранов и три меню. В текущей новой админке 152 общих RU/EN корня: 76 настольных и76 мобильных, 78 экранов и74 меню. Язык не удваивает количество. [Проверка связей](link-check.json): 334 перехода новых мобильных корней, отсутствующих целей и переходов на настольные корни не найдено.

Figma использует подготовленные выборы и сравнение R-1 → R-2 → R-3; свободные числа, поисковые строки и проверка суммы весов выполняются в HTML. Сохранённые сценарии и реестр не являются полным ручным проходом каждого сочетания роли/языка/исхода. [Независимый разбор](finish-review.md) — SHIP только для проверенного HTML и перечисленных исправлений; [документирование дизайна](design-handoff.md) сохраняет принятую систему.
