# Стабильное меню при техническом режиме

Дата: 26.10.2026. Исходный main: `c3baa2a671eb4b1f7a98e9576592594d35a182ef`.

## Исправление

Прототип подменял обычное ролевое меню списком аварийных ссылок. Удалена отдельная подмена: используется общее меню с прежними группами, иконками и порядком. Состав сначала определяется правами сотрудника; технический режим только временно блокирует обычные разделы. Закрытые пункты видны с замком и пояснением. Профиль, инциденты, безопасная денежная сверка, технический режим и восстановление доступны только тем ролям, которым они уже разрешены.

Восстановление выделено как текущий раздел. На коротком экране меню прокручивается отдельно; активный пункт попадает в видимую область. На телефоне раскрытие сохраняет группы, заблокированные пункты и вертикальную прокрутку. Индикатор режима остаётся видимым. После подтверждённого выключения временная блокировка снимается без изменения роли.

- 122 утверждения аварийного восстановления: сохранены два независимых подтверждения, ограничения и неизвестный результат без повторной отправки.
- В браузере RU: владелец A → включение → подтверждение остановки → восстановление; актуальный раздел виден, обычные пункты заблокированы.
- В браузере EN, 390 × 844: раскрытие меню, видимость заблокированных пунктов, выделение восстановления; горизонтальный перенос колонок устранён.

Сохранены ролевые привязки; заблокированные варианты не имеют переходов; обычные привязаны к снятию ограничения. Новых верхнеуровневых экранов нет. [Состав изменений](navigation-figma-result.json).
