# Проверка технического режима

26.10.2026. Локальная модель, браузер, Figma и публикация проверяются отдельно.

## Локальная модель

`check-technical-mode.cjs`: 152 проверки, pass. Все семь учебных ролей × RU/EN; один уполномоченный включает ограничение; отсутствие/отзыв/сужение права; изменение причины/версии; проверка личности; неполная остановка; неизвестный результат без повтора; независимая передача владельцам; неизвестное восстановление не снимает режим; новый цикл не использует старые подтверждения; поздний отказ не отменяет частичную остановку; существующий запрос не перезаписывается; ошибка видна сразу; журнал не дублируется при возврате.

Полный набор: 15 сценарных программ, 2683 проверки. Предметные проверки не доказывают серверную авторизацию, физические ключи или остановку реальных компонентов.

## Браузер

Пройдено: руководитель → причина → проверка личности → принятие команды → частичная остановка → полный учебный результат → запрос восстановления → отдельный вход владельца A → первое подтверждение → выход → EN → владелец B → второе подтверждение → применение → возврат с тем же контекстом. Обычная навигация закрывается с принятия команды; аварийные функции остаются.

Визуально проверены RU при фактическом окне 1280×720 и EN при 390×844. На мобильном документ 375 px по содержимому, горизонтального переполнения нет. Проверены мобильное меню, поле причины и кнопки. Промежуточная проверка через iframe не используется как финальное мобильное доказательство.

Снимки: `evidence/local-desktop-ru.png`, `evidence/local-mobile-en.png`. Независимый обзор: [finish-review.md](finish-review.md).

## Figma и публикация

Figma: добавлены 3 настольных и 3 мобильных корня, общие для RU/EN. Ручной настольный маршрут: владелец A RU → причина → последствия → учебный ключ → принятие → частичная остановка → профиль → EN → возврат с тем же владельцем/состоянием → подтверждённая остановка → восстановление → первое подтверждение → выход → владелец B → ключ → второе подтверждение → применение → возврат «Mode removal confirmed». Снимки: `evidence/figma-partial-ru.png`, `evidence/figma-restored-en.png`.

Прочитаны реакции/назначения новых корней, мобильные переходы адресованы мобильным вариантам. Полный ручной проход нового мобильного маршрута Figma и всех семи ролей не заявлен. Проверки сроков/областей назначения на сайте шире подготовленных условий Figma. Глобальные переходы старых экранов Figma ещё требуют ограничения при активном техническом режиме; блокировка сайта уже действует. Figma не является серверной защитой.

Публичный сайт: версия 12, публикация `succeeded`; точные идентификаторы и SHA256 17 файлов в [publication-evidence.json](publication-evidence.json). Реальные операции выключены.

Публичная браузерная проверка: обновление версии → вход владельца A → «Технический режим»; новый экран и поле причины доступны. Снимок `evidence/public-technical-ru.png`.

Открытые проверки Figma: полный мобильный маршрут/все роли, ограничение обычной навигации исторических экранов, явное сообщение при уже ожидающем другом запросе восстановления. Существующий запрос не перезаписывается, но подготовленный Figma-вариант пока не показывает ошибку так же полно, как сайт.
