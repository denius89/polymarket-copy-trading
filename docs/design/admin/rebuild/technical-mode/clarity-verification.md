# Понятное включение и выключение технического режима

26.10.2026. Основа `17d9965e333a2a7844d423f9bc90379a51a8004b`. Доработка существующего раздела по замечанию владельца; новых правил допуска и денежных действий нет.

## Что изменилось

- Состояние и следующий шаг стоят вверху. В выключенном состоянии — «Включить технический режим», после подтверждённой остановки — «Выключить технический режим».
- Включение открывает три шага: причина → проверка личности → отправка. После отправки отдельно проверяется остановка; принятие команды не равно остановке.
- Обычный учебный ответ подтверждает остановку. Ошибки и частичная остановка доступны отдельно, не мешают обычному проходу.
- Выключение поясняет основание, готовность, первое подтверждение, передачу второму владельцу и окончательное применение. До подтверждённого результата режим остаётся включённым. При неизвестном результате проверяется прежний запрос без повтора.
- Отказ восстановления позволяет подготовить новый запрос, сбрасывая прежние подтверждения. Остальные ограничения сохраняются, старые заявки не запускаются снова.
- Исправлены отступы, мобильные кнопки и перевод фокуса к текущему шагу. RU/EN сохраняют причину и контекст сотрудника.
