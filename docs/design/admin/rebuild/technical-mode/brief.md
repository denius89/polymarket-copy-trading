# Направление

Mode: Operate. Продолжение действующего admin rebuild UI kit, без смены визуальной системы.

- THESIS: сотрудник различает намерение остановить сервис и подтверждённый факт остановки.
- OWN-WORLD: действующие тёмные поверхности Shadow, Inter, фиолетовый акцент действий, привычные поля/таблицы состояния.
- STORY: область и последствия → причина/личность → команда → состояния компонентов → независимое восстановление.
- FIRST VIEWPORT: сотрудник, вся среда/обе площадки, текущий статус, последствия и причина доступны без поиска.
- FORM: десктоп — основной контекст и правая колонка действий; узкий экран — вертикальный поток, переносы без горизонтального переполнения.

Инварианты: Paper Alpha 0%, неизвестный результат не разрешает повтор, два подтверждения не заменяются языком/ролью/повторным входом, старые операции не воспроизводятся.
