# Карта навигации новой админки

[План](README.md) · [Требования](requirements.md) · [Первый маршрут](first-route.md)

Рабочая структура v1, 23.10.2026. Это логические разделы, не созданные экраны и не новые права. Названия уточняются на первом маршруте. Здесь нет ссылок на удалённые макеты.

## Постоянная оболочка

- Слева: логотип, постоянное меню разрешённых областей, раскрываемые группы. Выбранный пункт и родительская группа видны, длинные названия не обрезаются.
- Сверху: сотрудник и активное назначение, понятные площадка/режим там, где они применимы, доступ к уведомлениям и своему профилю.
- В контенте: путь → один заголовок → относящиеся к странице фильтры → данные → действия. Профиль не дублируется заголовком в каждом блоке.
- Роль влияет на видимость разделов; переход между разделами внутри одного назначения не меняет состав меню. При реальном изменении/истечении прав — явное уведомление и безопасная проверка доступа.
- Внутренние вкладки карточки меняют её содержимое, но не заменяют главное меню. Контекстные переходы ведут в те же общие разделы с фильтром по объекту.

## Дерево разделов

| Основной пункт | Внутри | Связанные требования |
| --- | --- | --- |
| Обзор | Сводка, графики, задачи внимания → фильтрованный список | R01, R17 |
| Пользователи и торговля | Пользователи; сессии. В карточке: обзор / торговля / подключения / условия / поддержка / история / настройки. Заявки и позиции сначала внутри сессии, без лишних глобальных пунктов | R02–R04 |
| Поддержка | Обращения; обратная связь. Связи с пользователем, сессией и инцидентом | R05 |
| Финансы | Обзор; движение средств; партнёры; выплаты; собственные средства; сверка операций. Настройки внутри: тарифы и рефералы, денежные партнёрские правила, собственные источники, защита выплат | R06–R08 |
| Площадки и данные | Подключения площадок; рынки; сбор данных; проверка данных; рейтинг и версии | R09–R10 |
| Контент и маркетинг | Тексты и переводы; лендинг; объявления и уведомления; кампании и аудитории | R11–R13 |
| Управление | Инциденты; сотрудники и роли; безопасность; журнал; ограничения и восстановление | R14, R16 |
| Профиль в шапке | Личные данные; язык (выпадающий список); защита; свои сеансы; мои права (просмотр); выход | R15, R18 |

Профиль открывается только кнопкой с аватаром в шапке. В боковом и мобильном меню отдельного пункта профиля нет — для всех ролей, RU/EN и технического режима. Возврат из профиля сохраняет рабочий контекст. Сверка имеет единый список с типом/объектом и открывается из торговли либо финансов с нужным отбором. Подключения площадок и собственные денежные источники не смешиваются. Настройки безопасности организации отделены от защиты личного аккаунта.

## Переходы и сохранение состояния

| Событие | Требуемый результат |
| --- | --- |
| Показатель или участок графика → список | Передаются период, площадка/режим и подходящий фильтр; отбор виден и сбрасывается |
| Список → карточка → назад | Сохраняются поиск, фильтры, сортировка, колонки, страница и позиция прокрутки |
| Пользователь → сессия → проблема/сверка | Пользователь и площадка не подменяются; обратный путь возвращает в исходный контекст |
| Раздел → свой профиль → обратно | Сохраняется рабочий экран; текущий сотрудник не становится выбранным клиентом |
| RU ↔ EN | Меняются подписи, сохраняются роль, значения, фильтры, объект и черновик |
| Прямая ссылка | Проверяются права; отсутствующий контекст не заимствуется у другого сотрудника; понятный выход к разрешённому списку |
| Выход или истёкший доступ | Чужие/прежние данные не открываются кнопкой «Назад»; повторный вход не восстанавливает отозванные полномочия |
| Несохранённые изменения → уход | Явный выбор сохранить/отменить уход/отбросить; никакой скрытой потери черновика |

В демонстрации переключатель тестовых сотрудников, если нужен для проверки, находится отдельно от рабочего интерфейса. Он не имитирует реальное право менять себе роль.

## Собственные средства — 26.10.2026

Владелец: Финансы → Собственные средства → источник/валюта/сеть → полный адрес, сумма и назначение → проверка → согласие первого владельца → явный выход/вход второго → независимое согласие → учебная отправка → сверка исходного перевода. Настраиваемый минимальный остаток доступен из этого же раздела. Переход в профиль и RU/EN сохраняет перевод; роль меняется только при явном входе другого сотрудника. Неизвестный вывод также доступен из «Сверки операций», в том числе для безопасной проверки при техническом режиме. [Правила и границы](own-withdrawals/README.md).


27.10.2026 — [Восстановление доступа сотрудников и владельцев](access-recovery/README.md): отдельный вход без рабочих прав, проверка личности → новая защита → проверка исходного результата → новый вход. Замена защиты не снимает блокировки и не возвращает старые сеансы или подтверждения. Неподтверждённая независимая процедура явно остаётся открытой.
