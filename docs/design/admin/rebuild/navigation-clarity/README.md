# Понятные ограничения и сверка

26.10.2026. Исправление вопросов коллеги: ограничения и восстановление выглядели как конкурирующие режимы, назначение сверки и её место в меню были неочевидны. Основания — ADR-0030, ADR-0043, ADR-0045 и ADR-0047. Новые денежные полномочия не вводятся.

## Что изменено

- Один вход «Управление → Ограничения и восстановление» вместо отдельных пунктов технического режима и аварийного восстановления. Пункт выбран и при работе с запросом снятия ограничения.
- «Полное отключение сервиса» показывает состояние технического режима и его прежние действия включения/выключения. Восстановление — процедура снятия одного запрета после проверки и независимых подтверждений; остальные запреты не исчезают.
- Из этого же раздела открывается текущий запрос либо подготовленный пример другого ограничения. Это учебные альтернативы, а не дополнительные действующие переключатели. Их выбор не включает запреты и не снимает реальный для текущего прохода технический режим.
- «Финансы → Сверка операций». Общая группа доступна сотрудникам с правом сверки; финансовый обзор и денежные действия остаются только у владельцев. Права на просмотр сумм, запуск проверки и заметки прежние. При техническом режиме безопасная сверка остаётся доступной, а финансовый обзор закрыт.
- В списке и карточке сверки объяснены цель, пример потерянного ответа и последствия: проверка не отправляет операцию повторно и не редактирует баланс. Совпадение относится к конкретному показателю. Три торговых снимка не объявляются полной сверкой всех денежных потоков; выплаты и пополнения проверяются в собственных карточках.
- RU/EN используют одни и те же роли, записи и запросы. Профиль по-прежнему открывается только из шапки.

## Вывод собственных средств

[Отдельное предложение для коллеги](own-funds-withdrawal-proposal.md): контролируемые получатели, доступный остаток после обязательств/резервов, два владельца на внешний вывод и предложенная задержка новых реквизитов. Всё это выделено как предложение; маршрут отправки не добавлен до согласования.
