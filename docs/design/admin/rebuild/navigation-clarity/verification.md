## Ручной браузерный проход

Владелец A: RU обзор → общий раздел → восстановление → возврат; финансы → сверка; профиль → EN → возврат в сверку с тем же STAFF-201. EN меню проверено при ширине 390 px. Объяснение сверки показывает пример потерянного ответа и запрет повторной отправки. На публичной версии 16 отдельно проверен руководитель операций STAFF-206: группа «Финансы» содержит только сверку, общий раздел открывается с тем же сотрудником. Выборы всех семи ролей покрыты модельными проверками, а не объявлены полным ручным проходом.
