# Проверка аварийного восстановления

25.10.2026. Учебный интерфейс, без настоящих операций и секретов.

## Автоматические проверки

- `node docs/design/admin/rebuild/prototype/check-emergency.cjs`: 122 утверждения — роли, три области, свежая проверка, разные личности, смена версии/данных, отзыв права, неизвестный исход, запрет повторного применения, контекст RU/EN.
- Все восемь `prototype/check-*.cjs`: 1316 утверждений, включая ранее существующие маршруты. Проверены именно модели состояния, не серверные права.
- `verify.js`: 90 утверждений по сохранённым реакциям Figma — семь назначений, три области × два языка, один переход после входа/профиля, два подтверждающих, неизвестный исход и запрет сброса. Реакции исполняются в отдельном проверочном интерпретаторе, без изменения живых переменных.
- Отдельная проверка [finish-review.md](finish-review.md) завершилась SHIP для desktop. Исправлено восстановление фокуса после действия: новый заголовок имеет tabindex=-1; выбор ограничения возвращает фокус к списку.

## Ручной проход

Локально во встроенном браузере: владелец A → основание/проверки/проверка личности → первое подтверждение → отдельный вход B → второе подтверждение → профиль EN → возврат → неизвестный исход → сверка → подтверждённый исход. Проверены также технический режим и сохранение версии/основания при RU/EN. После исправления фокуса действия проверены клавишей Enter: активный элемент — заголовок, tabindex=-1.

Figma во встроенном браузере: вход A → восстановление → выбор основания/проверки → проверка личности → первое подтверждение → выход/вход B → новая проверка личности → второе подтверждение → профиль EN → возврат с обоими подтверждениями → неизвестный исход → сверка исходного применения. Применение исчезает при неизвестном результате. Разрешены только учебные действия.

Figma иногда теряет часть доступных элементов из дерева браузера после обновления переменных, хотя кнопки остаются на экране. В таких случаях использованы координаты из свежего снимка; успешность проверена по видимому статусу. Это ограничение средства прототипирования, не свидетельство доступности реального приложения.

## Визуальные свидетельства и ограничения

- [Desktop RU](evidence/desktop-ru.png), [desktop EN](evidence/desktop-en.png): локальная финальная композиция с первым подтверждением и техническим режимом.
- [Figma EN](evidence/figma-en.png): исходное применение подтверждено после сверки, до последней правки меню. [Figma RU](evidence/figma-ru.png): финальное меню, руководитель операций без права подтверждать. Возврат через «Инциденты → Аварийное восстановление» вручную сохранил STAFF-206.
- [Документирование дизайна](design-review.md): сохранена существующая визуальная система.

Мобильная приёмка этого пакета не заявлена: команда изменения ширины браузера не изменила фактическую ширину документа. Также не проверены сервер, реальные ключи, одновременное подтверждение в разных браузерах, долговременное хранение и реальные аварийные ограничения. Нативные отличия Figma перечислены в [контракте](README.md).
