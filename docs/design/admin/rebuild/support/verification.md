# Проверка поддержки

23.10.2026. Проверен ограниченный пакет очереди и переписки, не вся админка.

## Автоматические проверки

- `node docs/design/admin/rebuild/prototype/check-support.cjs`: 91 утверждений, семь входов. Область данных, запреты, отдельные заметки, неизвестный исход без повтора, подтверждённый сбой с тем же ID, пустой текст, экранирование сообщения, фильтры, выход и отсутствие внутренних заметок у просмотра.
- `check-account.cjs`: 169 утверждений существующего профиля.
- `check-fixtures.cjs`: 11 проверок связанных учебных данных.
- Figma: [100 утверждений](check-figma.json) по сохранённым реакциям семи входов. Маркетинг проверяется на запрет и не получает рабочий отчёт строки. Это оценка модели, не 100 ручных кликов.
- Статический дизайн-детектор: только предупреждение о распространённом Inter. Шрифт сохранён как часть согласованного UI kit, новая типографика не вводилась.

## Реальные клики

Локально пройдены семь входов: состав очереди, открытие разрешённого обращения, профиль → EN → возврат, доступность/отсутствие действий. Для руководителя дополнительно: отдельные черновики ответа/заметки, сохранение заметки, неизвестный исход ответа, первая проверка без результата, смена языка через профиль, подтверждение исходного ответа, независимые статус и ответственный, связанная сессия и обратный путь, сохранённый поиск.

В Figma реально пройден руководитель операций: очередь → поиск Demo Noor → обращение → выбор учебного текста → неизвестная отправка → первая проверка → профиль → EN → возврат к тому же обращению → подтверждение исходного ответа → сессия ORD-002 по-прежнему с неизвестным исходом → обращение → статус «Решено» → ответственный Олег → список с сохранённым Noor. Остальные роли покрыты сохранёнными реакциями, а не заявлены как полный ручной проход Figma. Полный перебор комбинаций фильтров также не заявляется.

Наблюдения и ролевые результаты: [журнал](evidence/manual-trace.json). Figma иногда теряет часть accessibility-дерева после изменения переменных; для следующего перехода использовался текущий снимок и видимые кнопки, не выдуманные индексы.

## Визуальная проверка

HTML: очередь и обращение при ширине 1440, английский отфильтрованный список, узкая область 390 px. Узкая проверка выполнена в iframe того же приложения без изменения его стилей: браузер игнорировал обычное ограничение viewport. Проверялись переносы, доступность полей и кнопок; таблица допускает горизонтальную прокрутку. Снимки в `evidence/` показывают фактические состояния. Figma: сохранён вид английской очереди после рабочего сценария; основные узлы редактируемые, а не изображения.

[Независимый разбор](finish-review.md) и [сверка визуальной системы](design-review.md) дополняют этот объём. Серверная безопасность, настоящая доставка, сохранение после обновления страницы и конкурентная работа сотрудников не проверялись и не реализованы.

## Исправление по независимому разбору

Убрано автоматическое подтверждение на второй проверке. Повторные проверки в HTML и Figma остаются с неизвестным исходом. Для подтверждения нужно отдельно выбрать «Успех» в учебном ответе сервиса, затем снова проверить исходное сообщение. Повторный ручной проход обеих версий и новые утверждения 91/100 подтверждают эту границу. Снимки `local-unknown-retained.png` и `local-confirmed.png` показывают два состояния; Figma-снимки повторно сняты в читаемом стандартном размере 1280×720; поведение дополнительно отражено в журнале и сохранённых реакциях. Ранее описанный проход относится к состоянию до этого исправления; финальное поведение определяет этот раздел.
