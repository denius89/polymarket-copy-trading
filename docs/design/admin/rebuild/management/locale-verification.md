# Повторная проверка локализации сотрудников

26.10.2026. База: main `f64a5c1d44acd01262a7bed7b8d01b09c6f3e8fc`. Объём — M-EN-01 в разделе сотрудников: 10 настольных и 10 мобильных корней, без новых экранов и бизнес-правил.

## Найдено и исправлено

- Обычные текстовые слои могли сохранять русский язык при выбранном EN. Обновлены существующие привязки 252 текстов; значения и идентификаторы переменных сохранены.
- Часть экземпляров кнопок показывала русский текст при английском тексте в дереве доступности. Пересобраны 250 экземпляров из тех же исходных компонентов, с сохранением действий, видимости и размеров. Подписи занимают доступную ширину. Идентификаторы экранов не менялись; замены дочерних узлов записаны в [реестре](locale-buttons-evidence.json).
- Режим языка нормализован в 20 корнях и их содержимом: конечное состояние — наследование, без закрепления EN на объектах. [Запись изменений](locale-normalize-evidence.json).
- Проверка по дереву доступности недостаточна: в ходе прохода оно сообщало EN, когда на снимке ещё оставались русские кнопки. Поэтому сохранены и снимки реального прототипа, и последовательность наблюдений.

После обновления результата команды проблема могла возвращаться. Для действий 20 корней добавлено повторное применение текущего режима языка: выбирается по `ui/currentLanguage`, не меняет состояние сотрудника или операции. [Изменённые узлы и правило](locale-action-evidence.json).

[Последовательность прохода](evidence/locale-trace.json) включает промежуточные неудачные попытки, перезагрузки и проверки; это не набор только успешных тестов. Файлы `before` показывают найденные проблемы, а не итог.

- [Настольная компоновка после исправления ширины подписей](evidence/locale-desktop-final.png).
- [Мобильный список EN](evidence/locale-mobile-list-en.png).

Проверяются только учебные операции. Перезагрузка Figma начинает состояние по умолчанию; сохранение контекста проверяется при переходах внутри текущего прохода. Проверка не подтверждает серверные права, работу настоящих устройств или завершение общей приёмки админки.

Сайт и его исходники не изменялись; публичная версия v10 остаётся действующей. Повторная публикация сайта не требуется. Рецепты ремонта не являются точной резервной копией файла Figma.

Дополнительно после последней правки проверен русский возврат из подробностей в журнал: [снимок](evidence/locale-mobile-audit-ru-final.png).

## Результат и границы ручного прохода

M-EN-01 закрыто для данного среза. На desktop пройдены список → Нора → параметры Polymarket/срок/причина → сравнение → неизвестный результат → профиль RU/EN → возврат; шаблоны, отзыв с отменой, журнал и подробности. На mobile проверены список, карточка, параметры Limitless/срок/причина, сравнение и возврат EN → RU → EN, шаблоны, результат, меню состояний, журнал и подробности. После последнего обновления языка проверено, что неизвестный результат не возвращает русские подписи: [снимок](evidence/locale-mobile-result-en-final.png), [событие](evidence/locale-mobile-event-en-final.png).

Полный настольный проход и часть мобильного прохода выполнены до последнего добавления применения режима после действий; повтор после него сфокусирован на регрессии результата/журнала. Не заявляется полный повтор каждого действия всеми семью назначениями после каждой промежуточной правки. Мобильный подтверждённый отзыв в этом проходе не повторялся. Работа экранного диктора Figma не сертифицирована: дерево доступности иногда неполно после перерисовки; выводы о языке подтверждены снимками. Это не доказательство доступности будущего приложения.

Рецепты: `locale-repair.js` → `locale-buttons-repair.js` → `locale-normalize.js` → `locale-action-refresh.js`. Повторное создание экземпляров меняет дочерние ID; не запускать всё повторно без необходимости. Общие корни, переменные ролей, бизнес-правила и публичная версия сайта сохранены.
