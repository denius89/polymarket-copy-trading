# Проверка пакета торговли

25.10.2026. Только учебный прототип; здесь нет проверки серверных прав, реального исполнения или восстановления работающего сервиса.

## Проверено

- 670 локальных утверждений: семь назначений × RU/EN × разрешённые снимки; доступ к объектам, скрытие сумм и событий, сохранение выбора, строгие условия завершения, сохранность исходных пользователей/сверки/инцидентов, арифметика частичной покупки и позднего исполнения. Noor и Orion не получают пояснение о суммах Robin.
- 393 утверждения над сохранёнными Figma reactions: семь назначений, RU/EN, выбор снимка, ограничения входа, признак скрытых сумм, отрицательные/положительный исход проверки, закрытие результата, возврат через сверку и профиль, привязка пояснения к Robin, инвентарь 47 корней. Это оценка сохранённой логики, а не 393 настоящих клика.
- Ручной HTML-маршрут сотрудника операций: Robin → ORD-005 → позднее исполнение → REC-103 → возврат → восстановление → отрицательная проверка → профиль → EN → возврат с сохранёнными ролью, выбором и проверкой. Проверены частичная продажа на узком экране, отдельный завершённый снимок с положительным результатом и отсутствие чужого пояснения в карточке Noor.
- Ручной Figma-маршрут сотрудника операций: обзор → Robin → сессия → заявка → разбор → раскрытие списка → позднее исполнение → исходная сверка → возврат → восстановление → отрицательный результат → закрыть → профиль через боковое меню → EN → возврат. Сотрудник, заявка и выбранный исход сохранены.
- Визуально просмотрены HTML на обычной ширине 1265 px и мобильной ширине около 390 px; Figma — общий desktop-кадр 1440 px. Нативная Figma не объявлена адаптивной мобильной реализацией.

Проверки репозитория `npm run check`, `npm run test:repository` и `git diff --check` пройдены. Семь локальных наборов: 169 / 85 / 11 / 77 / 91 / 91 / 670 проверок. После исправления возврата из профиля отдельно пройдены ещё 8 проверок сохранённых Figma-переходов, включая отсутствие конкурирующего перехода.

Публичный сайт обновлён до версии 4. После публикации вручную пройден маршрут сотрудника операций до ORD-005 с выбором позднего исполнения; [снимок опубликованной версии](evidence/public-late-ru.png). [Figma RU](evidence/figma-late-ru.png) и [Figma EN](evidence/figma-recovery-en.png) просмотрены отдельно.

## Найдено и исправлено

1. Таблица заявки наследовала минимальную ширину общего списка. Для неё задана собственная ширина без лишней горизонтальной прокрутки.
2. Пояснение о предыдущих частях Robin показывалось для других пользователей. Ограничено его карточкой и доступом к денежным данным.
3. Боковая кнопка профиля новых Figma-кадров наследовала прежний адрес возврата. Теперь возвращает к разбору либо проверке восстановления; старые переходы из профиля отделены от новых маршрутов.
4. Признак возврата к разбору сбрасывается при входе в глобальные разделы. Исходная сверка остаётся отдельным снимком и не перезаписывается альтернативным состоянием.
