## Исправленные дефекты

1. Figma при сохранении многоступенчатого условного действия оставляла первые две ветви. В ручном проходе это приводило к чужому короткому имени. Исходные ветви заменены независимыми условными действиями с явной пустой альтернативой; сохранённые реакции повторно прочитаны и проверены для всех входов.
2. Закрытие окна с неизвестным результатом раньше позволяло потерять ожидающий запрос. Теперь цель и запрет повтора сохраняются; обновление только проверяет результат. В этом небольшом примере одновременно разбирается одно ожидающее завершение; открытие другого действия возвращает к нему.
3. Кнопка повторной генерации кодов скрывается после одноразового показа. Закрытие скрывает маркер. Новый набор снова требует проверки личности.
4. В локальном представлении адрес ожидания экранируется; угловые скобки отклоняются. Проверка с разметкой в адресе включена в `check-account.cjs`. Длинные имя/адрес переносятся в узкой компоновке.
5. Старый фиксированный локальный сотрудник заменён теми же семью учебными контекстами. Ограниченные роли не получают суммы; маркетинг не открывает торговые данные.

## Визуальная проверка

[Нативный профиль Figma 1440×900](profile-evidence/figma-profile-native.png), [HTML 1280 px](profile-evidence/local-profile-1280.png). Применены клиентские цветовые переменные, компоненты кнопок/навигации, сетка и внутреннее меню. Совпадает организация профиля; пиксельное равенство двух сред не заявляется. Figma в режиме «вписать» уменьшает весь кадр, HTML рисуется в размере окна.

Для узкой проверки штатное изменение размера IAB не применилось: фактическая ширина оставалась 1280. Вместо ложного мобильного снимка использовано неизменённое приложение в `responsive-review.html`, окно iframe **390×640**, ширина содержимого 375 с полосой прокрутки, scrollWidth 375. Проверены [меню](profile-evidence/local-profile-mobile-top.png), [форма с длинным именем](profile-evidence/local-profile-mobile-details.png), [диалог](profile-evidence/local-profile-mobile-dialog.png), [сеансы](profile-evidence/local-profile-mobile-sessions.png). Это адаптивный HTML, не отдельные мобильные макеты Figma и не проверка устройства.

Impeccable detector запущен один раз по `account.js` и `style.css`. Единственное предупреждение — распространённый шрифт Inter, существующий в согласованном kit; шрифт намеренно сохранён. Независимый finish reviewer после узких снимков: **ship в границах данного прототипа**. Документер сохранил действующую визуальную основу.

## Сборка и границы

Порядок адресного построения: существующие `model.json`/`common.js`, затем `profile-model.json`, `profile-state.js`, `profile-common.js`; отдельно `profile-screen.js`, каждый `profile-dialogs.js` с именованным JOB; `profile-polish.js`, `profile-navigation.js`, `profile-integrate.js`, последним `profile-reactions.js`. Эти файлы — construction source, не точная резервная копия Figma. Не запускать весь старый пакет поверх текущих экранов.

Внешняя авторизация, настоящие ключи, письма, серверные сеансы, денежные подтверждения и реальные операции отсутствуют. Нельзя считать учебную смену роли или перезапуск входом в настоящий аккаунт. Обновление страницы начинает новый пример; сохранение в памяти не равно серверному сохранению. Общая приёмка всей админки и последующие этапы плана этим пакетом не закрываются.
