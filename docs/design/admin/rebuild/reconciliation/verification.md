# Проверка денежной сверки

23.10.2026. Учебный прототип, не проверка серверной авторизации или реальных денежных операций.

## Автоматические проверки

- Локальная модель: 91 утверждение по семи назначениям; неизвестный результат, расхождение, частичное исполнение, версия снимка, заметки, фильтры, язык и независимость инцидентов.
- Регрессия: профиль 169, поддержка 91, обратная связь 85, инциденты 77, начальные данные 11 утверждений.
- 126 утверждений сохранённых реакций Figma проходят по семи назначениям; они проверены отдельно в `check-figma.json`; это выполнение модели реакций, а не имитация ручного просмотра всех сочетаний.

## Ручной проход

Локально: руководитель операций → Limitless → REC-102 → расхождение +4 → заметка → INC-102 → возврат → профиль → EN → возврат. Сотрудник STAFF-206, запись, результат и черновик сохраняются. Текст сотрудника не переводится. Проверены раскрытие пояснения, пустая заметка, сохранение заметки, сброс фильтра, клавиатурный фокус и сообщение о результате. Пять наблюдений фокуса сохранены отдельно.

Просмотрены настольные RU/EN и узкая карточка 390×640 последовательными снимками. Суммы и смысловые пояснения читаются; узкая версия прокручивается вертикально. Это не полный аудит доступности всех экранов.

На публичном сайте версии 3 фактически открыты REC-101 и REC-103. Неизвестный итог остаётся неподтверждённым; совпадение 8 USD не освобождает оставшиеся 12 USD. Проверка использует ту же опубликованную модель, что локальный пример.

Figma: вход руководителя → список → Limitless → REC-102 → проверка → окно результата → полная карточка → INC-102 → REC-102. Исправлены наложение пункта навигации, размер заголовка и исчезновение неизменённых слоёв после операции с переменными. Для результата и пояснения используется отдельное окно с явным возвратом; переменные сохраняются.

Дополнительно в Figma пройден EN → профиль → RU → «Вернуться к работе»: открывается REC-102 с тем же STAFF-206 и результатом +4. Подсказка расчёта закрывается явной кнопкой и возвращает полную карточку. Повторная публикация публичного сайта не потребовалась: эти последние исправления касались только native Figma.
