# Проверка вывода собственных средств — 26.10.2026

Исходный main: `c5fefce2665535fa54954a3219b551f7ad47097c`. Пакет реализует ADR-0060 только как учебный прототип. Реальных переводов, подписания и ключей нет.

## Локальная модель

`check-own-withdrawal.cjs`: 167 утверждений. Семь назначений RU/EN; три пары токен/сеть; обязательства, резервы и минимум; разные владельцы и независимые проверки личности; истечение учебного согласия и изменение назначения; запреты; неизвестный исход без повтора; подтверждение исходного перевода и однократный учёт. Изменение минимального остатка возвращает незавершённый вывод в редактируемый черновик, а не тупиковый экран подтверждений.

Регрессия: финансы 137; технический режим 603; контекст ролей 620; аккаунт 169; сверка 91. Это тесты модели в памяти, не доказательство серверной авторизации. `npm run check`, `npm run test:repository` и `git diff --check` выполняются перед коммитом.

## Ручной браузерный проход

- Владелец A: USDC/Ethereum, полный учебный адрес, 100 USDC и назначение → проверка → независимое согласие.
- Явный выход/вход другого владельца с EN сохраняет точный перевод; второй участник подтверждает самостоятельно. Неизвестный результат удерживает резерв и не предлагает повторную отправку. Подтверждение исходного результата даёт остаток 900 USDC из 1000, свободно 550 после обязательств/резервов/минимума.
- Профиль → язык EN → возврат на мобильном экране сохраняет сотрудника, 100 USDC, адрес и введённое назначение. Пользовательский текст не переводится автоматически.
- Мобильная форма: viewport 375×844, ширина документа и scrollWidth 360; лишней горизонтальной прокрутки страницы нет. Ввод адреса дополнен полным переносимым предпросмотром; review также показывает полный адрес. Физический телефон не проверялся.
- Публичная версия 17 открыта через реальное меню владельца: Финансы → Собственные средства. Три маршрута присутствуют. [Публикация](publication.json).

## Дизайн и ограничения

Ручной native Figma проход: владелец A / RU → USDC Ethereum / 100 / полный адрес → проверка личности → 1/2 → явный выход → EN / владелец B → тот же перевод → отдельная проверка личности → 2/2 → отправка / неизвестный результат → повтор отклонён → подтверждающие данные → сверка исходной операции / однократный учёт. До согласий отправка также отклонена. [Наблюдения](manual-figma-trace.json). После изменения переменных Figma временно исключала часть кнопок из дерева доступности, хотя они оставались видимыми и работали; продолжение проверено нажатием по актуальным снимкам. Это ограничение Figma Present, а не подтверждение доступности рабочего HTML.

Проверка текущей страницы: 228 корней, 114 настольных и 114 мобильных; новый маршрут — 12 из них. Исправлены переносы меню и высота мобильных экранов: форма 390×1651, проверка 390×1432, минимум 390×1216. Снимки Figma показывают исходные значения переменных, поэтому имя сотрудника на статическом экспорте не является записью ручного входа владельца.

Дополнительно вручную проверено изменение минимума на 0 двумя владельцами в локальной версии: возврат сохраняет реквизиты, требует новой отметки проверки и создаёт новую версию без прежних согласий. Старый снимок local-en-confirmed.png сохранён как промежуточное наблюдение; финальное отображение свободных средств учитывает резерв текущего запроса.

В Figma добавлены шесть общих RU/EN настольных и шесть мобильных корней: форма, проверка, минимум, выбор источника, учебных значений и исхода. [Реестр](figma-build-result.json). Существующие финансовые экраны ведут в новый раздел; профиль и смена владельца сохраняют рабочий шаг. Construction scripts — история построения и ремонта, не точный backup и не идемпотентная миграция.

Figma использует выбор подготовленных значений, а HTML — произвольный ввод. Проверка формата адреса не подтверждает принадлежность или поддержку зачисления; контрольные суммы/сетевая проверка и реальная оценка комиссии требуют реализации. Учебное время согласия 5 минут не задаёт производственный срок. Состояние хранится только в текущей вкладке; два независимых реальных браузера не синхронизируются.

Impeccable detector запущен один раз: единственное предупреждение — существующий Inter; шрифт сохранён по согласованному kit. Независимый финальный обзор выявил тупик после изменения минимума; исправление и полный мобильный preview получили ограниченный verdict `ship`. Это не общая приёмка админки.
