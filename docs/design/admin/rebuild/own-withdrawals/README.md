# Вывод собственных средств

26.10.2026. [Принятые правила](../../../../decisions/0060_service_own_funds_external_withdrawals.md).

Вход: Финансы → Собственные средства; также из карточки собственного источника. Денежные действия доступны только двум владельцам; просмотр определяется финансовыми правами сотрудника. Источник / актив / сеть → полный произвольный адрес → сумма и назначение → отметка проверки → точная версия → проверка личности и согласие каждого владельца → учебная отправка → сверка результата.

- USDT TRC-20, USDT ERC-20, USDC ERC-20; ожидания нового адреса нет.
- Полный адрес, сумма токена и отдельная комиссия сети; клиенты и партнёрские выплаты не смешиваются.
- Минимальный остаток на источник/актив меняется двумя владельцами; 0 допустим, обязательства и резервы сохраняются.
- Редактирование сбрасывает согласия. До отправки можно отменить. После неё результат неизвестен до подтверждающих данных; повтор запрещён.
- RU/EN и смена владельца через явный учебный выход сохраняют перевод в этой вкладке. Перезагрузка страницы начинает новый учебный сеанс. Настоящих ключей и операций нет.

Figma моделирует выборы из учебных вариантов; свободные адрес и сумма вводятся на сайте. Ни один результат прототипа не подтверждает серверную авторизацию или состояние сети.

Визуальное направление сохраняет действующий финансовый UI kit; идея раздельных доступного остатка и журнала сверена с [референсом кошелька](https://dribbble.com/shots/27525708-Digital-Wallet-App-UI-Design-Fintech-Mobile-Dashboard). Референс не источник денежных правил.
