# Возврат к рабочей выборке

Возврат из карточки к списку должен сохранять выбранную страницу, применённый отбор и область доступа. Посещение личного профиля и смена языка не меняют исходную выборку и не заменяют её историей переходов браузера.

Для карточек TKT-1060 и TKT-1027 исходный список — вторая страница поддержки. Их кнопки ведут туда напрямую в соответствующей локали. У более общих карточек, доступных из нескольких списков, следует хранить явный ключ исходной выборки. Не подменять неизвестный контекст чужой ролью.

Черновик фильтра и применённый отбор — разные состояния. Прямое открытие готового кадра по ссылке не является применением фильтра. Сброс и переход к общему каталогу допустимы только как понятно подписанные самостоятельные действия.

Боковое меню должно выделять текущий рабочий раздел. В профиле сохраняется личная навигация; возврат восстанавливает раздел исходной записи. Выделение раздела не является серверной проверкой прав.

В реализации сохранять фактические значения и проверять актуальные права на сервере. Повторное открытие записи после отзыва доступа должно иметь отдельный безопасный исход; макет не реализует такую проверку.
