# Русский язык документации админки

Правило владельца от 14.10.2026: материалы для согласования пишем на понятном русском языке. Английский термин, если он нужен разработчику, указываем один раз в скобках при первом упоминании или в этом словаре. Далее используем русский вариант и нужный по контексту падеж.

| Технический термин | Русский вариант |
| --- | --- |
| Owner | владелец |
| Unknown | результат неизвестен / операция с неизвестным результатом |
| scope | область действия |
| version | версия |
| policy | правило или политика — по смыслу |
| live | реальный режим |
| jobs | задания; для фоновой работы — фоновые задания |
| preflight | повторная проверка перед отправкой |
| control | ограничение — в аварийном управлении |
| submitted | отправлено; для операций — отправленные операции |
| evidence | подтверждающие данные |
| health | состояние подключения |

Названия площадок и продуктов сохраняем. Идентификаторы прав, коды ограничений, поля API, ссылки и названия технических файлов не переводим. В пояснениях раскрываем их смысл по-русски. Не используем механическую замену без проверки грамматики и контекста.

В справочнике Google Docs обновлены 71 абзац, включая ADM-13–17 и общие пояснения. Это языковая правка: полномочия, операции и правила не изменены. Изменения перечислены в changes.json. Макеты Figma в этом цикле не менялись.
