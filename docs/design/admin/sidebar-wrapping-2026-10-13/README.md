Только дизайн существующей админки. 292 RU + 292 EN; UI kit 0.4.14, 23 набора / 142 варианта. Структура меню, названия разделов, маршруты и роли сохранены.

## Исправления
- Admin/Navigation item 2032:81: во всех шести состояниях высота зависит от содержимого (counterAxisSizingMode AUTO), минимальная высота 44 px. При переносе растёт весь пункт с фоном выбранного состояния.
- Текст HEIGHT с заполнением доступной ширины. Не сокращать важные названия ради фиксированной высоты.
- Все варианты используют общие Label#2033:0 и Icon#2032:2. В Hover/Focus/GroupOpen/Disabled отсутствовали привязки: выводился Overview и исходная иконка. Привязки восстановлены.
- Внутренние группы имеют фиксированную ширину 208 px в sidebar 248 px и адаптивную высоту. Group items больше не сохраняет ширину, рассчитанную для горизонтального расположения. Пункты внутри группы имеют HUG по вертикали.
- Отключена обрезка в служебном контейнере списка; отсутствие обрезки не заменяет проверку границ.

Предыдущая проверка table-flow касалась непосредственных границ текста. Для бокового меню проверка теперь учитывает clipping ancestors и реальный Present. Старые финансовые меню являются FRAME композициями: их нельзя исключать из аудита по типу INSTANCE или имени Admin navigation.
