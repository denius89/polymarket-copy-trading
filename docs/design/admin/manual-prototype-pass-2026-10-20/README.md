# Ручной проход прототипа админки

20.10.2026. Исходный Git main: `0843365002199479fd52c1648b986b51659cb891`. Работа выполнена в существующем файле Figma, без отдельной ветки дизайна и без разработки приложения.

В браузере пройдены основные переходы 19 сценариев проверки RU/EN. Дополнительно проверены сборщики данных и операционные уведомления. В журнале отдельно сохранены загрузки, прямые открытия отдельных учебных исходов и нажатия внутри сценария. Прямой переход по ссылке не выдаётся за проверенную кнопку.

**Это не полная приёмка всех 825 состояний и всех сочетаний прав, возвратов и ошибок.** Не проверялись реальные ключи, переводы, серверные ограничения и интеграции. Незакрытые пункты прежней сверки сохраняются ниже; весь дизайн не объявлен готовым к разработке.
