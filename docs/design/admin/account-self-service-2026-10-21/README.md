## Что можно прокликать

- **Личные данные:** черновик имени, обязательное поле и исправление ошибки, сохранение/отмена, учебный аватар с предпросмотром. Сохранение обновляет шапку; отмена не публикует черновик.
- **Email:** новый адрес → повторная проверка личности → ожидание подтверждения → подтверждение. Прежний адрес действует до последнего шага. Есть повторная отправка, истекшая ссылка и отмена.
- **Защита:** новая проверка для каждого изменения, пароль по возможностям провайдера входа, замена средств защиты, резервные коды с однократным показом недействительного образца. Владельцам нужны два разных отдельно зарегистрированных и проверенных физических ключа; остальным сотрудникам — защита по назначению.
- **Свои сессии:** завершение одной другой сессии или остальных с подтверждением, отмена, ошибка до выполнения и неизвестный результат. Неизвестный результат не помечает сессию завершённой и блокирует повтор до сверки. Текущий выход — без второго запроса.
- **Восстановление:** отдельный экран без рабочего меню, разрешённое подтверждение, новая защита, для владельца две отдельные проверки ключей, затем новый вход. Старые сессии и денежные подтверждения не возвращаются.

Полные правила — [CONTRACT.md](CONTRACT.md). Права, финансовые правила, тарифы и подтверждения выплат не менялись.

## Согласованный вид и состояние

Компактная идентификация сотрудника, меню 2 + 10, обзор четырьмя карточками 2×2. Язык находится в настройках интерфейса, полномочия — в отдельном разделе только для просмотра. Использованы существующие редактируемые компоненты и токены, Inter, состояния полей и кнопок. UI kit **0.4.21**: новых мастеров и отдельной ветки Figma нет.

Сведения сохраняются по STAFF-ID. Два назначения Норы используют общие данные аккаунта и состояние сессий, но раздельные рабочие контексты, выбранные разделы и черновики. RU/EN одного контекста разделяют значения и текущие шаги. Существующий точный возврат к рабочему экрану сохранён; прямой вход не подставляет чужую область.

Владелец A дополнен на существующих подробных маршрутах: интерактивные поля, отмена черновика, сохранённая идентификация/аватар, подтверждение email, повторная отправка/истечение ссылки и неизвестный результат сессий. Его права и ранее разделённые проверки двух ключей сохранены.

## Границы

Поля выбирают подготовленные значения по нажатию; произвольного ввода, загрузки фото, отправки почты и реального изменения ключей/паролей в Figma нет. Адреса, устройства, суммы и сотрудники учебные. Источник реальных данных и провайдер входа ещё подключаются на этапе реализации. Новая прямая ссылка или перезапуск начинает отдельный учебный сеанс.

Полная приёмка всех сочетаний, настоящая авторизация, срок проверок, запрет возврата браузером после выхода и серверный отзыв сессий требуют отдельной реализации и проверки. Этот пакет завершает обозначенные сценарии дизайна и не разрешает запуск продукта, реальные операции или изменение финансовых полномочий.
