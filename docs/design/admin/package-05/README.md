## Что изменено

- Иконка в верхней панели открывает профиль напрямую, как в клиентском UI (`1036:6136`). Личные настройки представлены карточками с переходами; основной sidebar сохраняет 13 пунктов.
- Имя/аватар, роль только для чтения, язык, безопасность, MFA/резервные способы, свои устройства и выход. 38 RU + 38 EN новых экранных состояний на существующих страницах, всего 508.
- Все 432 прежних RU/EN-контрола удалены. В 209 существующих авторизованных экранах каждого языка появилась кнопка профиля; на 7 auth/recovery экранах профиля нет. С новыми экранами — 242 входа в профиль на язык.
- Смена языка касается предпочтения сотрудника. Управление языками/текстами проекта остаётся отдельной функцией. В Figma переход между страницами RU/EN открывает языковой прототип по URL; сохранение предпочтения сервером ещё не реализовано.
- Два семейства UI kit: кнопка профиля и строка настроек, общие tokens/Inter. Source sets в существующей секции 02; витрина instances в секции 03. Версия 0.4.6, 17 семейств / 111 вариантов.

## Учебные данные и границы

Основной личный аккаунт — вымышленная STAFF-201 Елена Морозова / Elena Morozova, Owner A из SHADOW-ADM-01. Снимки результатов смены email/MFA/сессий — отдельные ветви, а не живой профиль. [Дополнение fixture](account-fixture.json). На других рабочих макетах подписи участников операций относятся к их сценарию; профиль в этой review-ветви использует STAFF-201. При реализации он всегда берётся из текущей авторизованной identity, никогда из чужой карточки сотрудника.

Парольный вход и приложение-аутентификатор — учебный вариант, провайдер/политика не утверждены. Настоящих паролей, QR, MFA-secret и резервных кодов в Figma/Git нет. Аватар — инициалы; file upload и crop не работают в прототипе. Ни один экран не меняет Owner-only денежные права, не допускает самостоятельного повышения роли и не заменяет runbook потери обоих Owner.
