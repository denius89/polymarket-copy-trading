## Согласованные ограничения

Два личных Owner; Operations объединяет поддержку и операционную работу. Кастомные роли не получают Owner-only денежные полномочия. Сохранение шаблона роли отдельно от назначения человеку. Маркетинг и контент публикуются по праву с журналированием, без постоянного согласования Owner.

Аварийное ограничение включает один действующий уполномоченный сотрудник. Возврат требует Owner и другого независимого действующего уполномоченного сотрудника по одной области/версии. В примере второй — Owner B; правило не ограничено исключительно двумя Owner. GLOBAL_STOP не подменяет восстановление отдельного подключения или аккаунта.

Изоляция в Shadow не доказывает отзыв credential у площадки. Уже отправленные операции продолжают сверку. Старые неотправленные денежные заявки после возврата требуют нового preflight и подтверждения инициатора; неизвестный результат не разрешает повторную отправку. Запрет пополнений скрывает новые инструкции в Shadow, но не останавливает прямой перевод на известный адрес; отдельный экран показывает наблюдение и дедупликацию.

Потеря обоих Owner ведёт к защищённому внешнему runbook. Макет не предлагает master key, самоназначение или обход проверок. Боевой механизм восстановления и ответственные ещё должны быть выбраны до реализации.

## Учебный набор

[SHADOW-ADM-01](../fixtures/README.md) связывает пять вымышленных сотрудников, две площадки, сессии, роли и события. В UI нет реальных персональных данных, ключей или рабочих credentials. Поля статические; кнопки переключают подготовленные состояния.

Нормальная работа и сбои — независимые снимки сценариев, а не один последовательный серверный журнал. Ветви изменения/отзыва роли помечены branch. Котировки $0.9998/$0.9997 и профиль предупреждения 0.5%, критического отклонения 2%, длительности 180 s — учебные значения, не утверждённые production-defaults. Расхождение источников измеряется в процентных пунктах относительно $1: учебный максимум 0.20 п.п. Внутренний учёт остаётся 1 USDT = $1 без исторического пересчёта. Источники рекомендует [документ 120](../../../120_usdt_usd_sources_and_admin_alerts_2026-10-12.md); live не подключён.

Финансовый пример прошлых макетов сохраняется отдельно как будущий платный этап: $160 доступно, $18 pending и $25 резерв, всего $203 обязательств. Это не alpha-баланс; частичных выплат нет. Все существующие финансовые/клиентские макеты этим пакетом заново не наполнялись.

## UI kit и передача

Ревизия 0.4.5: новый исходник Admin/Metadata row с Title/Detail/Meta, общими токенами и Inter; alerts адаптируют ширину текста через Fill и растут по высоте. Нет новых token collections. Desktop 1440: sidebar 248, основной контейнер 1192, сетка 12 колонок, gap 16, поля 24. Форма входа отдельно центрирована и имеет ширину 560. Адреса по-прежнему показываются полностью.

Construction/refresh/wiring helpers — исторические рецепты сборки, не точный backup и не код приложения. Не запускать их повторно вслепую. Источник актуальных ID — manifest и живая Figma. Перед разработкой читать свежий main, сверять экран и связанные компоненты; дизайн-состояния не являются контрактом API.

## Граница готовности

Структурно проверено 125 затронутых макетов каждого языка; выбранные реальные переходы прокликаны в Present RU. Полная вычитка всех 432 состояний и принятие с коллегой ещё впереди. Настоящие MFA, защищённая копия аудита, маршруты площадок, external security channels, server authorization и мониторинг не реализованы.

Следующий дизайн-пакет: поддержка, управляемые тексты/языки и объявления внутри приложения. Конструктор лендинга, ротация интеграционных ключей и массовые email/Telegram/push остаются позже.
