# Внутреннее меню админки · 13.10.2026

Применена логика референса Settings: внутри раздела — меню слева, содержимое справа. Главный sidebar и breadcrumbs сохранены. Только дизайн, без новых экранов и функций; всего 291 RU + 291 EN.

## Где применяется

- 33 состояния личного аккаунта сотрудника на каждом языке: обзор, личные данные/аватар, язык, безопасность, свои сессии и просмотр прав, включая связанные формы и результаты.
- 4 состояния профиля пользователя: Noor, настройки Atlas/Noor и отдельный просмотр Operations.
- 5 самостоятельных экранов восстановления входа оставлены без внутреннего меню и без изменений. Доступ к настройкам не предлагается до проверки личности.
- Финансовые таблицы, очереди и другие широкие рабочие разделы этой правкой не затронуты.

Личное меню: Обзор, Профиль, Язык, Безопасность, Мои сессии, Роль и доступ. Меню пользователя: Профиль, Настройки; ниже отдельная группа Связанные разделы — Сессия и К списку. Названия короткие, текущий пункт выделен. Роли и полномочия не изменены; Operations VIP остаётся disabled.

## Компоновка и UI kit

12 колонок основного контейнера: **2 + 10**. Меню 177.33 px, gap 16 px, область содержимого 950.67 px. Если есть контекстная карточка справа, рабочая область делится на 6 + 4 глобальные колонки (564 + 16 + 370.67). Для формы поля и действия адаптированы по ширине; Auto Layout переносит длинные тексты и группы кнопок.

UI kit 0.4.10: Admin/Section navigation (2233:1217), 6 вариантов Active, общий Admin/Navigation item, Title и видимость служебных пунктов. Витрина 2248:93029 показывает аккаунт и профиль пользователя. Live user menus сохраняют ID существующих tab instances и используют те же nav-item masters; staff menus используют Section navigation instances. Поля и исходные переходы операций сохранены; ничего не удалено.

## Прототип и проверки

Проверены границы всех 37 компоновок RU и EN: навигация/содержимое совпадают с сеткой, горизонтального переполнения нет. Визуально проверены профиль Noor, личные данные, безопасность RU/EN и UI kit. В Present проверены переходы обзора аккаунта к безопасности и языку и выделение текущего пункта.

Figma при native NAVIGATE иногда не дорисовывала неизменённую панель identity; reload восстанавливал её. Для демо локальные пункты используют same-tab Figma prototype URLs с полной загрузкой целевого экрана. **В приложении — внутренний router, не Figma URL**; независимые проверки прав, контекста и несохранённых изменений остаются задачей реализации/приёмки. Полная ручная приёмка всех 582 состояний не заявлена.
