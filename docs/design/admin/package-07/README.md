## Что входит

Каталог с ключом/назначением, экраном, языками, статусом, версией и автором; поиск и фильтры. Редактор RU/EN рядом, неизменяемый ключ, typed placeholders, ограничения и комментарий. Проверка пропущенного перевода, переменной и длины; сохранение черновика и конфликт чужого изменения.

Предпросмотр связанного подтверждения вывода RU/EN с полным адресом и недоступными денежными действиями. Подготовка единого набора, выполнение, подтверждённый успех/ошибка и неизвестный результат. История, просмотр B-12, предпросмотр старых значений, восстановление новой публикацией B-14. Просмотр без редактирования, отсутствие доступа и редактирование без права публикации.

Языки проекта RU/EN и неактивный черновик Arabic/ar. Добавление черновика не включает язык; RTL и дополнительные launch locales не объявлены готовыми. Резервный EN в форме — демонстрационное значение, не новое решение о production fallback.

Раздел доступен в «Управление». На главном каталоге нет повторяющихся хлебных крошек; вложенные страницы показывают путь возврата. Новых Figma страниц/веток нет.
