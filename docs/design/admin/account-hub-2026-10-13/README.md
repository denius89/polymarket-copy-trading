## Компоновка

- Обзор: компактная шапка сотрудника (инициалы, имя, роль, email, просмотр своих прав), ниже четыре карточки 2×2: личные данные, безопасность, интерфейс, устройства/сессии.
- Локальное меню: Обзор → Личные данные → Безопасность → Устройства и сессии → Настройки интерфейса → Мои права.
- Сетка 2 + 10: 177.333 px меню + 16 px промежуток + 950.667 px содержимое. Детальные страницы занимают всю рабочую область; постоянная правая колонка с повтором профиля убрана.
- Безопасность: действие рядом со своей настройкой (пароль, MFA, email, резервные коды). Повторное подтверждение личности и recovery flows сохранены.
- Устройства: шапка таблицы, устройство, последняя активность, статус, действие. Завершение отдельной сессии в строке; завершение остальных отдельной кнопкой. Текущее устройство помечено.
- Язык остаётся выпадающим списком в настройках интерфейса. Это язык сотрудника, не управление переводами продукта.
- Мои права остаются просмотром. Настройки своего аккаунта не дают права управлять другими сотрудниками.
- Во всех 280 шапках каждого языка аватар открывает «Мой аккаунт» / «Выйти». Выход ведёт на существующий учебный экран входа.
- Вымышленный STAFF-201 / Elena Morozova используется в прототипе. В продукте необходимо показывать текущего авторизованного сотрудника.
