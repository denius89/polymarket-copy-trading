## Что добавлено

- Редактор роли с полной матрицей 18 разделов и семью независимыми видами действий; отдельный пример флажков раздела поддержки.
- Площадка, среда, типы данных и срок назначения; итог перед сохранением, результат, конфликт версии и отказ самоэскалации.
- Рабочая область операционного сотрудника, минимальные карточки клиента, сессии и назначенного обращения; отсутствие денег в доступе не показывается нулём.
- Запреты другой площадки, реальной среды и действия; окончание срока назначения и блокировка аккаунта разделены.
- Аудитор без экспорта и отдельная ветвь с правом экспорта: параметры, подготовка, готовность, ошибка и отзыв до получения файла.
- Сводка критических действий, проверка владельца, отказ кастомной роли, самостоятельность маркетолога и ограниченные аварийные права.

Меню ограниченных ролей состоит из разрешённых компонентов навигации. Рабочие переходы не ведут из ограниченной роли в денежную область владельца. Служебные переключения примеров вынесены в «Сценарии прототипа». Они не являются рабочими командами продукта.

## Как вычитывать

1. Настройка роли → матрица разделов → «Поддержка» → отдельные действия → область и срок → итог → сохранение. В альтернативной ветви проверить конфликт, не перезапись.
2. В сценариях открыть операционного сотрудника: клиент → сессия → назначенное обращение. В меню нет финансов и управления сотрудниками; сумма не раскрывается и не заменяется нулём.
3. Пройти чужую площадку, реальную среду, отказ изменения, окончание срока и отзыв аккаунта. Отказ возвращает в ту же разрешённую область; отзыв аккаунта ведёт только к входу после выхода.
4. Аудитор: просмотр без экспорта → запрет. Отдельная ветвь с экспортом: параметры → подготовка → готовность / ошибка / отзыв права перед скачиванием. Отзыв одного экспорта оставляет разрешённое чтение.
5. Владелец: сравнить одинарные и двойные подтверждения; переходы строк ведут к существующим денежным сценариям. Новые реквизиты ждут 24 часа после второго владельца. Проверка личности не выдаёт права и не снимает ограничения.

[Учебный CSV](sample-access-export.csv) содержит только две вымышленные записи доступа, без адресов и денег. Его публичная ссылка нужна для вычитки примера. Реальные файлы должны выдаваться сервером после актуальной проверки прав и никогда не используют такую публичную схему.

## Границы

Основания и неизменённые согласованные правила перечислены в [контракте](contract.md). Примеры назначения, сроки и наборы прав не утверждают пресеты по умолчанию или поставщика входа. Приглашение B04 остаётся открытым. Новых денежных полномочий, торговли за пользователя, доступа к приватным ключам и автоматического восстановления нет.

Paper Alpha: комиссия Shadow 0%, реальные выплаты выключены. 1% — только неактивный пример будущей платной версии. Полные P-01–P-18/X01/X04, клиентский интерфейс, мобильные размеры, серверная авторизация, клавиатура и реальные API этим пакетом не принимаются. Личный кабинет сотрудника и полный сценарий ответа поддержки не перепроектируются этим срезом.

Конструкционные сценарии описывают выполненные операции и не являются точной резервной копией Figma. Источник макетов — текущие узлы; изображения и структурная проверка — датированные свидетельства. [Список проверок контракта](contract-checks.json) проверяет только синтетические примеры, не работающий механизм прав.
