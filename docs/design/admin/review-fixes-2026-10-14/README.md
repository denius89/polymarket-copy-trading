# Правки по вычитке · 14 октября 2026

Принятые изменения: защита входа владельцев основным и запасным физическими ключами; ограниченное восстановление без денежных прав; конкретные результаты блокировки сотрудника, выплат и аварийного восстановления. Обычная выплата — один владелец; изменение реквизитов — независимый второй владелец. Обязательной задержки после изменения адреса нет.

Документация данных и рейтинга синхронизирована с принятым расширением ADM-07: настройки сборщиков, валидатора и рейтинга, версии и раздельные права.

Изменены 35 экранов на каждом языке. Новые страницы и корневые экраны не создавались. UI kit остаётся 0.4.20.

Справочник Google Docs: 71 исправление проверено чтением, 422 карточки экранов сохранены.
