# Язык аккаунта сотрудника: выпадающий список

13.10.2026. Только дизайн админки. RU и EN остаются единственными включёнными языками; будущие языки добавляются через реестр, без изменения компоновки профиля. Настройка относится к аккаунту сотрудника, отдельно от управляемых переводов проекта (ADR-0034).

## Поведение
- Общий компонент Admin/Language selector: Locale RU/EN × State Closed/Open.
- Названия на языке оригинала, коды RU/EN и отметка выбранного варианта. Один chevron вниз.
- Выбор другого языка сохраняется автоматически; существующие language-saved и language-error состояния сохранены.
- Выбор текущего языка закрывает список без повторного сохранения.
- При ошибке прежний язык остаётся действующим. Backend отсутствует; это контракт будущего поведения.
- Когда включено более 8 языков, добавить поиск по названию/коду и прокрутку списка до 320 px. Сейчас поиск не нужен.
- В реализации: popover, клавиатурная навигация, Escape/клик вне списка и возврат фокуса. Эти клавиатурные сценарии не имитируются в текущем Figma-прототипе.
- В прототипе открытое состояние раскрывает карточку по высоте. Для обхода дефекта Present, скрывавшего соседний блок, переходы открытие/закрытие выполнены через same-tab URL. В продукте это локальное состояние, не переход страницы.
