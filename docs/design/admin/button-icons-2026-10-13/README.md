# Иконки кнопок админки · 13.10.2026

Только дизайн. Изменены существующие кнопки на RU/EN страницах и примеры Admin UI kit. 292 RU + 292 EN, UI kit 0.4.13; 23 набора / 142 варианта сохранены. Новые страницы, экраны и ветки не создавались.

## Правило
Обычная кнопка по умолчанию содержит текст без иконки. Универсальная стрелка вправо больше не обозначает любое действие. Show icon по умолчанию false в четырёх текущих семействах и трёх legacy masters. Скрытый slot Icon сохраняется для совместимости; его нельзя показывать без явного выбора смысловой иконки.

- Сохранить, отменить, отклонить, остановить и обычные ссылки на разделы: текст без декоративной стрелки.
- Назад/возврат к разделу: стрелка влево. Это переход к указанной цели прототипа, не обязательно browser history.
- Обновить/повторить: refresh; редактировать/настроить: pencil; отправить: send.
- Пауза: pause; возобновить: play; предпросмотр: eye; подтвердить/применить: check; копировать: copy.
- Подпись обязательна. Опасность дополнительно передаётся Danger стилем; иконка сама не подтверждает полномочие.
- Стрелки раскрытия списков и групп меню сохраняют своё значение.
- Loading spinner, hover/focus/disabled состояния и реакции кнопок сохранены.

Переиспользованы существующие Admin и Client icon masters, новые иконки не создавались. Нормализация подписей в журнале операций служит для миграции существующих макетов; при новых макетах выбирать иконку явно по смыслу действия, а не запускать регулярные выражения в frontend.

## Проверка
785 экземпляров кнопок на каждом языке обработаны, включая 230 legacy экземпляров на язык. Повторная структурная проверка: generic forward-arrow buttons 0, пересечения соседних auto-layout элементов 0, выходы текста за непосредственный блок 0 на RU/EN. Это проверка данного класса дефектов, не полная ручная приёмка всех экранов.

Витрина проверена визуально: [Admin UI kit · действия](https://www.figma.com/design/lxPP2um7FvIbt02K8eeH4T?node-id=2274-1082). QA и журналы операций рядом. Backend, реальные полномочия и маршруты не менялись. Пакет локальный; в GitHub не опубликован.
