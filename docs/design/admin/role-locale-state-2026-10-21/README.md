Два назначения Норы имеют разные переменные возврата и разные профили. Совпадение сотрудника не объединяет права. Никакая ветвь языкового списка этих ролей не открывает профиль владельца A.

Смена языка переносит 33 существующие пары подготовленных значений. Рабочий экран и его название дополнительно записываются сразу для RU и EN при входе в профиль — отдельно для каждого назначения. Кнопка «Назад к рабочему экрану» использует точный сохранённый ключ, а не историю браузера. Поэтому переход в профиль, смена языка и возврат не оставляют пользователя в цикле двух профилей и не возвращают на общую главную вместо исходного состояния.

При прямом входе в профиль по ссылке рабочий контекст не выбран: кнопка возврата скрыта, показано пояснение. Язык по-прежнему можно выбрать. Неизвестный ключ возврата не подменяется рабочей областью другой роли. Выбор уже активного языка и закрытие списка не меняют сотрудника и рабочие данные.
