# Проверка и ограничения

Исходный main: `1eec4c63b2a1273333046b0c62f789647534063a`. Область — продолжение L08/L11/L13. Проверяются подготовленные учебные маршруты, не весь продукт.

| Способ проверки | Подтверждение | Предел |
| --- | --- | --- |
| Ручные нажатия в прототипе RU/EN | `manual-checks.json`: фактическое дерево экрана, действия, переходы | Не считать название шага доказательством: ранние неудачные попытки сохранены |
| Данные Figma после исправлений | `native-final-readback-*.json`, `native-filter-*.json` | Размеры, шрифты, привязки, реальные записанные реакции; не серверное исполнение |
| Прогон записанных реакций | `verify.mjs`: 486 сочетаний пяти меню, сохранение применённых значений при ошибке, 12 маршрутов возврата | Интерпретация ограниченного набора действий, а не 486 ручных кликов |
| Полноразмерные снимки Figma | PNG в пакете | Визуальный контроль; браузерные JPEG при узком текущем окне пригодны только как контекст переходов |
| Чтение Google Docs после правки | `guide-sync.json` | 878 уникальных карточек, прежние 852 сохранены, 52 новые ссылки; PDF не проверялся |

Ручной проход включает совместный отбор и отрицательные сочетания, ошибочный период, возврат с прежними значениями, отмену, очистку, карточку и устаревший результат; обе страницы сессий; точную выборку по счётчику; загрузку, ошибку и повторное чтение; выбранную денежную сверку; обе карточки второй страницы поддержки и сохранение фильтра; положительное закрытие инцидента, отмену, недостаток подтверждений и конфликт версии.

После последней правки отмены отдельно пройдены RU/EN: до первого применения → общий список; устаревший результат → редактирование → отмена → тот же устаревший результат. Старые записи до исправлений не выдаются за успешные.

Ролевые боковые меню новых экранов проверены по известным ссылкам владельца; это не проверка серверных прав. Последнее повторное чтение содержимого не заменяет исходную ролевую проверку. Сценарий прямого общего входа в денежную сверку после выбранного входа исправлен в реакциях; отдельный браузерный повтор этого пересечения не заявлен.

Не проверены все сочетания всех списков админки, произвольный ввод/календарь, адаптивная реализация, клавиатурная доступность и реальные подключения. Общий проход L17 и приёмка коллегой остаются открытыми. Настройки размера окна и чтения экраном не изменялись; исходная пользовательская вкладка оставлена открытой и возвращена к исходному прототипу.

Скрипты построения — воспроизводимые записи отдельных изменений с внешним CONFIG, не точная резервная копия Figma. Не запускать их на другом состоянии без сверки ID и текущего файла.
