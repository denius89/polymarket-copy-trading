# Проверка обзора

Проверка ограничена шестью изменёнными корнями и новым семейством графиков. Полная приёмка админки, серверные права и доступность работающего сервиса не заявлены.

- Структура: шесть прежних корней, общая сетка 12 колонок и прежние заголовки сотрудника. Новые блоки не выходят по ширине за родителя.
- Учебные данные: все участники почасовых интервалов входят в существующий список; счётчики равны двум пользователям, двум сессиям и одному неизвестному результату. Период истории не меняет текущие счётчики.
- Ручной просмотр: раскрытие данных, 6 часов, возврат через профиль и переход RU → EN с сохранением шести часов и раскрытых данных; сотрудник Елена Морозова / STAFF-201 остался прежним.
- Найдено и исправлено: новое действие «Открыть сессию для сверки» наследовало переход счётчика в список. Действие и строка таблицы перенаправлены прямо в S-DEMO-002; счётчик сохранил переход к выборке.
- RU/EN: подписи источников уточнены; единственное число `1 user` исправлено. Учебные переходы сведены в отдельную группу.
- Ограничение просмотра Figma: после переменных часть неизменившихся элементов исчезает из дерева доступности, сохраняясь в изображении. Проверку продолжали через навигацию, не выдавали исчезновение дерева за потерю данных. Настройки пользователя не менялись.
- Не проверено этим проходом: все роли и сочетания устройств, реальные источники, перезагрузка с хранением состояния, клавиатурная доступность приложения, финансовые аналитические экраны. Прямой вход/перезагрузка прототипа начинает самостоятельный учебный сеанс.

Итоговые структурные и визуальные свидетельства, проверки переходов и проверка справочника сохраняются в этом пакете. Проверки репозитория перечисляются после фактического выполнения.

Выполнено: `npm run check`, `npm run test:repository`, `git diff --check` — успешно. Ручные цепочки — в `manual-observations.json`; это одиннадцать кратких записей о проверках, не одиннадцать независимых полных приёмок.

Окончательная геометрия: окно обзора 1440 × 1000, Main прокручивается вертикально. Прокрутка нижних блоков с неподвижным меню подтверждена в Present. Сессии сгруппированы по наличию замечаний, без вывода о завершении неизвестной заявки.

Дополнительно: проверены синтаксис скриптов построения, состав почасовых участников, соответствие счётчиков и отсутствие временных ссылок на снимки в текстовых файлах. Пиксельная проверка не является измерением доступности работающего интерфейса.
