## Согласованные правила сохранены

Пользовательский VIP назначает один владелец; денежные партнёрские условия проходят отдельный согласованный процесс. Paper Alpha: комиссия сервиса 0%; 1% — только пример будущей неактивной версии. Внутренний учёт 1 USDT = $1. Партнёрский долг выплачивается целиком по выбранной площадке; неподтверждённое не доступно. Если комиссию перевода оплачивает партнёр, она отдельно удерживается по явно выбранному правилу, а не образует частичную выплату. Неизвестный результат запрещает повторную отправку до сверки. Новые реквизиты: два подтверждения и задержка 24 часа.

Проверка выплаты показывает срок согласия как **не заданный в этом демо**. Это не бессрочное согласие и не разрешение отправить деньги. При реализации нужно получить действительное значение из правила, отобразить его и повторно проверить перед отправкой; изменение параметров аннулирует согласие. Новые численные правила этим пакетом не принимаются.

Технический режим закрывает пользовательское приложение и публичный API, новые торговые/денежные действия через Shadow и продуктовые фоновые задачи. Работают только аварийная админка, наблюдение, журнал, инциденты, безопасная сверка и восстановление. Сверка ничего не отправляет; ранее отправленные внешние операции могут завершиться.
