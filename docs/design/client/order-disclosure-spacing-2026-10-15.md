# Раскрытие «Подробности заявки»: расстояние до значка

По замечанию владельца на клиентских RU/EN desktop/mobile страницах знак `+` стоял у правого края широкого блока, далеко от короткого заголовка. Исправлены **24 экземпляра** `Shared/Disclosure`: по три на каждой из восьми страниц — исходные mobile EN `29:2`, mobile RU `33:2`, desktop EN `186:2`, desktop RU `205:2` и соответствующие Final `2499:2`, `2477:528`, `2499:3`, `2477:529`. Админка и master-компонент не менялись.

У текстового слоя `Title` убрано заполнение всей ширины (`layoutGrow=0`); ширина теперь определяется текстом. Между подписью и знаком остался системный интервал 8 px. Внешний `Disclosure trigger` по-прежнему занимает всю ширину 318 px на mobile и 712–728 px на desktop, поэтому зона нажатия не уменьшилась. Существующая реакция `CHANGE_TO` на каждом trigger сохранена. Примеры: [RU desktop](https://www.figma.com/design/lxPP2um7FvIbt02K8eeH4T?node-id=2499-4127), [RU mobile](https://www.figma.com/design/lxPP2um7FvIbt02K8eeH4T?node-id=2498-29356), [EN desktop](https://www.figma.com/design/lxPP2um7FvIbt02K8eeH4T?node-id=2504-6181).

После правки просмотрены рендеры этих трёх кадров: текст и `+` стоят рядом, перекрытия нет. Полный ручной Present всех 24 экземпляров не выполнялся. Определение компонента, его варианты, токены и реестр UI kit не менялись; изменены только экземпляры клиентских экранов. Локальный Git-отчёт не считать опубликованным в GitHub до отдельной публикации.
