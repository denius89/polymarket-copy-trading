# Карточка «Что изменится»: спокойный список

15.10.2026 по замечанию владельца удалены яркие бирюзовые точки перед пояснениями в карточках «Что изменится» / “What changes”. Три строки теперь начинаются на одной оси с заголовком. Текст, бейдж и смысл состояний сохранены. В RU-варианте, где первая строка была скрыта, также скрыт пустой контейнер этой строки, чтобы список начинался без лишнего отступа.

Изменены по два `Context panel` на каждой из четырёх десктопных клиентских страниц: исходные [EN](https://www.figma.com/design/lxPP2um7FvIbt02K8eeH4T?node-id=186-2) (`219:83`, `506:46`) и [RU](https://www.figma.com/design/lxPP2um7FvIbt02K8eeH4T?node-id=205-2) (`220:309`, `506:165`), [EN Final](https://www.figma.com/design/lxPP2um7FvIbt02K8eeH4T?node-id=2499-3) (`2529:135426`, `2529:135581`) и [RU Final](https://www.figma.com/design/lxPP2um7FvIbt02K8eeH4T?node-id=2477-529) (`2529:22170`, `2529:133749`). Удалены 24 эллипса-маркера; строки сохранились. Пустая скрытая строка убрана из потока в `506:169` и `2529:133753`.

Проверка: структура всех восьми карточек после правки показывает отсутствие эллипсов и положение видимого текста `x=0` внутри строки; визуально просмотрены оба состояния RU Final (`2529:22170`, `2529:133749`). На мобильных клиентских страницах такой карточки с точками нет. Прототипные переходы и админка не менялись. Ручной Present всего маршрута не выполнялся. Пакет локальный; GitHub не обновлялся.
