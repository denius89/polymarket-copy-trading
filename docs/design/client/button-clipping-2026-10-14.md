# Клиентские экраны · устранение обрезки кнопок

Дата: **14.10.2026**. По скриншоту владельца проверены клиентские экраны и кнопки в Figma-файле [Controlled Copy Trading — Paper MVP](https://www.figma.com/design/lxPP2um7FvIbt02K8eeH4T). Админка не входила в работу и не менялась.

## Причина и исправление

На мобильных экранах рамка 1 px была включена в расчёт автокомпоновки повторяемой панели `App shell / Bottom navigation`: четыре вкладки начинались с `(1, 1)`, имели размер `87,5 × 64`, а последняя заканчивалась на `x=351` при ширине панели 350 px. Нижняя и правая границы кнопок обрезались включённым `clipsContent`.

На **всех 274 панелях** четырёх клиентских мобильных страниц RU/EN, включая страницы «Финал» и скрытые сохранённые копии, установлено `strokesIncludedInLayout=false`. Вкладки теперь начинаются с `(0, 0)` и помещаются в контейнер без изменения его ширины, экранной позиции, текстов или реакций. Для четырёх 72-пиксельных панелей утверждённых каталогов задан равный вертикальный отступ 4 px; кнопки высотой 64 px расположены по центру.

Отдельно найдены **19** видимых подписей внутри кнопок, которые выходили на 1 px за свою обрезающую внутреннюю группу, хотя помещались в саму кнопку: 8 на исходных мобильных страницах и 11 на исходных десктопных. Обрезка выключена только у этих внутренних групп. Родительские кнопки, их размеры и реакции сохранены. Скрытые вспомогательные слои не принимались за видимые дефекты.

## Правило для новых экранов

При создании мобильной панели с рамкой и четырьмя равными вкладками не включать рамку в расчёт их места: `strokesIncludedInLayout=false`. Для панели шириной 350 px каждая вкладка должна занимать 87,5 px; до обрезки и после смены языка проверить `x >= 0`, `y >= 0`, `x + width <= panel.width`, `y + height <= panel.height` для всех вкладок, и аналогично подписи внутри каждой вкладки. Видимая панель должна помещаться в родительский экран. Для 72-пиксельной панели с 64-пиксельными вкладками использовать вертикальные отступы 4/4 px. Не закрывать проблему скрытием текста или изменением ссылки кнопки.

Историческая запись построения `design/qa-2026-10-03/recovery-builder.js` дополнена этим свойством, чтобы повторное использование её шаблона не создавало ту же ошибку. Она не является резервной копией актуального Figma-файла.
