# Компактный период на десктопном экране первого запуска

15.10.2026. По замечанию владельца кнопка единственного периода `30 д` / `30d` на десктопном профиле трейдера первого запуска занимала всю строку шириной 728 px. На обычных десктопных профилях каждый из четырёх периодов имеет ширину около 176–178 px; на мобильных экранах периоды тоже уже компактны. Проверены все восемь клиентских страниц RU/EN mobile/desktop, исходные и Final.

Четыре десктопных экземпляра первого запуска уменьшены до 177,5 × 48 px и выровнены по левому краю области контента. Контейнер, карточка результата и нижние блоки сохранили свои размеры и положение. Скрытые варианты 24 ч / 7 д / 90 д не показывались: у них нет переходов в этом сценарии, а показывать неработающие элементы было бы неверно. У `30 д`/`30d` в данном сценарии реакций также не было; правка не добавляет их.

Визуально просмотрены все четыре полных десктопных экрана первого запуска. Мобильные страницы и обычные четыре периода на других десктопных профилях не требовали изменений. Админка, masters и токены не менялись. Полный Present-клик не проводился; это визуальная правка прототипа. Пакет пока локальный, публикация в GitHub отдельно не подтверждена.
