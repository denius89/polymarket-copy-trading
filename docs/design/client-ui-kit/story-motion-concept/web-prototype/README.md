# Анимированное знакомство · интерактивный прототип

`index.html` показывает три мобильные сторис с готовыми видеосценами. Текст, кнопки и индикатор прогресса остаются HTML-слоями поверх видео. Переключатель RU/EN меняет интерфейс без перезагрузки; `?lang=en` открывает английскую версию напрямую. Кнопка «Далее», касание правой/левой половины сцены и клавиши ←/→ переключают шаги. Кнопка ↻ запускает текущий ролик заново; автоматического переключения нет. При смене шага фокус переходит на заголовок, новое состояние объявляется диктору. «Пропустить» и последний CTA явно подписаны как переходы в Figma и ведут к каталогу соответствующего языка. При реализации продукта обе ссылки заменить на локализованный клиентский маршрут `/traders` с сохранением контекста первого входа.

Видео и статичные обложки находятся в `../videos/`. Каждый MP4 длится 5 секунд, имеет размер 720 × 1280 и весит примерно 2,1–2,2 МБ. Загружается текущая сцена; следующая начинает предварительно загружаться после двух секунд просмотра. До появления видео видна обложка, а при ошибке загрузки или включённом системном режиме уменьшения движения остаётся статичный кадр.

Ролики можно обновить без изменения логики: заменить пары `01-signal.mp4`/`01-signal-poster.jpg`, `02-rules.mp4`/`02-rules-poster.jpg`, `03-demo.mp4`/`03-demo-poster.jpg` с сохранением вертикальной композиции и оставить текст вне видео. После замены проверить смысл RU/EN подписи, длительность, первый/последний кадр, вес, мобильную загрузку и reduced motion; опубликованная страница обновляется отдельным выпуском.

Это концепт для визуального согласования, не продуктовый frontend. В Figma пока сохранены статичные иллюстрации: MP4 подключены к этому веб-прототипу. Текст и примерные суммы взяты из текущей сторис Figma; он не задаёт серверные правила исполнения и не обещает доходность.

`layered-demo.html` и старые анимированные WebP в этой папке сохранены как предыдущие эксперименты. Основной просмотр теперь — `index.html` с видео.
