## Содержание и действия

Текущий режим обозначен как демо с виртуальными средствами. В демонстрации нет прибыли, публичного Copy Score или обещания live. $200/$20 — иллюстрация настройки, а не новый минимум/тариф или подтверждённая торговля. Пример пропуска не является записью собственной новой сессии.

Маршруты по [ADR-0048](../../../decisions/0048_unified_registration_and_first_entry.md):

- «Начать» / Get started → единый email-вход, далее выбор трейдера для нового пользователя без черновика.
- «Посмотреть трейдеров» / Explore traders → гостевой каталог.
- «Войти» / Log in → продолжение по фактическому состоянию сессии/черновика.

В этом визуальном пакете кнопки **не связаны** со старыми auth-переходами, не соответствующими новому сценарию. Следующие экраны и обновление auth-прототипа не входят в поручение. Переключатели языка представлены визуально; интерактивный language flow не принимается этим пакетом.

## Проверка и пределы

- Визуально просмотрены все четыре итоговых кадра. После обнаружения наложений исправлены auto-height текста, переносы, расстояния и насыщенность декоративного света.
- Структурно: на каждом кадре 0 найденных наложений соседних auto-layout элементов, 0 instances без master, все TEXT используют Inter, 0 image-filled nodes. Полная UI-растеризация не использовалась; слои и тексты редактируемые.
- Контент укладывается в высоту заданных кадров; PNG получены из финального Figma-состояния.
- Present/click-through, реальные email/API/данные, runtime accessibility/performance, 320/360/1280 и увеличение текста 200% не проверялись. Наличие вариантов kit не подтверждает эти проверки.

Первый экран и локальный handoff сохранены. GitHub не публиковался; commit/push/merge не выполнялись. Продолжение лендинга — по отдельному поручению.
