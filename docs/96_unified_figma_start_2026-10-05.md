# Единый старт Figma · 05.10.2026

По запросу владельца [лист «Начать здесь»](https://www.figma.com/design/lxPP2um7FvIbt02K8eeH4T?node-id=3-2) стал одной точкой входа для всех четырёх пользовательских версий. Коллеге достаточно отправить эту ссылку вместо восьми отдельных URL.

Дополнение 05.10: на листе добавлена ссылка на [карту экранов](https://www.figma.com/design/lxPP2um7FvIbt02K8eeH4T?node-id=1664-2). Она показывает порядок 11 опорных шагов и 44 прямых перехода к соответствующим экранам RU/EN mobile/desktop. [Как использовать карту и фиксировать замечания — 98](98_figma_navigation_and_quality_control_2026-10-05.md).

Четыре одинаковые карточки разделены по устройству и языку: mobile RU, mobile EN, desktop RU, desktop EN. В каждой два действия:

- **Первый запуск / First run:** на мобильном — три сторис, затем выбор трейдера и настройка демо; на ПК — один обзорный экран, затем тот же путь.
- **Активное демо / Active demo:** подготовленная сессия с историей для проверки позиций, заявок, средств и событий.

Сохранены существующие четыре стартовые точки активного демо. Добавлены четыре явных входа первого запуска. Подписи на листе больше не предлагают искать «отдельный старт» внутри прототипа. Карточки имеют одинаковый размер 314 × 250 px, а обе ссылки стоят на одних линиях.

Проверены все восемь URL-действий и текстовых ссылок: URL совпадают, восемь целевых Figma-узлов существуют. Стартовый лист просмотрен в нативном снимке после выравнивания. Проверка не заменяет ручной проход всех веток в Present; продуктовые экраны и их переходы не менялись.

Для передачи коллеге: откройте [одну ссылку на стартовый лист](https://www.figma.com/design/lxPP2um7FvIbt02K8eeH4T?node-id=3-2), выберите язык и устройство, затем сравните «Первый запуск» и «Активное демо». Таблица прямых ссылок в [инструкции 67](67_figma_archive_revision_2026-10-03.md) остаётся резервным способом открыть отдельное состояние.
