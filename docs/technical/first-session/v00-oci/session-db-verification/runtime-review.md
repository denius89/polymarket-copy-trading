## Wall: потеря подтверждения уже совершённого COMMIT

Оператор сообщил следующий фактически выполненный путь: временная обёртка увидела
ответ PostgreSQL `COMMIT`, но не передала его контроллеру; клиент получил503 без cookie;
GET исходной операции вернул resolved без cookie; Q01 без cookie —401; явное recovery
и следующий Q01 завершились успешно. Применялся временный операторский shim;
позднее добавленный reusable helper бэкенда не выдаётся за исполненный источник этого прогона.

Независимо проверенные времена хранилища, UTC:

| Поле | Сохранённое значение |
| --- | --- |
| completed_at / исходный completion |2026-11-04T12:29:30.257Z |
| resolved_at |2026-11-04T12:29:30.260Z |
| неизменяемый deadline |2026-11-04T12:34:30.257Z |
| close / first confirmation / erasure, полная точность |2026-11-04T12:29:30.572167Z |
| те же markers в DTO с миллисекундами |2026-11-04T12:29:30.572Z |

Прямой plan ссылается на тот же context/operation/login и на единственный полученный
secret ID; secret, credential и window относятся к этому login. Plan.completed_at
совпадает с completion; plan/window deadline совпадают. Close, first confirmation
и erasure имеют одно точное время. Причина закрытия `first_confirmation`, login не
отозван. Секретов, digests, nonce и ключей в опубликованном материале нет.

## Границы заключения

Снимок снят **после** прогона; снимка «до» не было. Он доказывает наблюдаемую итоговую
структуру, отсутствие второго сохранённого bundle и согласованность времён, но сам
по себе не измеряет количество HTTP Set-Cookie и не доказывает неизменность cookie
между двумя ответами. Эти утверждения опираются на отдельные HTTP/browser actual
бэкенда и оператора. SHA256 исходных снимков сохранены в независимом пересчёте.

Оператор отдельно сообщил libsodium1.0.18 roundtrip/wrong AAD/wrong key, HTTP12/12 и
browser37/37. Это не новые испытания, выполненные чатом БД: наша независимая часть —
сверка хранилища и адресная вычитка transaction/target mapping. Полный D03, V01,
production byte codec AC07/AC38, persistent D03-10 quotas и весь каталог78 этим
дополнением не закрываются.
