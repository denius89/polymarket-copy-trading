# Инструкции для Codex

## Перед началом задачи

1. Прочитать `docs/PROJECT_STATE.md`.
2. Открыть `docs/ROADMAP.md` и взять один результат из актуальной очереди.
3. Найти связанные материалы через `docs/README.md` и прочитать соответствующие ADR.
4. Использовать `references/Polymarket_Project_Dialogue_Handoff.md` только как локальный исходный контекст, если файл доступен. Публичные документы должны оставаться понятными без него.
5. Проверить остаток лимита перед крупным исследованием или архитектурной задачей.

## Текущий приоритет

По решению основателя от 24.09.2026 разработка MVP, wireframes и интерактивного прототипа приостановлена до согласования идеи и архитектуры. Текущая очередь находится в `docs/ROADMAP.md`. Прежние указания перейти к прототипу не исполнять.

## Рабочий процесс

- Один цикл должен давать один проверяемый результат.
- Реализовывать минимальный вертикальный срез и не расширять объём без необходимости.
- После изменения интерфейса проводить визуальную проверку.
- После изменения поведения выполнять соразмерные тесты.
- После завершения обновлять `docs/PROJECT_STATE.md`.
- При изменении очереди или gate обновлять `docs/ROADMAP.md`.
- Архитектурные решения фиксировать отдельным файлом в `docs/decisions/`.
- Перед коммитом выполнять `npm run check` и `git diff --check`.

## Безопасность

- Не сохранять приватные ключи, seed phrase, session cookies и рабочие API secrets.
- Реальное исполнение должно быть выключено по умолчанию и включаться явным флагом окружения.
- Не выполнять реальные сделки без отдельного решения основателя о переходе из paper trading.
- Любое неизвестное состояние ордера должно блокировать дальнейшее рискованное действие и создавать запись инцидента.

## Проектные границы

- Polymarket — первый кандидат на execution-площадку; фактический выбор зависит от GEO и spike-проверок.
- Limitless исследуется сейчас, полноценный адаптер добавляется после подтверждения MVP.
- Первый интерфейс — самостоятельный mobile-first web app.
- Основной язык — TypeScript.
- Материалы в `references/` считаются read-only.
